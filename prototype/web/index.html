    LIVE AI CONNECTION

    실제 AI로 업무를 분석해요

    키는 입력 직후 이 PC의 서버로 보내고 입력란에서 지웁니다. 브라우저 저장소·추천 결과·평가 기록에는 저장하지 않습니다.

    직접 입력한 키는 기억하기를 선택하지 않으면 종료할 때 사라집니다. 별도로 등록한 로컬 설정 파일의 키는 재실행 때 다시 읽습니다. 기억하기는 이 앱 전용 Windows 보안 저장소를 사용합니다.

    HOW AX NAVIGATOR WORKS

    문제를 나누고, 사례에서 전략으로

    비슷한 사례를 찾는 데서 끝내지 않고, 우리 업무에서 무엇을 어떻게 바꿔볼지까지 제안합니다.

    현재 실시간 모드의 실제 흐름아래 3개 관점은 설명용 예시 · 실제 개수와 내용은 입력에 따라 달라집니다
    ‘사례의 사실’과 ‘우리 업무에 대한 제안’은 달라요.

    기업이 실제로 실행한 방법과 보고한 성과는 사례 카드에, 우리 업무에서 시험해 볼 절차는 전략 영역에 따로 표시합니다. 효과를 보장하거나 성공 확률을 계산한 결과는 아닙니다.

    키 없는 데모와 연구 비교 옵션은 어떻게 다른가요?

    키 없는 데모: 예시는 저장된 AI 관점 + 실제 Dense 계산을 사용하고, 전략은 사례 분류에 따른 안내 틀로 보여줍니다. 자유 입력은 로컬 문장 분리 + 준비된 Dense 모델로 탐색하며 모델이 없으면 단어 일치로 표시합니다.

    256d QCI: 학습형 검색 모델의 기존 예시 실험 결과를 선택적으로 재생하는 비교 옵션입니다. 현재 기본 검색을 대체하지 않습니다.

    교수님 제안의 전체 연구 아키텍처와는 어떻게 연결되나요?

    아래는 전체 연구의 목표입니다. 위 그림은 현재 프로토타입에서 실제로 연결한 경로이며, 모든 학습·통계 모듈을 완성했다는 뜻은 아닙니다.

    1. 입력 이해와 다중관점 생성관점을 동적으로 만들고 문제·업무·맥락을 구분
    2. Multi-view → Gated Fusion → Hybrid 후보 → QCI학습형 검색 모듈은 별도 실험 · 현재 시연 기본값은 Dense
    3. 관점별 Top-K → Case Evidence Pooling검색된 근거를 관점별로 보존하고 구성
    4. Factor Anchor + Wald 관계 근거 → Evidence Fusion기존 v1 오프라인 진단 이력 있음 · v2.3 통합 효과 검증은 남아 있음
    5. LLM 추천 Head → 전략·근거 경로·행동 설명현재는 선택 사례 기반 설명 단계를 연결 · 학습형 전체 모델의 성능 입증과 구분

    Wald 분석은 요인과 전략의 연관성을 보는 근거이지, 인과관계나 추천의 정답을 보장하는 장치가 아닙니다.

    이 설명은 이 PC에 포함되어 있어 API 호출·추가 요금 없이 열립니다.

    RESEARCH BRIEF · 2026.10.25

    논문 연구, 지금 어디까지 왔나요?

    확인한 저장소의 연구계획·실험 보고서와 현재 프로토타입을 기준으로 정리했습니다. 기능 구현과 연구 효과 검증은 따로 봅니다.

    현재 단계

    작동하는 프로토타입을 완성하고,
    사용자 검토와 독립적인 효과 검증으로 넘어가는 단계

    “이런 결과를 보여주려는 연구”는 실제로 체험할 수 있습니다. 다만 제안 모델이 더 우수하다는 논문 결론까지 입증된 상태는 아닙니다.

    01 · 무엇을 연구하나요?

    기업 업무문제 기반 다중관점 AX 사례 검색·전략 추천 모델

    하나의 업무문제를 여러 관점으로 나누면 관련 사례를 더 잘 찾을 수 있을까요? 사례의 해결 방식과 문제 요인을 근거로, 실행 가능한 전략을 설명할 수 있을까요?

    RQ1 · 여러 관점의 검색 효과RQ2 · 검색 모듈별 기여RQ3 · 요인·통계 근거의 기여RQ4 · 전략·설명·추적성

    02 · 지금까지 실제로 한 일

    자료 구축

    84개 사례와 동적 관점 자료

    출처를 가진 v2.3 사례 84개를 동결했습니다. 개발용 업무 질문 10개를 3회 실행해 관점 97개를 생성했고, 관점–사례 8,148쌍을 AI가 두 차례 평가했습니다.

    AI 임시 판정(Silver)이며 사람이 확정한 정답(Gold)이 아닙니다.
    실험 수행

    관점 보존·Dense·QCI 비교

    관점별 결과 보존, 전체 84개 후보 평가, 학습형 256차원 Gate·QCI를 실제 실행·비교했습니다. QCI는 Dense보다 낮아 기본 검색으로 채택하지 않았습니다.

    같은 수의 후보를 주는 비교에서 다중관점의 독립적 우수성도 아직 미확정입니다.
    시연 가능

    사례 → 우리 업무의 실행 전략

    실제 AI 관점 분해 → 관점별 Dense → 선택 사례 기반 전략·실행 순서·준비사항·한계까지 연결했습니다. 키 없는 데모, 평가 저장, 보고서·CSV·JSON 내보내기도 됩니다.

    테스터는 ‘유용함 / 부분적 / 무관’과 자유의견으로 검토할 수 있습니다.
    기존 연구 이력

    요인·전략 관계와 근거 경로

    이전 v1 코퍼스 100개로 오프라인 Wald 관계 진단과 관점별 검색 경로 복원을 Dev에서 수행했습니다.

    현재 v2.3 84개와 데이터 버전이 다릅니다. v2.3 전체 추천 모델의 효과 검증을 대신하지 않습니다.

    03 · 현재 성능 결과는 솔직히 이렇습니다

    최신 256d 비교의 관점별 Top-10 관련 사례 회수율(Recall)입니다. 개발 질문 10개·동적 관점 97개·84개 사례의 AI-Silver 기준이며, 질문별 평균을 사용했습니다. 관련 사례가 없는 관점 18개는 이 주 평가의 Recall 분모에서 제외했습니다.

    같은 관점·사례·주 평가 기준의 Dev 비교
    검색 방식Recall@10현재 판단
    기존 3-view Dense47.64%프로토타입 기본값
    학습형 256d QCI27.73%기본값 미채택
    Dense + 256d QCI 보정45.33%Dense 개선 입증 못함

    사용자 만족도나 정답 정확도가 아닙니다. 97개 관점은 독립된 업무 질문 97개가 아니며, 이전의 질문별 합집합 Recall 수치와 직접 비교하면 안 됩니다. 추가 AI 감사 후 학습 보조판정은 7,996쌍으로 정리했지만 주 평가 기준과 분리해 보존했습니다.

    04 · 아직 입증하지 못한 것

    • 사람이 검토한 독립 정답과 새 질문의 TestAI 판정의 일치는 실제 정답의 정확성 증명이 아닙니다. 현재 Dev 결과만으로 일반화나 우월성을 확정할 수 없습니다.
    • v2.3의 요인·Wald·Evidence Fusion 전체 효과사례 라벨 표시와 LLM 설명을 학습형 Factor Anchor·통계 결합 모델의 효과 입증으로 해석하지 않습니다.
    • 전략 추천의 실제 유용성과 실행 가능성프로토타입 동작 확인은 마쳤지만, 수정이·교수님·테스터의 독립적인 유용성 검토와 효과 분석은 앞으로 필요합니다.
    • 논문 원고의 완성·제출 여부저장소에서 연구계획과 실험 보고서는 확인했습니다. 완성 원고의 집필·제출 상태는 이 자료만으로 확인할 수 없어 완료율을 표시하지 않습니다.

    05 · 다음에 할 일

    1. 이 결과가 사용자의 의도에 맞는지 듣기관점이 자연스러운지, 사례·전략이 유용한지, 실행 순서에 무엇이 빠졌는지 의견을 모읍니다. 의견을 자동으로 연구 정답에 편입하지 않습니다.
    2. 평가 기준을 고정하고 독립 검증 준비대표 표본의 사람 관련도 검토와 새로운 업무 질문 Test를 설계하고, 같은 출력 예산으로 기준 모델과 비교합니다.
    3. 근거 결합의 기여를 분리해서 검증v2.3 요인·전략 연결의 신뢰도와 희소성을 확인하고, 통계 근거·Evidence Fusion을 더했을 때 실제로 나아지는지 단계별 비교합니다.
    4. 방법·결과·한계를 논문으로 정리성능이 오르지 않은 실험도 보존하고, 시연 완성과 과학적 검증을 구분해 서술합니다.
