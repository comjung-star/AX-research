## 선별할 때 알아둘 점

- 공식 포털 원천 레코드의 단계는 운영 1,989개, 시험 1,521개, 도입 전 1,479개, 개발 중 227개, 계획 15개, 종료 314개, 미사용 69개, 단계 미상 338개입니다. 모두 성공 사례가 아닙니다.
- 원천에서 AI로 분류한 레코드는 5,460개이며, AI 분류·운영 또는 시험 단계·기초 품질 조건을 만족하는 우선 검토 목록은 3,031개입니다. 이는 독립적인 사실·성과 검증이 완료됐다는 뜻이 아닙니다.
- 공식 포털 자료에서 CSV 열 수가 맞지 않은 11개 행은 [별도 격리](portals/malformed_rows_quarantine.json)했습니다. 값을 옆 열로 밀어 넣어 정상 자료로 취급하지 않았습니다.
- 포털 자료의 기관명·제목이 정확히 겹치는 70쌍과 기업 출처의 canonical URL 중복 2그룹을 별도 기록했습니다. 서로 다른 공급사에서 소개한 같은 실제 업무 등 의미 단위 중복은 추가 확인이 필요합니다.
- 기업 출처 중 기존 frozen 사례의 출처와 직접 겹치는 기록도 2개 있습니다. 새 사례라고 단정하지 않습니다.
- 기업·사례포털 웹페이지는 출처 제목, 제한된 설명, 접근 기록·체크섬·본문 분량·키워드 신호를 저장한 수집 후보입니다. 원문 전체를 복제하지 않았으며 문제·실제 해결 방식·관측 성과의 최종 구조화와 한국어 정리는 남아 있습니다.
- 포털 원천의 기대효과를 관측 성과로 바꾸지 않았습니다. 성과가 따로 확인되지 않은 항목은 UNKNOWN 상태를 유지합니다.
