# 자주 나오는 연구 용어 사전

낯선 용어가 나왔을 때 빠르게 다시 확인하기 위한 학습용 문서다.

| 용어 | 쉬운 뜻 |
|---|---|
| AX | AI를 이용해 업무·서비스·조직을 실제로 변화시키는 것 |
| Query | 사용자가 입력하는 질문 또는 업무문제 |
| Case | 검색 대상이 되는 AX 사례 |
| Retrieval | 많은 사례 중 관련 사례를 찾아오는 것 |
| Perspective | 한 문제를 바라보는 하나의 관점 |
| Multi-Perspective | 한 문제를 여러 관점으로 나눠 보는 방식 |
| Dataset | 연구에 사용하는 사례들의 모음 |
| Pilot Dataset | 큰 실험 전에 구조와 규칙을 시험하는 작은 데이터셋 |
| Main Dataset | 실제 논문 실험에 사용하는 본 데이터셋 |
| Freeze | 실험 중 바꾸지 않도록 특정 버전을 고정하는 것 |
| Ground Truth | 실험 전에 만들어 놓은 정답 데이터 |
| Gold Label | Ground Truth 안의 정답 라벨 |
| Gold Perspective | 평가자가 Ground Truth용으로 미리 확정한 정답 관점. 실제 서비스에서 모델에 주는 고정 관점은 아님 |
| Generated Perspective | 실제 사용 시 LLM이 사용자 Query를 보고 그때그때 동적으로 생성한 관점 |
| Gold Relevant Cases | 해당 Query와 관련 있다고 최종 확정한 AX 사례 |
| Gold Strategy Set | Query와 관련된 정답 AX 전략 집합 |
| Relevance | Query/Perspective와 Case가 얼마나 관련 있는지 |
| Baseline | 우리 모델과 비교하는 기존·기본 방법 |
| BM25 | 같은 단어의 출현과 중요도를 이용하는 전통적인 검색방법 |
| Sparse Retrieval | 단어 중심의 희소 표현을 이용하는 검색 |
| Dense Retrieval | 문장을 임베딩 벡터로 바꿔 의미 유사성을 검색하는 방법 |
| Embedding | 문장이나 단어의 의미를 컴퓨터가 비교할 수 있는 숫자 벡터로 바꾼 것 |
| Multi-view | 사례를 Problem·Task·Context처럼 여러 정보 관점으로 나눠 표현하는 것 |
| Problem View | 무엇이 문제인가 |
| Task View | 어떤 업무를 개선하는가 |
| Context View | 어떤 환경·조건에서 문제인가 |
| Gated Fusion | 여러 View의 중요도를 조절해 하나의 표현으로 결합하는 방법 |
| Hybrid Retrieval | Dense, Sparse 등 여러 검색방법을 함께 사용하는 것 |
| Candidate Pool | 정밀 평가 전에 넓게 모아둔 후보 사례 집합 |
| Reranking | 1차 검색 후보의 순위를 더 정교하게 다시 매기는 것 |
| Query-Case Interaction | Query와 Case를 서로 비교하며 관련성을 정밀 평가하는 단계 |
| Root Cause | 문제가 발생한 근본적인 원인 |
| Root Cause Factor | 여러 사례에 공통으로 적용할 수 있게 표준화한 원인 분류 |
| Blind RCA | 해결방법을 보지 않고 Problem View만으로 Root Cause를 판정하는 것 |
| Factor Anchor | 검색된 사례를 공통 Root Cause 기준에 연결하는 것 |
| Wald Evidence | Root Cause와 Strategy의 통계적 연관성을 나타내는 보조 근거 |
| Evidence | 모델의 판단을 뒷받침하는 근거 |
| Evidence Fusion | 사례·Factor·통계근거 등을 결합하는 단계 |
| Strategy | 기업이 실제 문제를 해결하기 위해 적용한 AX 방식 |
| Recommendation Head | 근거를 이용해 최종 Strategy 추천을 만드는 단계 |
| Recall@K | 정답 사례 중 검색 Top-K에서 얼마나 찾아냈는지 |
| Perspective Coverage@K | 여러 Gold Perspective 중 Top-K 결과가 얼마나 많은 관점을 커버했는지 |
| Strategy Coverage@K | Gold Strategy 중 결과에서 얼마나 발견했는지 |
| Search Budget | 비교 모델이 검색할 수 있는 후보 수 등 검색량 조건 |
| Ablation | 모델 구성요소를 하나씩 빼면서 각 요소의 효과를 검증하는 실험 |
| Leakage | 정답이나 Solution 정보를 실험 입력에 미리 노출해 평가가 부당하게 쉬워지는 문제 |
| DRAFT_UNADJUDICATED | 아직 검토·합의가 끝나지 않은 초안 상태 |
| Adjudication | 여러 평가 결과의 차이를 검토해 최종 Gold를 확정하는 과정 |

---

## 반드시 기억할 세 문장

1. **Ground Truth = 시험 정답지**
2. **Baseline = 비교할 기본 선수**
3. **Multi-Perspective = 한 문제를 여러 관점으로 나눠 각각 검색하는 우리 연구의 핵심**
4. **Gold Perspective는 시험 정답이고, 실제 서비스의 Perspective는 LLM이 매 Query마다 새로 만든다.**
