## 9. GTQ001 Perspective Adjudication 완료

Pilot에서 발견한 P2 overlap 문제를 재검토했다.

### 결론
P1/P2/P3 모두 유지한다.

- P1 = 처리용량/규모 문제
- P2 = 반복업무/인력집중 문제
- P3 = 지식접근/답변품질 문제

세 Perspective는 GTQ001 문장에 각각 직접 근거하며, 하나의 AX 사례가 여러 문제를 동시에 해결할 수 있으므로 동일 Case의 복수 Perspective 소속을 허용한다.

### 평가 규칙 보완
- Gold Perspective는 평가용 정답이며 runtime 고정 관점이 아님
- 실제 사용 시 LLM이 Query마다 P1...Pk를 동적으로 생성
- Perspective 개수는 3개로 고정하지 않음
- Perspective Coverage@K는 각 Gold Perspective를 대표하는 관련 Case 존재 여부를 평가
- Perspective 간 Gold Case overlap은 별도 기록하여 Coverage 과대해석 방지
