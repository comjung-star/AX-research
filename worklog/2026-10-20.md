## 13. 교수님 Ground Truth 피드백 반영

### 교수님 직접 질문
- Query와 정답이 1:1 매칭인지
- 전수 relevance 라벨링 시 과적합 위험은 없는지
- 문제만 보고 Perspective를 만드는 것이 단순 카테고리화인지
- Reference에 없는 새로운 관점 생성 시 어떻게 평가하는지
- Ground Truth 작업과 Runtime LLM 동적 Perspective 생성의 연결관계

### 기존 의도 재확인
- Query 1개에 여러 Perspective / 여러 Relevant Case가 대응
- Ground Truth Perspective는 Runtime 입력이 아니라 평가 기준
- Runtime에서는 LLM이 Perspective 수와 종류를 동적으로 생성
- 검색결과를 본 뒤 정답을 만드는 방식은 사용하지 않음

### 우리가 반영한 방법론적 보완
- GTQ001~GTQ010 = Dev/Pilot Query
- 최종 Held-out Test는 모델·Prompt·평가기준 Freeze 후 별도 생성
- Gold Perspective를 의미상 Reference Perspective(최소 기준)로 정의
- Reference에 없는 Generated Perspective를 자동 오답 처리하지 않음
- 새로운 관점은 Query 근거성 / 비중복성 / 추가 Relevant Case 회수 여부를 검토
- 구체적인 Novel Perspective 정량 방식은 Dev 실험 후 Test 전에 Freeze

교수님이 직접 제시한 것은 질문과 우려사항이며, 위 구체적인 평가 규칙은 이를 반영해 연구자가 명문화한 보완이다.
