# 2026-10-28 Query–Case 기능 매핑

## 단위1: 범위 확인·사전 설계

- 사용자 첨부 지시서 전체 확인. 기준 SHA 일치, 작업트리 정상, 원격 기준 fetch 후 새 연구 브랜치 생성.
- 기존 교수님 아키텍처/MLP 구현과 데이터 제한을 검토했다. 이번은 비학습 설명 가능한 기능 매핑 실험이며 교수님 신경망 완성판이 아니다.
- Stage4는 Dev 평가로 구분, 독립 Test 봉인. API/키/학습0. 기능 문법과 추천 정렬식을 새 결과 계산 전에 커밋한다. 규칙설계자는 과거 필수 사례/결과를 이미 알므로 완전 blind라 하지 않는다.
