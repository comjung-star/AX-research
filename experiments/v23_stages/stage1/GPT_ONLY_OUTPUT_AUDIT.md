# Stage 1 GPT-only 비교군 출력 품질 감사 — v2.3

- 원본 비교: v2.3 동결 사례 84개, 개발 질문 10개, GPT-only 독립 반복 3회(합계 API 30회).
- 실제 모델이 반환한 **유효 사례 ID는 평균 6.73개/실행**으로 요청 예산 Top-10을 못 채운 경우가 **24/30회**였다.
- 유효하지 않은 사례 ID **12건**은 저장된 실제 Case ID가 아니므로 임의의 검색정답으로 간주하지 않고 비교군의 오류 기록으로 보존했다.
- 실제로 존재하는 ID가 _01 접미사를 무의미하게 붙이거나 빠뜨린 경우라도 정확한 원본 ID에 1:1로만 대응될 때 정규화하고 원본 반환값을 `rankings.json`에 별도 보존했다.
- 유효한 ID를 임의 추가해 Top-K를 채우지 않았다. 따라서 GPT-only의 Recall@10 성능은 원래 **일정한 Top-10 반환 약속을 충족하지 못하는 시스템**을 포함한 end-to-end 결과이다.
- GPU/Dense 및 BM25는 목표 Top-10을 채웠다. GPT-only와 정확히 같은 반환 건수로 인위적으로 자른 등가 추천건수 비교가 아니므로, 시스템의 품질·출력 계약 준수 차이를 함께 설명할 것.
- GPT-only 반복 성능 점수(Dev AI-grounded proxy)는 서로 차이가 있다. 검증된 인간 Ground Truth나 독립 Test 성능이라고 주장하지 않는다.

**Stage 1은 성공 완료되었으나 이 비교군의 출력 예산 미충족은 별도 실험 제한으로 명시한다.**
