## 키 없이 시연하는 방법

| 입력 | 실제 처리 | 화면 표시 |
|---|---|---|
| 제공된 예시 10개 원문 | 이전 GPT 실행의 동적 관점(run 1) 재생 → 저장된 BGE-M3 1024d 3-view 임베딩으로 점수·순위 재계산 | 저장 관점 + 실제 Dense 계산 |
| 새로 작성한 자유 입력 | 문장·접속어 분리 → 이 PC의 BGE-M3 인코더로 실제 임베딩 → 3-view Dense 검색 | 문장 분리 + 로컬 Dense |
| 로컬 모델을 준비하지 않은 다른 환경의 자유 입력 | 문장 분리 → 문제·업무·맥락 텍스트의 단어/문자 2-gram TF-IDF 일치 | 간편 탐색 · 단어 일치 |

예시 재생은 새 AI API 호출이 아닙니다. 자유 입력의 로컬 문장 분리는 LLM 관점 생성이 아닙니다. 키 없는 모드의 적용 전략은 사례의 frozen 전략 분류와 정해진 안내 틀로 구성되며 **사례 기반 시연 설명**으로 표시합니다. 실시간 모드의 **실제 AI · 사례 근거 기반 제안**과 구별합니다. 각 실행방식은 결과 위와 JSON/CSV에 남습니다. 단어 일치 방식은 Dense로 표시하지 않습니다.

이 PC에는 공식 BAAI/bge-m3 모델을 `.local/models/bge-m3`에 준비했습니다. 예시는 모델 로딩 없이 즉시 검색하며, 자유 입력 첫 실행은 약 2.3GB 모델을 메모리에 읽는 시간이 추가됩니다. 이후 같은 프로그램 실행 중에는 모델을 재사용합니다. 키 없는 두 데모 경로는 네트워크 없이 동작합니다. 공식 출처 링크를 열 때만 인터넷이 필요합니다.

평가 의미: **유용함**은 해당 관점의 업무에 구체적 참고가 됨, **부분적**은 일부 유사하지만 중요한 조건이 다름, **무관**은 해당 관점에 도움이 되지 않음입니다. 이 피드백은 사용성·유용성 검토이며 논문의 독립 검색 Ground Truth로 자동 승격하지 않습니다.

## 평가 저장과 내보내기

1. 결과 위의 **이 PC에 저장 동의**를 체크합니다. 실명 대신 별칭을 사용할 수 있습니다.
2. 사례별 평가 저장 또는 자유의견 저장 버튼을 누릅니다. 버튼을 누르기 전에는 질문을 DB에 저장하지 않습니다.
3. 동일 실행의 동일 관점·사례를 다시 저장하면 기존 평가를 수정합니다. 다른 관점의 같은 사례 평가는 따로 보존합니다.
4. **평가 CSV 내보내기**는 Excel용 한글 UTF-8 BOM 파일입니다. **전체 기록 JSON**은 입력, 실행방식, 관점, 실제 추천, 점수, 근거 경로와 평가를 함께 담습니다.
5. **이번 추천 내려받기**는 현재 결과만 저장합니다. DB 저장 동의와 별개로 사용자가 직접 내려받는 기능입니다.

기본 DB: `.local/ax-prototype/feedback.sqlite3`. Git에서 제외되며 외부로 자동 전송하지 않습니다. 프로그램 종료 후 이 파일을 별도 위치로 복사해 백업할 수 있습니다. 자동 브라우저 검증 기록은 별도 `.local/qa-feedback.sqlite3`에만 저장했습니다. 시연용 기본 DB와 섞지 않습니다.

실제 고객정보, 회사 기밀, API키를 업무 입력·의견에 붙이지 마세요. 키 형식은 저장 전에 가리지만 개인정보 자동 익명화를 보장하는 기능은 아닙니다.

## 실시간 LLM 관점 생성

**2026-10-25 확인:** 현재 PC의 `.env` 키로 실제 API 연결과 LLM→Dense 전체 추천 흐름을 검증했습니다. 바탕화면 실행파일은 시작 시 `.env`를 자동으로 읽으며, 키가 있으면 실시간 AI를 기본 선택합니다. 키를 변경하면 프로그램을 종료하고 재실행해 주세요. [실제 실행 결과](prototype-validation/live-api-result.json).

### 화면에서 바로 API 연결하기

1. 상단 **API 연결**을 누릅니다.
2. **OpenAI API키** 입력란에 직접 키를 입력합니다. 채팅이나 업무문제 입력란에는 보내지 마세요.
3. 모델은 기존 실험과 같은 `gpt-6-luna`가 기본입니다.
4. 내일 재실행할 때도 기억하려면 **Windows 자격 증명 관리자에 안전하게 기억하기**를 선택합니다. 선택하지 않으면 이 프로그램의 메모리에서만 사용합니다.
5. **연결 확인 · 실시간 사용**을 누릅니다. 일반 예시로 실제 OpenAI API 요청을 보내 관점 생성 응답을 확인합니다. 연결 확인 자체에도 소량의 API 비용이 발생할 수 있습니다.
6. 성공 메시지를 확인한 뒤 창을 닫고 업무문제를 입력해 **관점별 사례 찾기**를 누릅니다. 연결 후에는 예시 버튼을 눌러도 실시간 모드를 유지합니다.

API키는 제출 직후 입력란에서 지우며, 연결 상태 응답이나 추천·평가 내보내기에 포함하지 않습니다. 기억하기는 이 앱 전용 Windows 보안 저장소를 사용하며 소스 폴더·브라우저 저장소에 키를 저장하지 않습니다. **키 연결 해제**를 누르면 이 앱의 메모리 키와 이 앱이 보관한 자격 증명을 삭제합니다. 다른 프로그램이나 Windows 전역 환경변수의 키는 변경하지 않습니다.

잘못된 키는 인증 실패, 사용 한도·잔액 문제는 사용 한도 안내, 접근 불가능한 모델은 권한·모델 이름 안내를 표시합니다. 실패한 새 키가 이전의 정상 연결을 덮어쓰지 않습니다. 실제 LLM 추천 JSON의 `llm_evidence`에는 응답 ID, 모델, 토큰 수와 실제 호출 여부를 기록합니다. 키는 기록하지 않습니다.

구현 근거: [OpenAI API 인증 안내](https://developers.openai.com/api/reference/overview), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna). 서버에서 공식 OpenAI API만 호출하고 `store=False`로 요청합니다. 이 옵션이 모든 API 보관 정책의 부재를 의미하지는 않습니다.

### 환경변수로 연결하기 (개발자용)

프로젝트 최상위의 **`.env`** 파일도 실행 시 자동으로 읽습니다. 첫 줄을 `OPENAI_API_KEY=발급받은키` 형식으로 작성하고 저장한 뒤, 기존 프로그램을 종료하고 바탕화면 **AX나침반.exe**를 다시 실행하세요. 기존 프로세스 환경변수가 있으면 그 값이 우선합니다. `.env`는 GitHub 업로드에서 제외되며, 키 값은 연결 상태 응답이나 평가 기록에 포함하지 않습니다.

실시간은 사용자 업무문제에서 **문제 관점 1~6개를 동적으로 생성**하고, 기존 BGE-M3로 관점별 독립 Dense Top-K를 계산합니다. 평가용 reference 관점이나 qrels는 런타임 입력으로 사용하지 않습니다.

최초 인도 검증 당시 API키가 없어 실제 유료 LLM 호출은 미검증이었습니다. 새 API 연결 창의 성공 표시는 실제 응답을 받은 경우에만 나타납니다. 키가 없거나 연결에 실패하면 안내를 보여주며 재생 결과로 몰래 바꾸지 않습니다.

키를 소스·실행파일에 넣지 않습니다. 화면 연결 대신 Python을 실행하는 프로세스의 `OPENAI_API_KEY` 환경변수를 사용할 수도 있습니다. PowerShell에서 키를 명령 이력에 남기지 않고 입력하려면 다음과 같이 실행할 수 있습니다.

```powershell
$secureKey = Read-Host 'OpenAI API 키' -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', $secureKey).Password
./.venv/Scripts/python.exe -X utf8 run_prototype.py
Remove-Item Env:OPENAI_API_KEY
```

먼저 기존 앱을 화면에서 종료해야 새 프로세스에 설정한 키가 적용됩니다. **분석 방식 → 새 문제 분석 · 실시간 AI**를 선택합니다. 이 방식에서는 입력문제가 OpenAI API로 전송되며 API 비용이 발생할 수 있습니다. 기본 LLM은 기존 실험의 `gpt-6-luna`이며 필요하면 `AX_LLM_MODEL` 환경변수로 접근 가능한 모델을 지정합니다. 키 설정 후 성공 여부는 사용자의 계정·모델 접근권한·네트워크에 따라 달라집니다.

## 새 환경에서 설치·재현

Python 3.11 이상이 필요합니다. 현재 Windows PC는 Python 3.13을 사용합니다.

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements-prototype.txt
./.venv/Scripts/python.exe -X utf8 run_prototype.py
```

예시 시연에는 모델 다운로드가 필요하지 않습니다. 새 자유 입력도 실제 Dense로 검색하려면 공식 모델을 한 번 준비합니다.

```powershell
./.venv/Scripts/python.exe -X utf8 scripts/prepare_prototype_model.py --download
```

모델은 약 2.3GB이며 `.local/`에만 저장됩니다. 이미 가지고 있는 BGE-M3 모델 폴더는 `AX_BGE_MODEL_PATH`로 지정할 수 있습니다. 다른 임베딩 모델은 frozen 1024d 인덱스와 혼용하지 마세요.

바탕화면 실행파일을 다시 만들려면 다음을 실행합니다. Windows 내장 .NET Framework C# 컴파일러로 생성하며 관리자 권한은 필요하지 않습니다. 기존의 다른 실행파일을 덮어쓰지 않습니다.

```powershell
./scripts/install_prototype_desktop.ps1 -Desktop
```

## 연구 비교와 한계

- **연구 비교 옵션 → 256d QCI**는 제공된 예시의 기존 LOQO 학습 실험 Top-10을 재생합니다. 모델을 새로 학습하거나 임의 입력에 QCI 추론한 결과가 아닙니다.
- 기본 **Dense**는 Problem / Task / Context의 코사인 유사도를 각각 계산해 평균합니다. 관점마다 전체 84개를 비교하며 서로 다른 관점의 순위를 합치거나 전역 중복 제거하지 않습니다.
- 한국어 카드 설명은 별도 읽기용 요약입니다. 검색 임베딩·원인·전략 라벨·frozen 사례 원문은 고치지 않았습니다. 단어 일치 대체 검색에는 읽기용 문제·업무 요약도 사용하며 해결책 정보는 넣지 않습니다.
- 원인과 전략 라벨은 기존 사례의 분류이며 사용자 문제의 확정 원인이나 인과효과가 아닙니다. 실시간 AI는 관점별 상위 3개 이내 선택 사례와 허용된 전략 분류만 근거로 적용 전략·실행 순서·준비사항·한계를 작성합니다.
- 선택 사례의 문제·구현·성과·출처 요약과 사용자의 업무문제가 OpenAI API로 전송됩니다. 전체 84개 데이터셋·평가 기록·API키 값은 프롬프트에 넣지 않으며 `store=False`로 요청합니다. API 인증에는 서버에 등록한 키를 사용합니다.
- 새로운 LLM 전략 설명 단계는 연결했지만 **학습형 Evidence Fusion·Wald 통계 기반 전략 판단의 성능을 검증한 완성 모델**은 아닙니다. 독립 인간 평가·Held-out Test도 완료했다고 주장하지 않습니다.
- 원본 사례의 관측 성과와 외부 기업·벤더 발표를 독립 실험의 효과로 제시하지 않습니다.
