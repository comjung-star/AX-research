# v2.3 동적 생성 관점의 AI-Silver positive 0건 18개 원인 감사

**2026-10-24 실제 데이터 점검**. 원본 매핑은 `experiments/v23_runtime_perspective_qrels/runtime_qrels_8148.csv`; per-view 요약, 60개 원시 평가 `raw_passes/`, 84 사례 `data/v2_3/main_cases_v2_3.json`를 직접 대조한 진단 결과다. 원본 qrels 점수는 변경하지 않음.

## 결론
**18개가 모두 '관련 AX 사례가 실제로 존재하지 않는다'는 증거가 아님.** 관련 사례 0건의 정의는 84개 중 **두 번의 독립 AI 평가 모두 3점 이상**을 부여한 사례가 0건이라는 것이다. 18개 중 **8개 관점에는 적어도 한 채점에서 3점 이상을 받은 후보**가 있었고, 10개는 두 채점 모두 3점 이상 사례가 없었다. 18개는 단 5개 원질문에서 생성된 회차별 관점이므로, 독립 업무 문제 18개가 아님. 두 평가가 불일치해 학습에서 제외된 관점–사례 쌍은 해당 18개 관점에서 합계 **17건**.

## 데이터 근거로 확인한 주요 원인 3가지

### A. 실제 원문 업무 범위의 불일치 (코퍼스 공백 가능성)
- **부서 간 분석 기준 불일치**(V21D005, 3회 반복): Suzhou Universal `AXV2C_0093_01`(생산·품질 데이터가 분산되어 분석이 늦음)은 2/2점. 분석 작업은 관련되지만 **부서별 정의·기준의 불일치**는 사례 problem/task에 나오지 않아서 3점 미달.
- **생산가능성 판단의 경험 의존**(V21D007): Savage Precision Fabrication `AXV2C_0094_01`은 2/2점. 제조 견적 작성은 맞으나 **생산가능성 판정이 담당자 경험에 좌우된다**는 명시적 문제는 아님.
- **운영조건에 따른 생산량 변동**(V21D008): Albert Heijn `AXV2C_0050_01` 수요 예측과 Suzhou Universal `AXV2C_0093_02` 생산일정 조정이 유사할 수 있지만, '운영조건에 따른 실제 생산량 변동'은 명시되지 않아 2/1 또는 2/2점.
**판단:** 특정 관점은 frozen 84-case corpus에 그대로 대응하는 충분한 문제/업무 근거가 적다. 모든 AX 사례를 일반적인 '응용 가능성'만으로 related=3으로 올리면 연구 지표 왜곡.

### B. 채점 3점 문턱과 관점의 좁은 표현
- **기존 자료의 재작성**(V21D003 run2 P3): Morgan Stanley `AXV2N_0110`의 내부 문서 검색은 2/2점, IBM Creative and Content `AXV2N_0104`의 반복 고객 사례 초안 작성도 2/2점. 자료 검색·문서 작성은 공유하지만 원문상 **이미 있는 자료를 찾지 못해 같은 자료를 다시 만든다**는 핵심 고리는 명시되지 않았다.
- **복합 변동 요인**(V21D008 run1 P2): Albert Heijn `AXV2C_0050_01` 수요 예측은 2/2점. 수요 예측 문제는 맞지만 **기상·시장·운영 등 복합 변동 요인**은 사례에 명시되지 않았다. 넓은 '수요 예측'이면 유사, 좁은 '복합 원인'이면 일치하지 않음.
**판단:** 동적 LLM 관점이 원 질의의 구체적 원인/표현을 부여하고, 케이스는 간략한 Problem/Task/Context만 포함하는 경우 3점 이상 문턱에서 유용한 유사 사례가 2점에 묶일 수 있다. 라벨 기준이 잘못됐다고 단정할 수는 없음.

### C. 두 AI 채점 간 판정 불일치
- **전사 확산 보안 운영**(V21D009 run1 P3): 제주은행 `AXV22_0093_01`(전행 내부망 지식/문서 기반 에이전트)은 **4점 / 2점**. 한 채점은 전사 보안 운영에 직접 관련된다고 판단, 다른 채점은 **부서별 도구 운영 기준의 불일치 자체는 명시되지 않았다**고 판단. 두 점수의 관련 여부가 달라 임시 라벨은 UNRESOLVED.
- **기존 자료 재사용 부족**(V21D003 run1 P3): BPC `AXV2H_0071_01` **3/2점**, IBM Software Support `AXV2H_0091_01` **3/2점**. 기존 자료 검색과 기존 자료를 못 찾아 다시 만드는 과업의 포함 여부를 다르게 판단.
- **이종 자료 해석·비교**(V21D007 run3 P1): Relativity/문서 판단 사례 `AXV2H_0003_01` **2/3점**, 운임 청구/요율 비교 사례 `AXV2P2_0011_01` **3/2점**. 비교 업무의 의미적 범위를 다르게 판정.
**판단:** 이 사례들이 자동으로 3점 '정답'이 된 것은 아니다. 오히려 운영상 **매핑 불확실성을 보존해야 하는 경계 사례**라는 직접적 증거.

## 결론 및 정확한 수정 방향
1. **표시 수정:** `no related AX cases` 대신 `현재 코퍼스에서 두 AI 평가가 모두 3점 이상으로 인정한 사례 없음`으로 표현. 확실한 실제 코퍼스 공백은 인간 판단 또는 별도 독립 평가 후 판정.
2. **라벨 보존:** 기존 8,148개 raw 점수와 17개 경계 충돌을 **사후 임의 상향 변경 금지**. 추가 검토를 통해 별도 `independent_review`로 결론을 저장하고 기존 AI 점수와 병기.
3. **다음 검증 순서:** 8개 충돌 관점을 우선 검토, 그다음 10개 양쪽 0 관점의 각 최고 2/2점 유사 사례를 검토. 각 판단은 문제/과업/맥락의 공통 부분과 부족한 부분을 함께 증거로 기록.
4. **모델 사용:** 학습에서는 합의 양성 0개 관점을 무조건 삭제하거나 가짜 positive를 생성하지 않는다. 런타임 검색에는 Top-K 후보를 계속 점수와 함께 낼 수 있으나, '확실한 유사 사례 없음' 또는 '부분 유사 참고 사례'라는 구분과 신뢰도 표기가 필요.
5. **연구 범위:** 97개 동적 관점은 10개 원질문의 반복 재생이므로 18개 empty = 18개 독립 문제 실패가 아님. 독립 신규 질문, 소규모 인간 검토, 과도하게 구체화되는 관점 생성 프롬프트 조정은 **향후 별도 통제 실험**으로 평가.

**결과 요약:** 18개 중 8개는 AI 두 pass의 의견 충돌, 나머지 10개는 두 pass 모두 강한 일치사례가 없다는 평가. 이것은 자동 학습을 위한 보수적 품질 통제 결과이며 '실제로 대응 사례가 없는 관점 18개'라는 진술보다 정확하다.
