# AX v2.3 Stage 1 — Why Single Dense relevant Top10 cases disappear in MP Dense

작성일: 2026-10-24

## 목적 및 범위
v2.3 Stage 1의 동일한 Dev 10개 질의, 84개 동결 AX 사례, BAAI/bge-m3, 2,520개 AI-Silver 관련도 평가 자료를 **수정하지 않고**, 기존 Single Dense Top10의 Silver 양성 사례가 Multi-Perspective Dense 최종 Top10에서는 빠진 원인을 분해했다. 질문마다 MP 3회 실행을 Single Dense 1회(run 0)와 대응시켜 비교했다. 따라서 출현 건수 합계는 독립적인 39개 사례도 독립적인 39개 실험도 아니다.

원본 브랜치 `release/ax-v2.3-stage1-to4-dev-20261023`; 성공한 기존 Stage 1 실행 `39952604227`.
기준 원본 Git blob: `rankings_top20.csv` `08b71c2a1c6e9b9ad4e658bbfdc5c47844555e92`, `branch_rankings.csv` `958e5e325f6d571af02e149fdb8edb739186fb34`, `silver_dev_qrels_2520.csv` `9cdf60dc6f6da7bb5c3950f8d337f12ccf02df91`, `generated_runtime_perspectives.json` `0bca50f107a9d66147dcf05b1d3a933fe857402a`.

## 1. 원인 분류의 정확한 정의
질의 q, MP 실행 r, Single Dense Top10 관련 사례 c 중 MP 최종 Top10에 없는 사례에 대해서, MP의 **모든 생성 관점별 BGE-M3 순위(각 84개)**에서 c의 최상위 local rank를 확인한다.

- A — `BRANCH_TOP10_BUT_EXCLUDED`: 적어도 한 관점 branch의 순위가 1~10위이지만 최종 MP Top10에는 없음. **최종 출력 예산과 결합 단계에서 미선정됨.** 결합 알고리즘이 해당 사례를 읽지 못했다는 의미가 아님.
- B — `BRANCH_RANK11_20`: 모든 branch에서 10위 밖이나 최소 하나는 11~20위. **관점별 검색 순위가 원문 단일 검색 대비 밀림.**
- C — `BRANCH_BELOW20_OR_MISSING`: 모든 branch에서 20위 밖. 실제 저장된 전체 branch 순위는 84개이므로 이 분석 사례들은 확인된 22위이며, **검색이 완전히 실패하거나 검색 대상에서 사라진 것은 아님.**

서로 배타적인 분류이며 합산 총 39회 출현.

## 4. 해석과 원인 가설의 구분

**실증 관찰:** A/B/C는 실제 저장된 관점별 순위와 최종 순위를 교차 확인하여 나온 결과다. 39회 누락 중 다수는 관점 검색에 이미 존재했다. 이는 '다중 관점에서 사례를 찾지 못한다'는 단정과 배치된다.

**가설:** 현재 branch-balanced unique 결합은 관점 사이의 균등 기회를 보장하므로 상대적으로 후순위인 강한 관련 사례도 최종 K 슬롯 때문에 누락될 수 있다. 다만 이 결과만으로 branch-balanced가 다른 공정한 결합 방식보다 열등하다는 인과적 결론이 도출되는 것은 아니다.

**다른 가설:** 원래 문제의 긴 문맥을 짧은 동적 관점 제목만으로 교체할 때 일부 사례의 상대 순위가 낮아진다. 관점 title+description 등 다른 문자열 템플릿은 기존 v2.3 진단에서 확인했지만, **다른 템플릿이 항상 향상되는 것은 아님**. 템플릿, branch 분해 질, 코퍼스/관련도 라벨을 분리해 평가해야 한다.

## 5. 다음 공정한 진단 제안

1. **결합 과정에서 탈락한 A형 24회**를 대상으로, 원본 3회 검색순위에서 원래 Single Dense의 관련 사례를 보존하는 정도와 새 관련 사례를 동시에 얻는 정도를 구분해 평가한다. Top10 공통 예산 유지, branch identity 보존. 교수 제안 아키텍처는 Multi-view/Gated Fusion이며 RRF를 임의로 공식 아키텍처로 치환하지 않는다.
2. **관점 순위 자체가 떨어진 B/C형 15회**에 대해서는 LLM 관점 제목/설명, 원문 맥락, 각 branch 코사인 점수 및 중복도를 대조한다. 검색 문장 조건을 바꾼 실험은 같은 84개 사례와 qrels, 동일 TopK 하에서 별도 사전등록한다.
3. 분석에서 **AI-Silver 경계 사례**를 별도 표시하고, 새로운 유효 문제관점의 독립 판정은 기존 3개 참조 관점 coverage와 분리한다.
4. 현재 결론은 **기존 Dev 데이터의 원인 진단**이지 held-out Test의 성능 입증이 아니다.

**데이터 보존:** Stage 1–4 결과, Frozen v2.3 사례 및 Silver 평가 파일 모두 변경하지 않았다.
