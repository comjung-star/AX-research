## 구현에서 바꾼 것

혼합 질문20건 요청을 없애고 같은 질문별로 나눴다. 참조관점은 질문 ID와 관점 ID를 함께 분리했다. 모든 항목에 질문 원문과 사례 P/T/C를 반복 제공했다. 원질문 관련도와 참조관점 관련도는 별개로 평가했다.

세 모델 모두 출력 구조를 지정하고, ID·키·누락·중복·점수 범위·업무 일치 표기·발췌·이유 길이를 다시 검사한다. 다른 질문 발췌나 다른 사례의 근거 연결은 중대한 오류로 중단한다. 이유 상한은 새 v6부터40단어로 지시·검증을 통일했다. v8의 인용 부분은 원문에서 자동으로 잘라 제공하므로, 연결 검사를 통과한 것만으로 모델 이해의 정확성을 주장하지 않는다.

일반 형식 오류는 별도 버전으로 수정하고 시험했다. 이유 초과, 키 누락·오명명, 한국어 인용의 바꿔쓰기, OpenAI JSON 모드의 필수 입력 문구 누락을 해결했다. 과거 시도를 덮어쓰거나 이유를 임의로 잘라 통과시키지 않았다. v8은40쌍을 세 모델 모두 새로 평가했으며, 다른 버전의 점수를 v8 통계에 섞지 않았다. 버전별 비용은 모두 누적했다.

문자열 문맥 검사에도 오탐이 있었다. 차체 생산/용접을 manufacturing으로, quoting을 quotation으로, 익명화를 privacy로 표현한 정상 연결 등을 실제 원문과 대조해 수정했다. 경고 단어와 허용 근거 표현을 분리해 광고 이미지 production이 제조로 잘못 분류되는 검사 오류도 고쳤다. 냉동창고 하역을 manufacturing logistics라고 넓혀 부른 응답은 근거 없는 산업 수식어로 따로 남겼다. 이 문제를 다른 질문 혼동으로 집계하거나 이유의 사실성을 승인하지 않았다.

최신 [정책](protocol-v8.md), [형식 변경 이력](format-revisions.md), [개별 문맥 검토](context-review.json), [중단 설정](format-v8/halt.json)을 함께 읽어야 한다. 최초 파일럿 게이트의 ‘전수 점수 수집 허용’은 후속 중단 설정으로 폐기됐고 Silver 또는 Stage2·3 승인을 뜻하지 않는다.

## Stage 2·3 준비와 미완료 범위

Stage2 비교 코드는 동일 P/T/C, BGE-M3 전체1,024차원, CLS, 정규화, 기존 동일 가중3-View, BM25를 사용하도록 준비했다. 기존 branch-balanced unique 방식도 유지한다. 공통 사례 후보 전체112개, 최종 고유 후보20개와 Top5/10/20을 명시하며, 정답 미승인이나 미판정이 있으면 실행 전에 거부한다. 토크나이저로 본 단일 P/T/C의 최대 길이는87토큰이어서 설정4,096에서 정보 잘림은 없었다. 이는 임베딩·검색 성능 실험을 실행했다는 뜻이 아니다.

정답이 승인되기 전에는 A=원질문/단일Dense, B=원질문/3-View, C=동적관점/단일Dense, D=동적관점/3-View를 실행하지 않는다. 현재 네 조건과 BM25 모두 Precision·Recall·F1·Coverage는 **미산출**이다. 수치0으로 기입하지 않았다. Stage3 관점·검색어 비교·관련 사례 획득/손실도 미완료다.

관련 사례가0개인 질문을 발견하면 삭제하거나 양성을 꾸며내지 않는다. Precision 분모K는 유지하고 Recall/F1은 미정의로 표시하며, 평균에 들어간 질문 수와0개 질문 수를 함께 공개하도록 시험했다. 아직 전수 정답이 없어 실제0개 질문을 확정하지 않았다.
