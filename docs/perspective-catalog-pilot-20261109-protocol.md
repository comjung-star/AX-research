# 사례 근거 기반 관점 목록 시범 — 사용자 승인1~3단계

자료: 기존112개사례의Problem/Task/Context만. 질문별정답표·추천순위·평가점수는사용하지않는다. 사례를검토한assistant가관점후보와시범연결을작성하며새유료AI·추천·학습·사용자질문선택기는실행하지않는다. 원문출판물전체를재검증하거나독립전문가Gold를만드는작업은아니다.

1. 이전10개참고축을고정분류로쓰지않고구체적문제후보를나열한다. 전체사례검토와전체사례의완전분류는구분한다. 후보의대표사례는출발근거이며전수연결확정이아니다.
2. 경계비교가가능한소수문제관점에정의/포함/제외/원문근거/적용조건/미확인정보를붙인다. 실제수행기능은Task근거가필요하고Problem의필요성만으로구현을추정하지않는다. 같은사례가다른기능근거로여러관점에연결될수있다.
3. 연결은요약원문이뒷받침/확인보류/이번관점에서제외로구분한다. 제외는그사례가모든질문에무관하다는뜻이아니다. 동종업무·업종·단어만공유한대조사례, 현재확인과실제수정등행동경계, 검색/추출/검증차이, 관점중복을검토한다. 인용문자열과위치는코드로확인하고의미판단은같은assistant의내부검토라는한계를남긴다.

조건은질문이관점에맞는지판단할선택기준이지모든연결사례가그조건을충족한다는주장이아니다. 각연결에지원하는부분/지원하지않는부분/추가확인이필요한조건을구분한다. 근거부족사례는연결된정답으로승격하지않고, 맞는관점이없을때대체관점강제선택도하지않는다.

종료: 소수시범카드와후보목록, 긍정/보류/제외연결의원문근거및중복·과장검토기록을산출하면1~3단계완료다. 의미정확도/추천성능/전체112개적용완료/최적관점수라는주장은하지않는다. 기존교수구조나LLM동적관점모델은변경하지않고별도의사용자승인실험설계안으로보존한다.
