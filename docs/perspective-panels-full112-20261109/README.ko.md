## 4단계: 자료에서 관점 연결 확장

- 공통 인정 57개 연결을 추가 점검해 명확한 분류 경계 오류 4개를 보류했다.
- 확정 실험 목록은 **49개 사례, 53개 연결**이다. P01 검색 7, P02 추출·구조화 13, P03 문서·자료 검토 17, P04 문의 대응 16이다.
- 기존 시범 목록 17개 사례의 승인 연결 18개는 유지된다. 나머지 63개 사례를 네 관점에 억지로 넣지 않았다.
- 22개 판정 불일치는 보류로 남겼다. 추가 점검의 보류 4개는 22개와 별도이다.
- 자료에 없는 검색 기능을 검토 업무에 덧붙인 2개, 주제 요약을 추출·구조화로 해석한 1개, 차량 카메라 검사를 문서 대조로 해석한 1개를 보류했다.

근거: `stage4/summary.json`, `stage4/catalog-expanded.json`, `stage4/review-a.json`, `stage4/review-b.json`, `stage4/source-audit-held.json`.

주의: 사람의 정답 검증이 아니다. 동일 모델 계열의 별도 검토이며 기존 배정에 노출되었다. 저장된 Problem/Task/Context 요약을 검토했으며 원 출판물 전체를 다시 확인한 것은 아니다. 마지막 보조 검토는 사용량 한도로 종료됐지만 파일은 저장되어 있어 주 작업에서 형식과 인용을 확인해 반영했다.

## 5단계: 실제 질문→관점 선택

- 마지막 자료 점검 전 실제 API 예시 질문 6개는 형식 검사와 예상 관점 집합 비교에서 6개 모두 일치했다. 이는 사람이 독립적으로 만든 정답에 대한 정확도 100%를 의미하지 않는다.
- 자료 점검 후 예시 6개는 5개가 전체 계약을 통과했다. 1개는 선택한 관점 ID는 맞았으나 추정 확인 항목을 사용자 원문 조건처럼 써서 인용 검사에 차단됐다. 원문 조건과 추가 확인 사항을 구분하는 지시를 보완한 뒤 해당 1개를 확인했다. 오류 기록은 보존한다.
- 새 질문 8개는 별도 작업자가 자료·방법·검색 결과를 읽지 않고 작성했으며, 주 작업자는 방법 고정 후 내용을 열었다. 8개 모두 정상 선택 계약을 반환했고, 이 중 1개는 출력 한도에 걸려 사전 허용한 동일 설정 1회 기술 복구가 필요했다.
- 형식 통과와 별개로 의미 오류 2개를 발견했다. FQ007 물리 예지보전을 문서 대조로 확장했고, FQ008 수요예측 사례를 찾아달라는 요청 자체를 회사의 문서검색 업무로 오인했다. 이 질문을 제외하거나 결과를 보고 방식을 고치지 않는다.
- 새 질문은 합성 자료이며 실제 사용자를 대표한다고 볼 수 없다. 4개 관점에 맞는 분야를 일부 지정한 작은 탐색 실험이다.

## 6단계: 같은 수의 결과로 비교

검색 결과 저장·OpenAI 전체평가·수치 계산·로컬 재현 완료. Gemini 전체평가는 일일20회 할당 초과로 미완료다. 새 방식의 관점별 최대5개에서 중복 사례ID를 뺀 수U를 정하고 단일 질문 검색도U개를 비교했다. 이번U는 질문별5~15다. 유용한 추가39쌍·놓침23쌍을 모두 기록했다. 두 채점 결과를 일치시킬 때까지 반복하지 않았다.

채점 형식 확인에서 Gemini가 Task 인용란에 Problem을 복사한 오류도 있어, 새 질문 개봉 전 두 모델 모두 인용문을 생성하지 않고 무작위 사례 위치로 실제 Task 원문을 직접 연결하는 형식으로 고정했다. 출처를 잘 연결한다고 관련성 판단까지 자동 검증되는 것은 아니다.

U는 서로 다른 레코드 ID 수다. 112개 레코드는 83개 출처·누수 그룹에 속한다. 같은 그룹에 다른 업무가 들어 있을 수 있으므로 그룹 전체를 동일 사례로 단정하지 않으며, 결과의 출처 그룹 수도 기록한다.

기존 84×30 / 112×20 정답은 새 기준의 정답으로 가져오지 않는다. 봉인 Test15는 열지 않고, 모델 학습·원격 저장소 수정은 하지 않는다.

## 실행 및 비용

클로드는 실제 형식 확인 호출에서 잔액 부족 오류가 확인됐다. 충전하지 않았다. OpenAI·Gemini는 기본 확인 요청에 응답했다. 요청·응답·실패·사용량은 `api/`에 저장하며 키는 저장하지 않는다. 비용 상한은 15달러이고 실제 사용량 비용과 최악 예약 금액은 구분한다. `scripts.panels_full112_api_20261109.ledger()`로 이번 작업 비용을 다시 집계할 수 있다. 이전 실험의 미확정 청구액은 이 집계에 포함하지 않는다.

최종 사용량×단가 추정은3.41842달러, 보수적 예약액은10.3777845달러이며 미확정 전송은0건이다. Gemini는 무료 할당이므로 실제 청구액과 다를 수 있다. OpenAI 대기열 동시 처리 수만 실행 중 조정했으며, 모델·프롬프트·질문·출력한도·검색결과·평가지표는 바꾸지 않았다. 해당 실행 변경 기록도 남겼다. 검사19개 및8개 관점 결과 재현·동일U·수치 재계산은 통과했다. 이 확인이 의미 정확성이나 개선효과의 완전 검증을 뜻하지 않는다.
