# 이번 단계에서 정리한 기준

## 관점 선택

1. 질문에 명시된 문제·작업은 직접 근거로 연결한다.
2. 같은 문제의 다른 측면은 원문 증상+연결 이유+미확인 가정으로 제시한다. 원인으로 확정하지 않는다.
3. 같은 업종·기술이라는 이유만으로 관점을 추가하지 않는다. 명시 제외를 존중하고 억지로4개를 모두 고르지 않는다.

## 사례 제시

관점당 최대5개. 원문에 실제 수행한 업무와 연결 근거가 있어야 한다. 세부 적용 조건은 확인사항으로 설명하고, 원문에 없는 기능을 지원한다고 하지 않는다. 다른 업무라도 문제 해결에 참고할 연결 경로가 있으면 배제하지 않는다.

## 후속 성능 평가 준비

|값|기준|
|---|---|
|3|질문 문제에 직접 관련된 실제 핵심 업무|
|2|다른 관점이지만 구체적인 도움 경로가 있고 가정·차이를 설명할 수 있음|
|1|산업·기술·주제만 같거나, 없는 핵심 능력을 추가해야 함|
|0|유용한 연결이 없거나 명시 제약과 모순|

단순검색에도 같은 관점 평가 기준을 적용한다. 중복 제외U개라면 단순검색상위U개와 비교한다. 추가 발견뿐 아니라 놓친 사례와 중복도 보고한다. 현재71개 기능 검사와34개 재현은 이 의미적 점수를 검증한 결과가 아니다.
