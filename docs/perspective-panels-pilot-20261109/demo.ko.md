# 관점별로 보여주는 예시

**아래 첫 예시는 새 기준의 화면 동작을 보기 위해 관점을 수동 구성한 것이다. LLM이 새 기준으로 선택한 결과가 아니다.** 사례와 인용 근거는 기존 실제 데이터셋에서 가져왔다.

> 고객 문의 답변이 늦어져 대기가 길어집니다. 참고할 실제 사례를 보고 싶습니다.

## 업무 지식이 길고 분산돼 필요한 근거를 찾는 데 시간이 걸림

답변 근거를 찾는 시간이 지연 요인이라면 내부 지식 검색 사례가 참고가 될 수 있습니다.

**확인할 가정:** 직원이 답변 근거를 찾는 시간이 지연의 일부인지 아직 확인되지 않았습니다.

|순위|실제 사례의 수행 업무|사례ID|
|---|---|---|
|1|Document retrieval and cross-reference support|AXALL_US_OMB_2025_02663|
|2|Retrieve internal knowledge for financial advisors|AXV2N_0110|
|3|Retrieve CAD/CAM product support knowledge|AXV2P2_0010_01|

각 사례의 관련 이유·원문 근거·확인할 조건은 [전체 표시 예시](examples.ko.md)에 남겼다. 직접 적용이 확인됐다는 뜻은 아니다.

## 문의량·접수 시간대가 응대 가능 용량을 넘어 대기·누락이 생김

문의 응대 지연과 대기가 질문에 명시돼 있어 응대 용량·공백 대응 사례를 살펴봅니다.

|순위|실제 사례의 수행 업무|사례ID|
|---|---|---|
|1|Answer airline customer service questions|AXV2P2_0060_01|
|2|고객 문의 자율응답|AXV2H_0001_01|
|3|의료기관의 보험 자격·보장 음성 문의 응대|AXV24_71def85d86bd|
|4|RV 고객 문의의 상시 응대 및 상담원 인계|AXV24_df5d48fedff4|

각 사례의 관련 이유·원문 근거·확인할 조건은 [전체 표시 예시](examples.ko.md)에 남겼다. 직접 적용이 확인됐다는 뜻은 아니다.

**두 관점에서 총7개를 표시하고, 전체5개로 다시 줄이지 않는다.** 다음 성능 비교에서는 단순검색도 고유7개로 맞춰야 한다. 이번에는 점수를 계산하지 않았다.

## 공유 사례는 어떻게 보이는가

> 의뢰 자료의 자유서술 항목을 구조화하고 필수 항목의 누락을 확인해주세요.

정보 구조화 관점에서5개, 대조검증 관점에서5개를 표시한다. `AXALL_US_OMB_2025_01754`는 두 관점에 모두 연결된다. 각 관점의 순위와 연결을 유지하되 실제 수행 업무·원문 상세는 한 번만 보존한다. **표시10개와 고유사례9개를 구분**한다.

## 이전 실제 LLM 응답을 재사용한 표시

> 사내 출장 규정의 한도 조항을 검색하고, 영수증에서 금액을 추출한 다음 규정 한도와 대조해주세요.

기존 LLM은 이 질문에서P01/P02/P03을 선택했다. 새 표시 구조에 연결하면 각3/5/5개, 표시 합계13개·고유사례12개가 된다. 이 응답은 예전 업무형 기준으로 생성됐으며 새 문제관점 판단의 검증 결과가 아니다.
