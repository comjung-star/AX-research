# 요청·제외 구분부터 채택 판단까지 — 3~6단계 완료

2026-11-09. **요청과 제외사항을 나눠 비교한 방식은 세 정답표 모두에서 기존 Dense보다 F1과 nDCG가 올랐다. 그러나 사전에 정한 불확실성 기준은 통과하지 못해 최종 채택은 보류한다.** 누락 정보 복원만으로는 개선되지 않았다. 이번 결과는 유망한 개발 개선 후보이며 논문의 최종 독립시험 성능은 아니다.

## 3. 질문에서 요청과 제외사항 구분

개발 질문20개의 원문 문장과 위치를 보존해 요청/제외/사람 승인 조건/배경으로 구분했다. 요청은20개 모두 인식했고 fallback은 사용하지 않았다. 명시 제외는18질문, 사람 승인 조건은2질문이었다. 한정된 언어 규칙으로 분리한 결과이며 사람이 독립 검증한 의미 정답이나 완전한 부정 해석은 아니다.

- VQ001: ‘결함 의심 위치를 표시하고 검사자가 확인할 목록을 만들고 싶습니다’가 포함된 문장은 요청으로, ‘AI가 불량 판정을 최종 확정하거나 설비를 자동 중지시키지는 않습니다’는 제외로 보존했다.
- VQ012: ‘안내만 제공하고 장비 제어 명령은 실행하지 않습니다’에서 안내 제공과 명령 미실행을 분리했다. ‘하거나’로 연결된 부정 대상은 함부로 나누지 않는다.
- VQ002/VQ013: 사람이 정비 또는 거래처 병합을 승인한다는 조건은, 정비/병합 작업이 무조건 무관하다는 판정과 구분했다.

요청 문장만으로 새 Task/행동/대상 표현을 만들고, 제외 문장은 요청 표현에서 뺐다. 제외와 사례Task의 유사도는 별도 학습 가능한 보조값으로 보존했으며 실제 위반 여부로 단정해 후보를 차단하지 않았다.

## 4. 채점 방식 구현 및 정보 복원

새 유료 호출 없이 저장된 BGE-M3 모델을 로컬에서 실행했다. 기존 모델 파일 해시를 대조하고 네트워크를 차단한 상태에서 새 필드 문자열154개를 계산했다. 이전 단계에서 복원한24사례와20질문 사이의 행동 cosine **480쌍을 실제로 계산**했다. 기존88사례×20질문의 원문 행동/대상 cosine **1,760쌍은 그대로 유지**했다.

다음 조건을 고정해 비교했다.

1. **기존 Dense:** 기존 검색 순위 그대로.
2. **직전 채점기:** 앞선 순위 감사에서 고정한 외부예측을 재사용하는 참고 대조.
3. **누락 복원:** 동일한 채점기 학습 절차에, 복원24사례의 행동/잔여 대상 점수만 갱신. 질문 표현은 기존 전체 질문을 유지.
4. **작업 비교:** 복원에 더해 요청만의 Task/행동/대상 비교 및 제외문장/요청 결과 단서의 보조 특성을 사용.

모든 새 채점기는 작은 pairwise ridge이며 동결 BGE를 추가 학습한 것은 아니다. 원문 Dense/토큰/BM25 특성은 기존값을 유지했다. 후보는 이미 고정한 Dense20/원문토큰보완20/관점보완20 각각이며, 후보 안에서만 순서를 바꿨다. 후보 예산20·출력5는 같지만 전체112사례 특성을 계산하므로 계산량까지 동일하다고 주장하지 않는다. 관점별 후보 출처는 기존trace에 보존되어 있으며 전체 교수 제안 모델의 대체 구현은 아니다.

### 해석이 아직 제한된 부분

사례112개 중 명시적인 output 필드가 있는 것은1개뿐이다. 질문의 원문 결과 단서(목록/출처/근거 등)는12질문에서 확인돼 명시 출력끼리 비교할 수 있는 것은12/2,240쌍뿐이다. 그 외에는 결과 단서와 사례Task의 유사도라는 **보조 대리값**을 사용하며 사례의 실제 산출물이 일치한다고 주장하지 않는다. 없는 산출물을 추정해 채우지 않았다.

요청만으로 다시 추출하면 VQ004/006/009/017의 행동 표현은 기존 어휘 규칙으로 인식되지 않아 **448쌍이 UNKNOWN**이다. 사례24개의 누락을 복원한 것과 질문 측 표현을 완전히 해석하는 것은 다른 문제다. 해당 결측은 존재 표시로 구분했으며 정답을 본 뒤 단어를 추가해 재실험하지 않았다. 대상 역시 잔여 문자열 기반의 얕은 추출이다. 요청 문장을 제대로 선택했다는 것과 그 안의 모든 의미 역할을 정확히 해석했다는 것은 구분해야 한다.

## 5. 질문을 나눠 비교·검증

앞선 감사와 같은5개 외부 질문 묶음(각4개)을 사용했다. 각 평가 질문은 해당 모델의 학습과 설정 선택에 들어가지 않는다. 외부16개 학습 질문 안에서12개 학습/4개 검증을 반복해 설정을 고른다. λ={0.1,1,10}, 학습점수비중={0,0.5,1}만 비교했고, 내부 Dense후보의 F1우선/nDCG차선 규칙을 고정했다. 학습 및 설정 선택은 working 정답표만 사용했고, 예측을 저장한 뒤 나머지 두 표로 평가했다.

|정답표|Dense nDCG@10|누락 복원 nDCG|작업 비교 nDCG|작업 비교−Dense F1 차이의95% 구간|

working에서F1이 좋아진 질문3개, 나빠진 질문1개, 동점12개였다. 양성이 없는4개는F1평균에서 제외했다. 평균차이는+0.04190이지만 질문 단위bootstrap10,000회의 구간은0을 포함한다. nDCG평균도 올랐으나working구간은−0.01011~+0.10101로0을 포함한다. original/scoped의nDCG구간은0을 제외하지만 개발 반복/선택/다중비교를 보정한 확증으로 다루지 않는다.

구체적 예시(판정은working, 아래 교체 사례는 반복1의 상위5개):

- VQ011(통화 중 상담 책임자 연결 요구 탐지): F1 0→0.33333. ‘RV 고객 문의의 상시 응대 및 상담원 인계’라는2점 사례가 들어왔다.

- VQ012(유지보수 매뉴얼 안내): F1은 반복 평균0.30769→0.20513으로 악화했다. 반복1에서는0점의 감사 자료 반려·재제출 안내문 작성 사례가 들어오고2점 사례가 빠졌다. ‘안내’ 같은 표면적 일치를 아직 완전히 피하지 못한다.

### 다중관점 고유의 효과와 구분

이번에는 단일질문의 후보 조건이 최종F1에서 더 높다. 따라서 Dense 대비 작업 비교의 개선을 **다중관점의 최종 추천 우위**로 보고할 수 없다. 후보Recall은 고정했으므로 이전과 같아, working은Dense0.65019/관점0.66668이다. 검색 단계에서 후보를 추가하는 효과와 최종5개의 순위 향상은 별개다.

### 이 검증으로 말할 수 있는 범위

이미 관찰한 개발20질문, 동일112사례DB로 수행한 분할 검증이다. 새 독립시험이 아니며 처음 보는 사례로의 일반화도 검증하지 않았다. 세 표는 같은 질문의 서로 다른AI Silver판정으로 독립실험 세 번이 아니다. scoped도 전체2,240쌍 중464쌍만 별도 판정을 반영한 부분 검토본이다. 무양성 질문의F1/nDCG는 제외했고P@5는 전체20질문으로 평균했다. 각 반복은 질문 내에서 평균했으며60반복을60개 독립질문으로 취급하지 않았다. 정답표는 변경하지 않았다.

## 6. 채택 판단

결과를 보고 바꾸지 않은 채택 기준은 세 정답표 모두Dense보다F1상승/nDCG비감소, 그리고working F1차이의 구간 하한>0이었다.

- **누락 복원만의 채택: 불가.** 추천 개선을 보이지 못했다. 추출의 문자열 처리 범위를 복원한 성과와 구분한다.
- **작업 비교 방식: 유망한 개발 후보로 저장하고 최종 채택은 보류.** 평균 지표의 방향은 세 표 모두 개선됐지만 구간 조건에 미달했고, 부분 검토본의F1증분도+0.00285로 작다.

새40질문과Test15를 사용하지 않고 유료API호출0회로 마쳤다. 새40질문도 과거에 결과를 봤으므로 나중에 재사용해도 미열람 최종시험이라 부르지 않는다. 이번 결과에 맞춰 단어나 가중치를 추가 탐색하지 않았다. 기존 운영 모델을 교체하지 않고 이번 방법과 예측을 고정 저장한다. 논문에서는 ‘요청/제외를 분리한 순위 채점의 개발 개선’과 ‘다중관점 후보 발견의 효과’를 각각 보고하는 것이 현실적이다.
