## 무엇을 고정하고 실행했나

앞서 보존한 `work-aligned-dev-v1-20261109`의 모델5개를 그대로 사용했다. 새 질문에 적용할 정책은 **각 모델 점수를 동일 가중치로 평균**하는 것으로 예측 생성 전에 기록했다. 새 학습이나 모델 선택은 없었다. 과거 외부폴드 예측은 질문별 모델1개의 결과였지만 이번에는 기존5모델을 결합하므로 그 두 수치를 완전히 같은 실험으로 비교하지 않는다.

질문40개, 사례112개, 기존관점·토큰·Dense점수를 재사용했다. 새 필드 문자열64개만 같은BGE-M3로 로컬 계산했다. 요청/제외 규칙과 가중치는 고치지 않았다. 원문Dense20, 원문토큰보완20, 원문BM25보완20, 관점보완20의 후보를 고정된 규칙으로 구성하고 같은 채점기로 정렬했다. 최종출력5개로 비교했다. 관점별 출처는trace에 보존했다. 기존E는 참고용 과거 결과로만 두었고 새 방법에는RRF를 사용하지 않았다.

관점은 기존3슬롯×3반복을 사용했으나 총360슬롯 중10개는기존MISSING이었다. 누락을 다시 생성하지 않고 유효한 관점만 사용했다. 후보예산은같지만 관점별 검색경로 및 전체112개 특성 계산 비용까지 동일한 것은 아니다.

모든840개 순위는 이번40질문의 판정 파일을 열지 않고 먼저 저장했다. 이후 기존Claude/Gemini의4,480쌍 판정을 각각 적용했다. 판정은 생성·수정하지 않았다. 반복3회는질문 내에서평균했다.

## 3. 추가40질문에서의 성능

### 공급자가 양성이라고 판정한 질문에서의F1@5

F1은 높을수록 좋다. 무양성 질문은F1에서제외하므로 **Claude12질문, Gemini38질문**으로평균 대상이 다르다. 이 표만 보고 두AI가 같은 질문들에서 개선을 확인했다고 해석하면 안 된다. P@5는양쪽모두전체40질문으로 계산했고 원본에 보존했다.

|판정 기준|F1평균 질문 수|기존Dense|작업비교+Dense후보|작업비교+토큰후보|작업비교+BM25후보|작업비교+관점후보|
|---|---:|---:|---:|---:|---:|---:|
|Claude|12|0.39215|**0.41973**|0.39195|0.39195|0.40121|
|Gemini|38|0.28387|**0.30472**|**0.30472**|**0.30472**|**0.30472**|

관점후보 조건의nDCG@10도Claude0.57681→0.59746, Gemini0.47476→0.51526으로올랐다. 하지만 다음 동일질문 비교와 불확실성을 함께 봐야 한다.

### 두AI 모두 양성이라고 본 동일12질문에서 비교

같은질문 집합이라는 뜻이며 사례별정답판정까지 합의했다는 뜻은 아니다.

|판정 기준|기존Dense F1|작업비교+Dense후보 F1|작업비교+관점후보 F1|관점조건−기존Dense F1차이95%구간|
|---|---:|---:|---:|---|
|Claude|0.39215|0.41973|0.40121|−0.08300~+0.09815|
|Gemini|**0.35915**|0.33657|0.33657|−0.09048~+0.03889|

Gemini의 전체 양성38질문 평균에서는 상승했지만, 공통12질문에서는 F1이 하락했다. 관점 조건의 공통12질문 nDCG는 Gemini0.55180→0.55347로 소폭 상승하지만, 단일Dense후보 조건은0.55127로 소폭 하락했다. 최종5개 정답 선택이 일관되게 좋아졌다는 결론은 낼 수 없다.

전체 양성질문 기준으로도 관점조건−Dense의 F1차이 구간은 Claude−0.08300~+0.09815, Gemini−0.01971~+0.06055로 모두0을 포함한다. 작업비교+Dense후보의 차이 구간도 Claude−0.07262~+0.13175, Gemini−0.01971~+0.06055로0을 포함한다. 질문 단위 bootstrap10,000회이며, 개발 선택/다중비교를 보정한 확증 통계는 아니다.

## 4. 다중관점의 역할을 따로 확인

### 최종5개 선택의 추가 이득

같은 채점기를 쓰면 관점후보는 Claude에서 Dense후보보다 F1이0.01852 낮고, Gemini에서는 양성38질문의 F1이 모든 후보 조건에서 동일했다. Claude차이는 나빠진 질문1개, 좋아진 질문0개에서 나왔고95%구간은−0.05556~0이었다. 토큰/BM25보완보다 Claude F1이0.00926 높지만 한 질문 차이이고 구간은0~+0.02778이다. 강한 단일질문 조건을 일관되게 이겼다고 말할 수 없다.

### 후보20개 안에 정답을 담은 비율 — Recall@20

각 공급자의 양성질문 집합에서 계산했다.

|판정 기준|Dense후보|토큰보완후보|BM25보완후보|관점보완후보|
|---|---:|---:|---:|---:|
|Claude|0.80648|0.78333|**0.80926**|0.79877|
|Gemini|0.61326|**0.66176**|0.62229|0.61855|

- Claude기준 관점보완은 Dense대비 새 양성 질문–사례쌍1개를 추가했지만2개가 빠졌다.
- Gemini기준12개를 추가했지만7개가 빠졌다.
- 토큰/BM25 두 보완 방식에 모두 없는 양성쌍은 Claude1개/Gemini2개였다.

위 수치는 반복을 중복 집계하지 않은 질문–사례쌍 수이며 독립질문 수나 순수 최종정답 증가 수가 아니다. 일부 후보 추가 가능성은 관측되지만, Gemini에서는 토큰보완후보의 Recall이 관점보다 높고 Claude에서는 관점이 Dense보다 낮다. **개발20질문에서 본 후보Recall이득을 새40개 전체에 일반화할 수 없다.**

## 이번에 드러난 적용 범위의 한계

원문 요청을 직접 인식하지 못해 배경문장을 대체 사용한 질문은8개(IVQ003/008/010/012/016/017/018/028), 요청 행동필드가 빈 질문은15개였다. 이 결과를 보고 규칙을 보완하거나 다시 예측하지 않았다.

- IVQ003의 ‘계획안이 필요합니다’, IVQ008의 ‘운영 규칙이 필요합니다’는 현재 요청 패턴으로 인식되지 않아 fallback으로 처리됐다.
- IVQ001의 ‘후보 요인 목록이어야 하며, 원인을 단정하지는 않아야 합니다’는 긍정 요구와 제외사항이 같은 문장에 있는데 현재 규칙이 문장 전체를 제외로 분류했다. 원하는 결과 요구 일부까지 빠지는 구체적인 한계다.

따라서 개발20질문의 문장 형식에 잘 맞았던 분리 규칙이 더 다양한 표현에서도 안정적이라고 볼 수 없다. 이것이 이번 모든 성능 변화의 원인임을 인과적으로 입증한 것은 아니다.

Claude와 Gemini는 전체4,480쌍 중4,138쌍에서 양성/음성 판정이 일치했고342쌍은 불일치했다. 불일치를 음성으로 만들거나 새Gold로 합치지 않았다. 두 공급자는 사람의 정답이 아니며 질문 작성자와 한 판정자가 Anthropic계열이라는 한계도 있다.

## 최종 정리와 종료 범위

현재 방법을 다른40질문에 그대로 적용한3단계와, 다중관점의 역할을 분리한4단계를 완료했다. **작업 비교의 개발 개선 가능성은 남지만 이번 추가 자료에서 일관된 우위를 확인하지 못했고, 다중관점의 최종 추천 추가 이득도 확인하지 못했다.** 기존 운영 모델 교체와 논문 최종 성공 주장은 보류한다.

이40개는 과거 결과를 본 AI작성 질문이므로 재사용 추가 확인이다. 새 독립 최종시험이 아니며 사람이 제출한 실제 업무질문이나 인간Gold도 아니다. 새 학습0회/유료API호출0회/정답 변경0회이며 Test15에는 접근하지 않았다. 다음5단계의 미열람 최종시험은 진행하지 않았다.
