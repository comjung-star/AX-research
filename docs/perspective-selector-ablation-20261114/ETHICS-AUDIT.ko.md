# 평가자 정보·연구윤리 증거 검수 (2026-11-14)

## 증거가 확인된 것
- 제출된 평가자 1·2 Excel 자료는 동일한 A/B 차집합 152개 질문-사례 쌍을 담고 있고, 각각 152개 점수와 판단 사유가 기록되어 있다.
- 안내문에 두 평가자 사이의 상의 금지, AI 기존 점수와 A/B 소속을 보지 말 것, 공통 0~3점 평가 기준이 명시되어 있다. 설계와 실제 행동은 구분한다.
- 두 제출 파일의 출처 원문 확인 상태는 총 304개 입력에서 모두 **미확인**이다. 나중에 14개 고유 사례/11개 출처 URL을 대조한 연구자 검수는 평가자 원문 열람이 아니다.
- 동일 U에서 차집합 상대 Precision 차이는 계산 가능하지만, 공통 추천 178개가 빠져 인간 기준 절대 Precision, Recall, F1은 계산할 수 없다.
- 모든 최초 평가 점수·판단 근거는 보존했고, 재채점하거나 합의 Gold로 바꾸지 않았다.

## 별도 증명 없이는 확정할 수 없는 것
- 평가를 실제 수행한 2인의 신원, 전문성과 소속/역할, 실제 평가 기간.
- 서로 상의하지 않았는지, AI/추천 방식의 정답을 실제로 보지 않았는지, 사용한 AI 지원 도구가 있는지.
- 사전 연구 참여 설명·동의의 실제 존재, 익명화된 점수 및 평가 이유 공개 동의.
- 기관/공용 IRB의 실제 적용·심의·면제 여부.
- 저자 확정, 공저자 기여 4요건 및 특수관계인 여부, 라이선스 확인.

## 공개 가능한 연구 방법
- OpenAI `gpt-5.4`: 합성 질문 생성, 역할 선택, 112사례×20질문 관련도 평가(2,240쌍).
- Anthropic `claude-sonnet-5-5`: A/B 차집합 152쌍 교차판정.
- ChatGPT: 분석·문서화·코드·원고 초안 작성 보조. 세부 대화별 실행모델 버전 미기록.
- 모델 판단과 사람이 직접 만든 정답 및 인간 저자의 책임을 구분한다.

## 원고 수정 요약
- 현행 원고 v0.6의 Ⅳ.5에서 실제 상호 독립성·전문성을 입증한 듯한 표현을 제거.
- Ⅳ.8에 블라인드 디자인과 실제 수행 증빙의 차이, 모델/AI 도구 역할 공개, IRB 판단 보류, 보안 보관 원칙을 추가.
- 국/영문 초록, 관련연구, 논의, 결론의 인간 평가 확정 표현 수정. 기존 통계/원점수 보존.
- 개인정보·서명/사실확인서 및 작성완료 엑셀은 **저장소에 업로드하지 않는다.** 대화 첨부된 검수 보고서 및 빈 양식은 별도 배포.

## 투고 전 외부 확인
1. 평가자 각각에게 사후 사실확인(전문성·기간·실제 독립성·AI 사용·익명 이용 동의); 소급 동의서/심의 승인으로 가장하지 말 것.
2. 기관 IRB 담당자에게 해당 검증의 심의/면제 적용 여부 확인; 관련 절차에 따라 처리.
3. 인간 저자 기여, 연구윤리 동의, 원출처/참고문헌 검수.
4. 그 결과에 따라 원고 문구 갱신 후 제출.

**상태:** 텍스트·증거 기반 검수 완료. 인적 사실, 동의, IRB 판단은 **확인 전**이며 완료나 승인으로 표시하지 않는다.
