## 쉽게 요약

1. **기존 B와 사례풀만 활용한 통제군이 거의 같다.** B−풀의 F1 차이는 +0.13%p이고 95% 질문 부트스트랩 구간은 -2.38%p ~ +2.25%p. **기존 B의 전체 향상을 관점 선택만의 효과로 귀속하면 안 된다.**
2. **관점 역할 선택을 고정 PTC 점수로 비교하면 무작위 관점보다 높다.** 선택−무작위 F1 +3.49%p, 95% 구간 +2.05%p ~ +4.90%p. 다만 이는 원본 B의 Task 분기 점수가 아닌 **보조 통제실험**이고, 선택과 채점이 같은 계열 LLM이므로 일반화/인과 효과의 독립 입증은 아니다.
3. **사례풀만 갖춰도 A보다 많이 개선**됐다: 풀−A F1 +5.02%p. 이는 사례의 사전 구조화/연결 자체가 중요한 설계 요인일 수 있음을 시사한다.

## 해석 시 중요한 제한

- **POOL_ONLY_PTC는 사전에 검토한 49개를 고른다.** 이는 검색 시스템에 수작업 지식/사례 연결을 추가한 효과를 포함한다. 성능 개선을 순수한 자동 관점 선택에 귀속시키지 말아야 한다.
- **선택관점−무작위관점**은 카드의 수와 미리 연결한 사례풀이 동일하고 PTC 점수를 공통 사용하므로 역할 선택의 **조건부 효과를 더 가깝게 통제**하지만, 원래 B에서는 별도 질문+카드 정의를 Task와 비교했으므로 원본 B의 순수 기여는 이 실험만으로 확정되지 않는다.
- 모든 관점을 선택하지 않은 4개 질문(VQ017~020)은 비교에 그대로 포함했다. 추가 관점/미선정 사례 정보의 부재도 원래대로 유지했다.
- 인간 152쌍 교차검증은 A/B에만 해당하며 새 풀 통제군에는 인간 정답이 없다. 새 통제군에 사람 평가의 신뢰도를 전가하지 않는다.
- 개선 여부에 맞춰 모델·정답·질문·관점 라벨·랭킹·사례 목록을 수정하지 않았다. 유료 API 요청도 없다.
