# 관점 선택 vs. 사전 연결 사례풀 기여 분리 — 동결 프로토콜 (2026-11-14)

## 연구 질문
관점을 선택해 추천하는 기존 B의 개선은, 이미 만들어 둔 49개 사례/53개 관점 연결을 활용했기 때문인가? 관점 자체를 문제에 맞게 선택하는 행위의 별도 이득이 있는가?

## 고정 입력
- 코드/자료 기준 커밋: `f76fb69e9684be0b7f537d22cb430b7e44dfd937`.
- 이미 채점된 VQ001–VQ020 **전체** 20개 질문 및 각각 112개 사례의 동일 OpenAI 0~3점 평가표; 사람 평가를 새 대조군 정답으로 전용하지 않음.
- 검증용 20문항은 기존 방법 선택에도 사용되었으므로 진정한 미사용 최종 테스트가 아님.
- 원본 `docs/perspective-omission-validation20-20261110/rankings.json`, `labels.json`.
- 동결된 `docs/perspective-panels-full112-20261109/stage4/catalog-expanded.json` 의 4개 고정 관점, 승인 사례연결.
- 유용 판정은 **2점 이상**. 모두 동일한 질문별 U (A/B/C 원래 동일한 고유 사례 수). 기본 5건 필수 유지, 중복 ID 제거. 제외 조건·채점 기준 및 데이터 변경 금지.

## 네 가지 주요 방법
1. **A_BASE**: 원본 A, 전체 112개 중 P/T/C 평균 코사인 순위 Top-U.
2. **B_MAIN_ORIGINAL**: 원본 B, 기본 5개 + 선택 MAIN 관점의 개별 Task branch Top-5 + 부족분 P/T/C 기본검색 충전. 기존 코드·결과를 그대로 재현.
3. **POOL_ONLY_PTC**: 기본 5개 + **관점 선택 없이**, 4개 관점에 연결된 모든 승인 사례의 합집합 중 원 질문의 저장된 P/T/C 코사인 상위 사례로 U개 충족, 필요 시 기본 순위로 충전. 이 통제는 **동일한 49개 사례 풀에 대한 접근만** 제공하지만 관점별 Task 질의·점수 재정렬은 하지 않는다.
4. **SELECTED_CARD_PTC**: 기본 5개 + 실제 MAIN 관점의 각 연결 사례에서 원 질문의 저장된 P/T/C 점수로 상위 5개씩 수집한 뒤 중복을 제거하고 부족분 기본 순위로 충전. 원본 B와 달리 별도 Task-query 점수를 사용하지 않으므로 **역할 선택 자체**를 보조적으로 검증하기 위한 분리 조건이다.
5. **RANDOM_CARD_PTC**: 각 질문에서 MAIN으로 선택된 관점 **수 m**과 같은 개수의 관점을 4개 중 선택하는 가능한 **모든 조합**에 대해 4번과 같은 P/T/C-기반 검색을 실시. 질문당 모든 조합을 균등 평균한 성능으로 우연한 카드 선택과 비교. m=0 또는 m=4일 때 비교는 정보가 없음.

모든 조건의 U는 원래 실험에서 정한 수로 유지하고, 후보가 부족하면 동일 A_BASE 순서로 충전. 각 관점에서 연결 사례는 최대 5개 사용. 출처 중복의 영향을 별도로 기술한다.

## 평가지표와 비교
- 질문별 Precision, Recall, F1; **macro 평균** 20개 질문 모두 포함(원본과 동일). 보조: 질문별 win/tie/loss, 새 유용사례/놓친 유용사례 수, 인출수 검산.
- B_MAIN_ORIGINAL - A_BASE: 이전 성능 검산.
- B_MAIN_ORIGINAL - POOL_ONLY_PTC: **사전 사례풀에 접근한 것만으로 설명할 수 없는 결합 효과** (역할 선택+branch Task 점수 등이 함께 바뀌므로 '순수 관점 선택 효과'라 부르지 않음).
- SELECTED_CARD_PTC - RANDOM_CARD_PTC: P/T/C 점수, 풀, 카드 수, U를 고정한 **관점 선택의 조건부 효과**. 선택자와 평가자가 같은 계열의 LLM이므로 외부 일반화 주장 금지.
- PTC 관점선택 조건과 원본 B의 차이는 task-branch/합집합 구성 차이가 있으므로 추가적 진단값이며 단일 요인의 인과 효과 아님.

## 통계/정직성
- 질문이 20개뿐이고 합성 질문/LLM 채점/사례-출처 중복이므로 신뢰구간과 유의확률을 모집단 인과 효과로 해석하지 않는다.
- 카드 조합 무작위 대조는 가능한 4개 관점의 조합 **전수열거**로 계산, Monte Carlo 샘플링 없음.
- 결과 확인 후 조건·기준 변경 및 유리한 질문 제외 금지. **음수 또는 동률 결과도 모두 기록**.
- 유료 API·모델 재학습·사례 추가·원본 데이터 변경 없음. 사전 승인 없이 main 병합하지 않고 신규 연구 브랜치에 코드·보고서·결과 저장.
