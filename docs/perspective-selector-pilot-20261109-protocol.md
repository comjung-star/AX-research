# 시범 관점 선택기 — 4단계 범위와 검증 기준

대상은검토된P01~P04카드만이다. 사용자승인4단계로질문의요청/대상/조건을대조해선택하고근거문장을남긴다. 신규관점생성·사례추천·순위채점·새학습은하지않는다. 기존17개후보전부가사용가능한것처럼보이지않게하고기존시범목록과모델을보존한다.

유료API없이규칙/조건대조로구현하는보수적기능시제품이다. 자유로운자연어의의미를완전히이해하는모델이아니다. P01은기존문서/지식탐색, P02는문서/자료항목추출·구조화, P03은업무기록과기준·다른자료대조, P04는문의응대와용량·시간대공백이라는각각의근거가함께필요하다. 같은업종/문서/상담단어만으로선택하지않는다.

질문이원하는작업의명시적근거가있으면그작업과관련된카드를선택할수있지만, 카드이름의‘지연/부담’까지질문의사실로추정하지않는다. 요청한기능과실제로서술한문제는구별해표시한다. 긍정요청/금지/사람승인/과거설명을구분하고, 부분적모호성이나상충지시는보류한다. 제외사항과수정·실행요구는후속사례검토에서확인해야할조건으로보존한다.

출력은선택된관점·선택근거·보류관점·제외관점·미지원요구·질문제약이다. 사례ID나순위는반환하지않는다. 0개선택도정상이다. 네관점밖의예측·번역·영상검사등은지원하지않는요구로표시하며기존17후보의미검토관점을자동승격하지않는다. 미지원과판단불가를구분한다.

별도로작성한합성기능검사로표현변화, 복수선택, 비선택, 금지, 과거설명, 수정제한, 이미지/문서혼동, 기준누락을확인한다. 기대결과는assistant작성개발검사로사람Gold/독립시험/정확도인증이아니다. 실패하면기능버그를수정하되추천점수에맞춰고르지않는다. 검사통과후소스/규칙/검사/카드해시와실행결과를보존하고종료한다. 실제질문평가와5단계사례추천은이번범위밖이다.
