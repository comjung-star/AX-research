# Dense 보존형 후보 보완 실험 사전 계획

새 AI40질문은 수정안 선택에 사용하지 않는다. 기존 신규20개발 질문과 보존된 검색/토큰 점수만 사용한다. 유료 API, 새 질문 생성, 정답 변경은 없다. 아래의 실험 설정은 교수 확정 사양이 아닌 검증할 구현 선택이다.

같은Top5 안에 Dense의5개를 전부 유지하면서 새 사례를 넣는 것은 불가능하다. 이번에는 Dense 상위3개의 ID와 순서를 고정하고4·5위 두 자리만 교체할 수 있게 한다. 따라서 보장되는 것은 상위3개 보존이며 Dense가 맞힌 모든 정답의 보존은 아니다.

세 조건을 사전 고정한다. (1) Dense 원문 순서, (2) DenseTop20 후보에서 원문 Dense/원문 Task토큰의 기존50:50 정규화 점수로 보완, (3) DenseTop10에 관점별 Dense 검색에서 고유 후보를 순환 추가해20개를 채운 뒤 같은 원문 점수로 보완. 부족한 후보 자리는 Dense에서 채운다. 관점별 순위를 별도 유지하고 출처를 남긴다. 관점 점수·규칙의 최대값으로 최종 순위를 올리지 않는다. RRF를 새 모델로 사용하지 않는다.

추가 후보는 원문의 정규화 토큰 점수와 원문 Hybrid 점수가 원래Dense4·5위의 최솟값을 각각 엄격히 초과해야 한다. 최종Top5는 보호된3개와 후보 중 원문Hybrid가 높은2개다. 원래4·5위는 항상 선택 가능하게 남긴다. 다음15자리는 동일 후보20안의 원문Hybrid 순서, 그 밖의 사례는 원래Dense 순서를 유지한다. 원문만의 조건과 관점 조건의 후보/출력 예산을 각각20/5로 맞추지만, 관점 생성·검색의 추가 계산비용이 같다고 주장하지 않는다.

기존 작업용 정답을 주 분석, 최초 정답과464쌍 합의 반영을 민감도로 유지한다. 모든 조건은 같은 정답·질문 집합에서 F1@5/nDCG@10/Recall@20/P@5를 비교한다. 질문 내3회 평균 뒤 질문 단위 재표집을 한다. 추가로 DenseTop5대비 새 양성 진입·양성 이탈·음성 진입과 후보Recall을 모두 기록한다. 관점의 이득은 원문토큰 조건 대비 차이로 판정하며 새 사례를 찾은 것과 최종Top5에 올린 것을 구분한다. 예측은 정답 파일을 열기 전에 저장한다.

이 실험은 이미 여러 번 검토한 개발 자료의 원인·구현 비교다. 좋은 결과만 고르거나 같은 질문의 반복을 독립 표본으로 늘리지 않는다. 평균이 높아도 확정 일반화/새 Test 성능으로 표시하지 않는다. 실패도 보존하고 보호 개수/가중치/문턱값의 무한 탐색은 하지 않는다.
