# 시범 관점 선택기 — 4단계 완료

2026-11-09. **사용자 질문에서 근거를 찾아 기존 네 관점을 선택하는 기능을 구현했다. 선택0개·복수선택·판단보류·일부지원·지원범위밖을 구분하고, 선택 근거와 금지/승인 조건을 보존한다.** 사례를 추천하거나 순위를 계산하는5단계는 진행하지 않았다.

버전은 `pilot-perspective-selector-v1.1-20261109`다. 외부AI나임베딩을새로호출하지않고, 시범목록에명시한작업·대상·조건을규칙으로대조하는보수적인시제품이다. 자유로운자연어를완전히이해하는모델이나실사용정확도가검증된서비스는아니다.

## 무엇을 선택하는가

아래네카드만선택가능하다. 나머지13개관점후보를자동으로사용가능한카드로승격하지않는다.

|ID|시범 관점|선택에 필요한 근거|
|---|---|---|
|P01|업무 지식 탐색 지연|기존문서·지식이라는대상과검색·참조요청|
|P02|비정형 정보 정리 부담|문서·자료라는대상과항목추출·구조화·관련분류요청|
|P03|자료 대조·검증 부담|업무기록·문서라는대상, 대조작업과기준·다른자료의근거|
|P04|응대용량·시간대 공백|문의응대와대기·용량·시간대문제의근거|

질문이‘금액을추출해달라’고만해도P02의작업범위를선택할수있지만, 그사람이실제로시간부담을겪었다고추정하지않는다. 카드이름의문제설명과질문원문에서확인한내용을구분해기록한다. 카드에지원연결이없으면선택하지않으며보류연결을근거로사용하지않는다.

## 실제 실행 예시

아래는기능검사용으로작성한질문에대한실제출력이다. 실제사용자정답이나추천성능평가자료는아니다.

|입력|선택/상태|이유|
|---|---|---|
|청구서에서금액을뽑고, 계약금액과다른항목을찾아주세요.|**P02+P03**|항목추출과계약대조라는서로다른작업이명시됨|
|출장기준을설명한사내규정을찾아주세요.|**P01**|기존규정의정보탐색요청|
|야간문의가누락됩니다. 고객문의에응대하고싶습니다.|**P04**|시간대공백과실제응대요구가함께있음|
|다음달상품수요를예측해주세요.|**시범지원범위밖**|예측은현재상세검토한네카드에없음|
|문서처리를잘하고싶습니다.|**판단보류**|검색·추출·검증중어떤작업인지불명확|
|청구서내용이맞는지검증해주세요.|**P03보류**|무엇과대조하는지기준이없음|
|항목을추출하지마세요. 이미있는금액을계약과대조해주세요.|**P03만선택**|P02작업은명시적으로금지됨|
|청구서금액을계약과대조하고자동수정해주세요.|**P03·일부만지원**|대조관점은맞지만실제자동수정은별도기능·권한확인이필요|

같은업종만으로선택하지않는예도검사했다. 고객문의가많아도사용자가이번에원하는것이‘상담대화록요약’이면P04의문의응대작업으로바꾸지않았다. 과거에하던문서검색을현재의요청으로선택하지않는검사와, ‘과거주문기록’을현재비교하는요청을잘못버리지않는검사도포함했다.

전체11개실행예시와원문근거·보존제약은 [읽기용 예시](examples.ko.md), 전체구조는 [예시 원본](examples.json)에서확인할수있다.

## 출력에 남기는 내용

- **선택한관점:** 관점ID·이름, 맞는작업, 원문작업·대상·조건의인용과위치.
- **판단보류:** 부족한대상/대조기준/문제근거, 긍정과금지가상충하는범위.
- **선택하지않은관점:** 근거부족·범위불일치·사용자금지이유.
- **미지원요구:** 예측·번역·요약·물리검사·자동실행등네카드와별도로검토해야할요구.
- **보존제약:** 금지한작업과사람승인조건. 카드의적용조건·미확인부분도후속검토용으로유지.

지원연결의‘개수’는카드의근거목록정보일뿐, 그사례들이이번질문에모두적합하다는뜻이아니다. **사례ID·추천목록·순위는반환하지않는다.** 예를들어P04가선택돼도모든연결사례가야간응대를지원하는지는5단계에서따로대조해야한다.

## 어떻게 검증했나

assistant가작성한합성개발검사33개를실행했다. 검색·추출·대조·응대의표현변화4묶음에서선택결과가유지됐고, 복수선택·비선택·보류·부분지원·금지·과거설명·승인조건·물리제품과문서의혼동을확인했다. 모든출력근거의문자열과위치도입력원문에대조했다.

|합성검사에서의 출력 상태|건수|
|---|---:|
|선택근거확인|19|
|일부만지원|2|
|판단보류|5|
|시범지원범위밖|7|

모두검사용기대결과를충족했다. **이를실제질문선택정확도100%라고해석하면안된다.** 검사와규칙의작성자가같고표현범위도제한돼있다. 실제사용자질문이나독립평가에대한일반화검증은하지않았다.

별도회귀검사11개도통과했다. 보류연결의근거사용금지, 원래관점목록의비변경, 잘못된목록버전/빈입력거부, 선택에작업·대상근거필수, 사용자진술에없는문제부담추정금지를확인했다.

개발중명확한다른관점이선택됐는데도‘찾기’나‘누락’단어만보고관련없는관점을추가보류하는경고를발견했다. 이경우에는해당관점의대상근거도필요하도록수정했다. 예를들어금액대조의‘다른항목찾기’를문서검색으로보류하거나, 야간문의‘누락’을문서검증으로보류하지않게했다. 초기출력은기존초안폴더에보존하고현재v1.1과구분했다. 이수정에추천점수나정답표를사용하지않았다.
