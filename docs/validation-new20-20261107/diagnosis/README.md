# 신규 20문항 AX 추천 실패 원인 분석

- 분석 기준: 2026-11-08, 기존 신규 Validation 20문항 / 112개 사례 / AI 잠정 채점 2,240쌍.
- **이번 작업은 분석만 수행했다. 모델·기존 검색 코어·112개 사례·정답·기존 독립 Test는 수정하지 않았다.**
- 실제 BGE-M3를 다시 실행해 Dense / BM25 / Dense+BM25(RRF) / 기존 C0 / 기존 A(C1)를 재현했다. **A의 20개 전체 순위가 이전에 봉인한 A와 정확히 일치**했다.
- 모든 수치는 추천 순위와 모델 이름을 가린 **단일 AI의 잠정 정답** 기준이다. 전문가 검증 정답이 아니며, 별도 독립 Test 성능이 아니다.

## 1. 한 줄 결론

**가장 먼저 고칠 곳은 BM25 검색 색인과 검색 결과 결합 과정이다.** 그다음으로 **정밀 기능 매핑에서 관련 사례가 뒤로 밀리는 현상**을 확인하고, **AI 채점의 애매한 정답**을 독립 검토해야 한다.

## 2. 어느 단계에서 점수가 떨어졌나?

F1@5는 상위 5개 추천의 적중률과 관련 사례 발견율을 종합한 점수다. 20문항 중 AI가 관련 사례를 1개 이상 판정한 **17문항**을 공통 기준으로 계산했다.

| 실제 계산 단계 | F1@5 | nDCG@10 | 관찰 |
|---|---:|---:|---|
| **Dense 단독** | **25.81%** | **46.94%** | 이번 잠정 평가에서 최고 점수 |
| BM25 단독 | 4.52% | 20.30% | 매우 낮음 |
| Dense + BM25, 동일 RRF(k=60) | 14.63% | 35.35% | Dense 결과가 크게 약해짐 |
| 원문 검색에 기존 C0 결합·매핑 | 17.88% | 43.02% | F1은 Dense보다 낮음 |
| 원문 검색 A(C1 보정 포함) | 24.08% | 43.42% | 일부 순위를 복구 |
| **기존 E** (원문+관점 3회 평균) | 23.72% | 42.39% | Dense보다 관찰 점수 낮음 |

- Dense−E 차이: F1 **+2.09%p**, nDCG **+4.55%p**. 질문별 탐색적 bootstrap 95% 구간은 각각 **[−8.84, +12.88]%p**, **[−9.89, +19.60]%p**로 0을 포함한다. 따라서 *Dense가 항상 더 우수하다고 입증된 것은 아니다.*
- BM25−E F1 차이: **−19.21%p**, 탐색적 95% 구간 **[−28.12, −10.57]%p**. 이 특정 색인·데이터 조건의 BM25 문제를 우선 진단할 근거는 충분하다.

## 3. 원인 A: BM25에서 영어 사례의 단어가 삭제됨

기존 `src/ax_research/retrieval/bm25.py` 코드:

```python
if not form or token.tag.startswith("S"):
    continue
```

이 조건은 구두점뿐 아니라 **영어 단어 태그 SL**과 **숫자 태그 SN**까지 버린다. Kiwi 공식 품사 태그 설명: https://bab2min.github.io/kiwipiepy/

고정 BM25 통계를 실제 점검한 결과:

- **112개 중 68개 사례의 BM25 문서 길이가 0.** 즉, 이 문서들은 단어 기반 BM25로는 내용에 맞춰 검색 점수를 얻을 수 없다.
- 112개 `Task` 가운데 **74개가 영어 위주**였고, 그중 **68개가 빈 BM25 색인**이었다. 나머지 일부 영문 Task 사례는 다른 한국어 텍스트에서 색인 단어가 남았다.
- AI가 관련으로 판정한 **89개 질문·사례 쌍 중 47쌍**이 BM25 문서 길이 0에 해당한다.
- 저장된 색인 IDF 단어에는 영어 알파벳 토큰이 **0개**였다.
- 따라서 Dense가 찾은 영어 사례를 BM25가 제대로 보완하지 못하고, 기존 50:50 Dense+BM25 RRF 결합에서도 불리한 순위 신호가 섞일 수 있다.

**주의:** 68개 사례가 전체 추천 후보에서 삭제된 것은 아니다. 전체 112개는 Dense 검색에 그대로 포함됐으며, **BM25 색인에서만** 단어가 비어 있다는 의미다. 또한 SL을 되살리는 것만으로 한국어 질문과 영어 문서의 언어 차이가 자동 해결되지는 않는다.

## 4. 원인 B: 좋은 후보가 순위 조정에서 뒤로 밀림

| 새 질문 | AI 잠정 관련 사례 수 | 초기 Dense 상위 5개 적중 | Dense+BM25 상위 5개 적중 | 최종 E 상위 5개 적중 | 판단 |
|---|---:|---:|---:|---:|---|
| VQ001 제조 제품사진 결함 탐지 | 10 | **3** | 1 | **0** | Dense가 찾은 사례를 후속 결합·매핑 단계에서 잃음 |
| VQ004 관리자 접근·권한 이상 탐지 | 1 | **1** | 1 | **0** | 관련 판정 사례가 RRF **2위 → A 52위 → E 약 51위** |
| VQ006 공급업체 납품 지연 예측 | 5 | 0 | 0 | 0 | 처음부터 상위권 후보 부족 + 의미가 먼 유사 예측 사례의 정답 판정 점검 필요 |
| VQ015 배송 차량 운행 순서 추천 | 1 | 0 | 0 | 0 | 관련 판정 사례 자체가 버그 티켓 라우팅이어서 정답 재검토 우선 |
| VQ019 문서 개인정보 탐지 | 1 | **1** | 0 | 0 | Dense 이후 후보 밀림 + 이미지 익명화 사례의 정답 판정 재검토 |
| VQ020 민원 관할 부서 배정 | 3 | 0 | 0 | 0 | 초기·후속 검색이 상위에서 모두 놓침; 일부 정답 경계 불명확 |

추가 관찰:
- 최종 E의 상위 5개에 새로 들어온 결과 가운데 **기존 A 순위가 20위 밖이었던 항목은 총 13개**(20문항 × 반복 3회의 합). 단일 AI 판정 기준으로 **13개 모두 관련도 0점**이었다.
- E와 A는 상위 5개 중 평균 **4.12개**, E와 C는 **4.05개**가 동일했다. 따라서 서로 유사한 결과를 75:25로 다시 합쳐도 효과가 제한적이었다.
- 기존 E 대비 I2·I3 각각 60회 비교에서 상위 5개 정답 개수가 바뀐 것은 **각 2회뿐**이었다. VQ002에는 개선, VQ007에는 악화가 발생하여 전체 F1 개선으로 이어지지 않았다.

## 5. 원인 C: AI 정답 판정에 재검토할 사례가 있음

AI가 등급 2(실질적 기능 전이)로 채점했지만 실제 수행 기능 차이가 커서, **정답을 바로 변경하기보다는 독립 검증이 필요한 사례**:

| 질문 | 관련 있다고 판정한 사례 | 검토 이유 |
|---|---|---|
| VQ015 배송 차량 경로 추천 | 소프트웨어 버그 티켓 담당팀 라우팅 | 차량 경로·운행 순서와 티켓 담당팀 분배는 핵심 목적과 대상이 다름 |
| VQ019 문서에서 개인정보 탐지·마스킹 후보 | 공장 이미지 속 사람 익명화 | 이미지 내 인물 비식별화와 문서 내 주민번호·주소 탐지 기능이 다름 |
| VQ020 민원 관할 부서 분류 | 채용 지원서 심사 | 지원자 심사와 민원 관할 분류가 실제로 같은 기능인지 불명확 |

현재 관련 사례 89쌍 중 직접 기능 일치(등급 3)는 **6쌍**뿐이며 나머지 **83쌍은 등급 2**다. 따라서 전이 가능성을 판단한 AI의 기준을 독립 검토해야 한다.

**관련 사례 0개**로 평가된 질문도 3개(VQ005 문서 버전 차이, VQ010 회귀 테스트 추천, VQ013 거래처 중복 식별)다. 이것이 실제 데이터 부족인지 평가 기준의 문제인지는 아직 단정할 수 없다.

## 6. 다음 실험 우선순위 — 현재 분석 이후 제안

1. **BM25 색인 결함 수정안을 별도 개발 브랜치에서 시험한다.** 구두점만 제외하도록 토크나이저를 교정한 뒤, 영문 `SL`·숫자 `SN` 토큰과 색인 길이가 정상인지 확인한다. 그다음 한국어 질문과 영어 사례 간 매칭을 처리할 언어 정규화/번역 색인 여부를 **별도의 통제 실험**으로 검토한다.
2. **Dense 단독 vs 수정 BM25 vs 수정 Hybrid**를 개발 자료에서 같은 정답·같은 사례·같은 Top-K로 비교한다. F1뿐 아니라 nDCG, Recall을 함께 기록한다.
3. **기능 매핑·관점 합성의 강한 가산/승격 기준을 진단한다.** VQ001/VQ004처럼 초기에는 보이던 관련 사례가 뒤로 밀리는 단계별 점수와 실제 수행된 Task 증거를 대조한다.
4. **AI 채점 오류 의심 사례를 추천 결과를 가리고 다른 평가 모델로 재확인한다.** 원본 판정·근거는 보존한다.
5. 현재 20문항은 원인 분석에 사용했으므로, 이 자료에 맞춰 수정한 모델의 **최종 일반화 성능을 여기서 다시 주장하지 않는다.** 알고리즘을 확정한 이후 별도의 미사용 독립 Test로 검증한다.
