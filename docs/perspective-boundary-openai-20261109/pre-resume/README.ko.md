# OpenAI 단독 경계 판단 실험

**현재 상태: OpenAI API 잔액 소진 오류로 전체 평가 미완료, 추가 호출 중단.** 실행 중인 요청은0건이다. 새 질문의 수정전/후 선택16건은 모두 완료됐다. 전체112개 채점은5/8질문 완료, BQ005는84/112개, BQ007/008은미착수다. 누락된9개 배치의 입력을 보존했다. [부분 결과와 오류 분석](RESULTS.ko.md)에 전체 수치와 한계를 기록했다.

완료5개 평균F1은 수정전37.2%, 수정후36.9%이며 전체8개 결과를 뜻하지 않는다. 추가된 유용사례0개, 놓친 유용사례1개, 제외된 덜유용한 사례4개다. 새질문의 범위밖2개에서 억지 관점 선택은 멈췄지만 실제 관련성 채점은 잔액 오류로 못했다. 개선 검증 완료라고 주장하지 않는다.

이번에는 OpenAI만 호출한다. 이전 오류 FQ007/FQ008은 OpenAI가 정상 완료한 응답에서 발생한 의미 오류다. Claude/Gemini의 호출 제한은 교차 평가 누락을 일으켰다. 출력한도에 걸린 FQ006의 별도 기술 오류와도 구분한다. 증거는 `api-vs-logic.json`이다.

수정은 포함·제외 기준 전달과 업무/자료요청 구분으로 제한한다. 사례 자체의 분류 기준을 사용자 질문의 동일 단어 요구로 오해하지 않도록 개발 단계에서 설명을 명확히 했다. 기존8개 개발 확인과 추가2개 확인을 보존하며, 새 질문 평가와 구분한다.

방법 고정 후 새 합성 질문8개를 작성했고, 수정전/후 각각8개 모두 형식·인용 계약에 통과했다. 새 질문의 예지보전·수요예측에 대해 수정전은 관점을 선택했으나 수정후는 선택하지 않았다. 이것을 사례 검색의 성공으로 세지 않는다. 다른 질문 하나도 관점 수가 줄어 실제 유용한 사례의 손실 여부를 확인한다.

검색 결과 저장·일부 채점·완료 부분 수치 계산·16개 패널 로컬 재현은 끝났다. 전체112개×8질문 채점은 잔액 오류로 미완료다. 결과를 본 뒤 질문·선택·기준을 고치지 않았다. 실제 최대 출력 예산을 통일한 주 비교와 반환한 실제 개수를 맞춘 보조 비교를 구분했다. 결과0개의 기준검색을0개로 줄여 성공처럼 보이게 하지 않았다.

비용 상한12달러. `api/`에 키를 제외한 요청·응답·오류·사용량을 저장한다. 다른 모델 제공자는 호출하지 않으며, Test15·과거 정답 라벨·모델 학습·원격 저장소 변경은 사용하지 않는다. 자세한 사전 계획은 `protocol.json`, 파일 고정은 `freeze.json`이다. 이 실험의 질문 작성자·선택기·채점자는 같은 모델 계열이므로 독립된 사람 정답이나 다중 모델 검증으로 부르지 않는다.
