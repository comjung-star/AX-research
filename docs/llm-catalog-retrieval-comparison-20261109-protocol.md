# LLM 선택을 실제 사례 검색에 연결: 승인된 1~4단계

## 범위와 고정

사용자가 승인한 작업은 LLM 선택→사례 검색 연결, 연결 과정 점검, 동일 조건 비교, 결과 분석까지다. 전체112 확장(5단계)은 하지 않는다. 기존4관점·18승인연결·17고유사례·조건 규칙·Task 정렬·배정 예산을 유지한다. 기존 동결 파일을 수정하지 않고 별도 어댑터와 실행 파일을 둔다. 새 학습과 새 사례 채점은 없다.

질문은 앞선 비교의 개발20개+재사용40개 모두60개를 그대로 사용한다. 이 자료는 이미 관찰됐으며 독립 최종 시험이 아니다. 관점 선택 개발에 쓴 회귀4개(IVQ010/015/020/029)는 별도 표시하고 나머지36개 결과도 함께 보고한다. 이36개도 과거 연구에서 본 자료이므로 새 held-out이라고 부르지 않는다. 봉인 Test15는 읽지 않는다.

LLM은 앞서 고정한 Claude Sonnet5.5/high/관점 설명/구조화 형식 그대로다. 동일 요청 본문으로 기존4개 응답을 재사용하고 나머지56개를 각1회 호출한다. 모델에 질문과 관점 설명만 보내고 정답·검색 결과·사례ID는 보내지 않는다. 새 호출 최대56회, 출력 상한4096, 사전 예약 총$5 이하, 자동 재시도0회다. 입력 UTF-8 바이트+8192 토큰 여유와 출력 전량을 공식 단가 $2/$10 per MTok로 예약한다. 실제 사용량과 실패 원본을 남긴다. 기존4개 응답 비용은 이번 신규 비용과 합산하지 않고 구분한다.

## 연결 방법과 기능 확인

LLM의 선택ID와 질문 인용을 기존 검색기가 쓰는 관점별 근거 형식으로 변환한다. 기존 문장 구분(scope_clauses)을 유지하고 인용이 겹치는 절에 정확한 위치를 붙인다. 인용이 여러 절에 걸치면 원문과 겹치는 부분만 나눈다. 검색 문장은 기존과 동일하게 작업 근거가 속한 절이다. 모델이 새 검색문을 작성하지 않는다.

추천 함수의 코드 본문·조건 확인·직접/응용 우선순위·cosine·관점별 배정은 그대로 사용한다. 함수의 선택기 의존성만 별도 이름공간에서 주입하며 전역 모듈이나 원본을 변경하지 않는다. 동일 규칙 선택을 주입했을 때 원본과 전체 결과가 같은지 검사한다. LLM 선택과 근거 표현을 함께 교체하는 실험이지 관점ID 하나만 바꾸는 실험은 아니다.

기존 절 구분이 LLM의 작업 근거를 과거·제외·승인으로 분류하면 자동으로 의미를 덮어쓰지 않고 연결 확인 보류로 남긴다. P04와 다른 문서 작업이 같은 절에 섞여 PDF/야간 등의 적용 범위를 구분할 수 없으면 해당 분기를 보류한다. 분리된 문장의 PDF 추출과 야간 응대에는 조건을 서로 전파하지 않는다. 긴 복합절의 완전한 의미 분석은 이번 어댑터의 지원 범위가 아니다. 원문에 미기재인 조건은 실제 불가능과 구분한다.

다중관점 보존·중복 제거·예산·원문 근거·조건 전파 방지·야간음성 근거 부족·읽기전용 미확인·선택 범위 충돌을 기능 검사한다. 이전 합성 선택 예시도 연결 진단으로만 확인하고 최종 정확도 표에 합치지 않는다. 기능 오류는 평가 전에 고치고 최종 순위 확인 후에는 고치지 않는다.

## 비교와 채점

주 비교는 같은17개/후보최대20/출력최대5의 A 기존 단일Dense, C 규칙 선택, E LLM 선택이다. B 질문전체−사례Task cosine을 보조 기준선으로 유지한다. A/B/C의 이전 순위는 그대로 재현·보존하고 E만 추가한다. 관점 분기와 출력 근거는 끝까지 보존한다. 17<20이므로 A/B 후보Recall20=1은 구조적으로 당연하며 개선 증거가 아니다.

질문·코드·정책·기준을 동결하고 순위를 저장한 뒤 채점한다. 기존 original/working_transfer/부분464쌍검토 표와40개 Claude/Gemini 전수 표를 각각 사용한다. partial은 전체검증 Gold가 아니고 모두 AI Silver다. 기존 판정을 다시 생성하지 않는다. 두 공급자의 공통 양성 질문과 사례별 이진 양성 교집합·합집합을 민감도 자료로 제시하되 합의 정답으로 채택하지 않는다.

주 지표는 동일17개 양성 질문의 macro F1@5, Recall@5, nDCG@5다. 빈 답은 양성 질문에서0점이다. F1=2TP/(실제출력수+양성수), gain=(2^grade−1) if grade>=2 else0을 유지한다. 정답 없는 질문은 F1/nDCG 평균에서 제외하되 출력·불필요 출력·빈칸포함P5·전체 적중 수를 보고한다. 실제 출력 중 정답비율만으로 성공을 선언하지 않는다. 전체112 정답을 분모로 한 계산과17목록의 정답 보존율도 함께 보고한다. 이는 전체112 검색 실험이 아니다.

사전 비교는 E−A, E−B, E−C다. 질문별 paired bootstrap seed20261109/10000회로 F1·nDCG의95% 구간을 계산한다. 기존 interval 함수의 보수적8비교 보정 구간도 유지한다(여기서는 실제6비교보다 보수적). 여러 정답표·개발선택에 대한 완전한 보정이 아님을 명시한다. 동일 질문에서 양성 여부가 바뀌지 않게 정답표별 코호트를 유지한다.

LLM 관점 선택이 늘었는지와 실제 정답 적중이 늘었는지를 구분한다. 양성 질문의 빈 답, 미선택 손실, 관점 제한 손실, 최종5개 배정 손실을 분리한다. 복수 관점이 실제 선택된 수와 그 질문에서의 결과를 기술하되 사후로 뽑은 질문의 좋은 점수만 성공 근거로 쓰지 않는다. 메타데이터 조건 진단은 방법과 같은 해석 자료를 쓰므로 독립 정확도 증명이 아니다.

## 종료와 판단

동결한 한 번의 비교와 저장 응답/벡터 재현 확인 후 종료한다. 결과를 본 뒤 프롬프트·가중치·관점·정답을 고쳐 다시 시도하지 않는다. 기존 검색과 업무중심 기준선 대비 일관된 이득, 규칙 대비 개선, 정답 누락·조건 위반의 균형이 뒷받침될 때만 확장 후보로 판단한다. 개선이 없거나 불확실하면 그대로 보고한다. 전체112 확장이나 성공 보장은 이번에 하지 않는다.
