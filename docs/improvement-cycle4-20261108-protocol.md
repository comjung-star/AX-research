# Cycle4: query-group out-of-fold learned score calibration

Cycles1-3 did not meet the frozen robust-development success gate. Fixed grammar/max/50:50 scoring appears too coarse; bilingual canonicalization alone is insufficient. This cycle tests learned calibration of existing branch interaction evidence, not a new end-to-end neural architecture.

Freeze two linear pairwise rankers: single-query features [Dense, structured semantic, purpose-filtered rule_grade/4], and multibranch features [same original3, branch Dense max/mean/min, branch semantic max/mean/min, branch rule max/mean/min]. No IDs, question text memorization, grades, strategy, solution, outcome, or test features. Branch evidence remains stored separately; summary statistics are diagnostic late fusion.

Twenty queries are sorted by SHA256(query_id), round-robin assigned to five folds. Each query and all112 cases and3 repeats stay in one fold. Train only on working_transfer labels of the other16 questions. Features are averaged over the3 repeats per query/case before fitting, so repeats are not independent samples. StandardScaler fitted on training rows only. Deterministic positive-vs-negative differences per training query are balanced in both directions; weight every positive-containing training question equally. LogisticRegression C=1, fit_intercept=False, liblinear, random_state=20261108, max_iter=1000. No hyperparameter grid or selecting folds. Queries with no positive do not create fake positive pairs.

Score every held-out query once, repeat the identical frozen ranking for comparison with historical repeat-averaged baselines. Evaluate the same out-of-fold predictions on all3 label versions. Compare linear single with linear multi, E and Dense. Report all folds, train/eval IDs, weights, descriptive paired intervals, and input hashes. Cases remain shared across folds: this is query-held-out development cross-validation, not case-held-out or independent external Test. Earlier inspection of the20 queries precludes final confirmation. No paid API, model downloads or label edits.
