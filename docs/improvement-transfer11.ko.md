# 후보10 고정 후 다른 기존 개발 질문에서 확인한 결과

2026-11-08. 후보10의 모델·원문/관점 가중치·토큰 점수·정규화를 변경하지 않고 기존 CPD8질문에 적용했다. 이 자료는 과거에 검토한 개발 질문이며 새로운 독립 Test가 아니다.29개 정답이 미판정인 CPD06/07은 주 지표에서 제외하고, 전수 판정된6질문을 같은 조건으로 비교했다. 제외 질문도 순위는 보존했다.

| 방식 | F1@5 | nDCG@10 |
|---|---:|---:|
| 기존 E |50.05%|78.06%|
| 원문 Dense |30.67%|57.75%|
| 원문 토큰 Hybrid |37.37%|66.53%|
| 후보10 원문+관점 토큰 Hybrid |38.38%|65.69%|

후보10은 Dense보다 F1 +7.71%p, nDCG +7.93%p였다. 질문 대응95%구간은 각각[+1.85,+14.38]%p, [+0.23,+15.84]%p다. 그러나 기존 E보다 F1 -11.67%p, nDCG -12.38%p였고 F1차이 구간[-22.78,-2.78]%p도 음수였다. 새로운20질문에서의 평균 개선을 기존 모든 업무의 개선으로 확대할 수 없다. 이 구간은6개 기존 개발 질문의 AI-Silver에 조건부이며 외부 독립 일반화나 다중 탐색 보정 결과가 아니다.

CPD01/02/04에서 E가 새 후보보다 높은 F1을 보였고, CPD03/05/08은 F1이 같았다. 후보10이 Dense보다 높은 F1을 보인 질문은 CPD01/03/04였으며 나머지는 동률이었다. F1과 nDCG가 항상 같은 방향으로 움직이지 않았으므로 둘 다 남겼다.

검증은 원문8개·E관점72개의 Dense를 기존 CLS벡터에서 재계산해 원본 점수와1e-6이내 일치하는지 확인하는 것부터 시작했다. 이후192개 고유 텍스트의 토큰 표현을 기존 로컬 모델로 계산했다. 최종80개 경로의 토큰 점수, 새 후보48개 순위 및6질문의 전체 지표를 캐시에서 다시 계산해 모두 일치했다. 정답 변경0, 유료 호출0, 새 모델 다운로드0, Test15접근0이다.

현재 판단은 후보10이 단순 Dense를 보완할 유효한 개발 단서이나 기존 E를 일괄 교체할 근거는 부족하다는 것이다. 다음 가설은 질문의 명시적 기능·원문/관점 일치·순위 합의 같은 정답을 보지 않는 입력 특성으로 E와 새 후보를 구분할 수 있는지다. 이를 학습한다면 평가 질문을 학습과 정답 기반 선택에서 제외하고, 두 개발 묶음의 결과를 각각 보고해야 한다. 자료 묶음 이름/질문ID를 입력 특성으로 쓰거나 이 결과를 독립 Test로 다시 이름 붙이지 않는다.
