# Cycle12: query-held-out late method routing

Candidate10 complements Dense on both development collections but loses to E on CPD. Test whether a small late router can preserve E's strengths rather than globally replacing it. This is experimental routing between two already branch-preserving models, not a claim that the professor explicitly specified a method router.

Freeze a LogisticRegression C=1,class_weight=balanced,liblinear,random_state20261108 router with train-only StandardScaler. Query features contain no labels, IDs or collection names: original function count, action-family count, original text log-length, mean fraction of original functions retained in Ebranches, mean original/branch CLS cosine and its standard deviation, mean E/Dense Top5 Jaccard, token/Dense Top5 Jaccard, E/token Top5 Jaccard, original Dense Top1-Top2 gap, original Dense Top5 spread, original Dense full112 standard deviation. Preserve original feature values and per-fold training IDs.

Use all28 queries for feature construction, but train only22queries having defined primary F1:16new20 working-transfer and6CPD complete questions. Five outer folds assigned by SHA256(query_id) round-robin over28queries. Every heldout query is excluded from training target construction, scaler and model. Target E if repeat-averaged primary F1 is higher than token, otherwise token; break F1 ties using nDCG, omit exact ties from training. Weight training questions equally, no grid or heldout early stopping. If a training fold has one target class, use that constant class and record fallback.

At inference choose E if probability>=0.5, otherwise frozen candidate10. Preserve selected method's3repeat ranks without rescoring or using ground truth. Compare E,Dense,token and router on each new20 label version and on6complete CPD questions separately. Do not optimize on sensitivity labels or pool incomparable collection means into one headline. Also measure leave-collection-out routing as a stress test: train targets/features only from one collection and evaluate on the other; collection identity may select the split but must never be an input feature. Previously inspected queries and shared cases mean none of this is fresh independent Test.

Evaluate selected methods against all controls, include failures, and audit routing decisions, feature scaling and query exclusion. No paid calls, new models, labels or Test15 access. Stop routing search after this one fixed router rather than choosing among a grid of gates.
