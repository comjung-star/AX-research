# 전체 수집 자료 포함 정책 · 사용자 결정

2026-10-26 사용자가 직접 요청한 변경이다. 공공기관·기업·개인/소비자·교육/연구·비영리 및 업무 구분이 불명확한 자료를 모두 포함한다. 공공기관이라는 이유로 제외하거나 기존 100~150개 목표에 맞춰 개수를 제한하지 않는다. 기존 기업 실제 운영 전용의 모집단 기준은 v2.5 자료 저장·검색의 제외 조건으로 사용하지 않는다.

이번 요청은 이전 동결본의 내용을 덮어쓰거나 기존 실험을 새 모집단의 검증 결과로 해석하도록 허용한 것이 아니다. 기존 v2.3 84개와 v2.4 108개는 별도 버전으로 보존한다. 교수 제안의 관점별 분기·Problem/Task/Context 분리·고정 전략 분류·출처 추적 원칙도 유지한다.

## 모든 입력의 포함

- 기존 수집 기록 8,430개와 발견 링크 3,208개, 이전 CSV 읽기 설정에서 오류로 분리된 11개 행·조각을 전부 보존한다. 원천 CSV를 표준 따옴표 처리로 다시 읽어 누락된 정상 레코드 9개를 복원하여 전체 입력은 11,658개가 된다.
- 별도의 개별 검토 업무 108개를 보존한다. 출처 페이지와 그 페이지에서 분리한 업무는 서로 다른 단위이므로 전체 기록 수를 고유 AX 사례 수로 부르지 않는다.
- `business_scope`, `business_scope_tags`, 한국어 `업무구분` 컬럼으로 업무 범위를 표시한다. 분류는 원천 명시 정보와 자동 키워드 규칙의 결과이며 수작업 확정이 아니다.
- `record_kind`, `ai_status`, `deployment_stage`, `annotation_status`, `content_check_status`로 사례/참고자료/링크, AI 여부, 실제 운영·시험·계획·중단·미확인, 확인 수준을 구분한다.
- 비AI·미확인 기술 자료, 시험·계획 단계, 실제 업무가 아닌 자료도 삭제하지 않는다. 이전 파서의 오류 이력과 접근 실패 자료도 원천 ID와 확인 결과를 남긴다. 복원된 원천 사례와 옛 파서가 만든 행·조각을 서로 다른 기록 유형으로 구분한다.
- 접근 실패·본문 부족·열 정렬이 깨진 자료는 레코드를 보존하되 확인되지 않은 내용을 만들어 검색에 넣지 않는다. 동일 내용의 중복 기록과 별도 검토 업무로 표현된 상위 페이지도 삭제하지 않고 검색 대표를 연결한다. 이 차이는 업무 범위 제외가 아닌 정보 유무·중복 표현의 차이다.

## 전체 확인의 의미

모든 원천 행을 프로그램으로 읽고 스키마·내용·업무 구분·운영 단계·중복을 점검한다. 저장된 웹 출처 링크 전체에 대해 공개 페이지 접근과 본문 추출을 시도하고 성공·실패를 각각 기록한다. HTTP 성공은 사례 사실 검증과 같지 않다. 원천기관 자료를 재구조화하거나 자동 점검한 것을 사람이 전체 원문을 정밀 검토한 것으로 주장하지 않는다. 접근 제한과 파싱 오류를 성공으로 바꾸지 않는다.

외부 유료 LLM으로 전체 자료를 일괄 전송하지 않는다. 로컬 BGE-M3로 검색 인덱스를 만들며 키와 기존 평가 기록을 데이터셋에 포함하지 않는다. 프로토타입의 실제 LLM 설명은 이전에 허용된 선택 상위 사례만 이용한다.

## 연구용 해석

원천의 혼합 설명을 검증된 Problem View로 몰래 바꾸지 않는다. 문제 문장과 구현 문장을 자동 규칙으로 구분하되 미확인 값은 UNKNOWN으로 둔다. 검색에는 확인 가능한 View만 사용하며, 추가 자료의 128토큰 인코딩 제한과 결측 View 평균을 별도 실험 선택으로 기록한다. 기존 동결 벡터는 유지한다.

원인 자동 분류 함수는 분리된 Problem 텍스트만 받고, 전략 자동 분류는 원천에 명시된 기능 표현을 고정 S1~S7에 대응시킨다. 자동 분류가 독립 Blind RCA·인간 Gold·검증된 통계 라벨을 뜻하지 않는다. 근거 없는 분류를 강제로 채우지 않고, 허용 전략이 없는 자료에 LLM이 임의 전략을 만들어 붙이지 않도록 한다. 새 자료를 확인적 Wald 분석이나 기존 qrels에 자동 편입하지 않는다.

새 모집단의 기업/공공/개인 등 비교는 이 컬럼으로 나중에 구성한다. 새 데이터 전체의 Recall·Coverage와 전수 사실 정확도는 이 처리만으로 입증되지 않는다.
