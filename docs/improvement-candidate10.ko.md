# 개선 후보10: 원문·관점 검색과 단어 단위 의미 비교

2026-11-08. 이번 반복에서 처음으로 세 고정 정답 버전 모두의 평균 F1@5와 nDCG@10이 기존 E 및 단순 Dense보다 높은 후보를 찾았다. 이는 재사용한 개발 자료의 관측 개선이며, 통계적으로 확정한 개선이나 새로운 독립 Test 성능이 아니다.

## 변경 내용

기존 BGE-M3 모델을 그대로 사용했다. 문장 전체를 한 벡터로 비교하는 Dense에 더해, 질문의 각 단어가 사례 Task의 어느 단어와 가까운지 계산했다. 사례 토큰의 공통 평균 방향을 제거한 뒤 질문 토큰별 최대 cosine을 평균했다. 각 점수는 같은112사례 안에서0~1로 정규화했다. 원문 Dense와 단어 비교를50:50으로 합쳤다. 관점도 같은 방식으로 별도 계산하고 원문과 의미가 가까운 관점에 더 높은 가중치를 주어 원문50%·관점50%로 늦게 결합했다. 원문·관점·사례 입력을 바꾸거나 정답을 보며 번역/가중치를 추가하지 않았다.

이는 기존 로컬 모델의 원시 토큰 표현을 이용한 실험이다. 사전학습 ColBERT나 별도의 교차 인코더를 사용했다고 쓰면 안 된다. 새 모델·학습·유료 API 없이310개 고유 텍스트의 토큰 표현을 로컬에서 새로 계산했다. 원래 Dense 점수는 검증된 기존 벡터를 재사용했다. 후보112개와 최종Top5 예산은 동일하지만 토큰 계산 비용은 추가되므로 같은 실행비용의 비교라고 주장하지 않는다.

작업용 전이 정답에서 Dense 대비 F1은+2.86%p, nDCG는+0.80%p다.95% 대응 구간은 각각[-2.52,+9.21]%p,[-4.05,+5.73]%p로0을 포함한다. 기존 E 대비 nDCG는+10.18%p지만 구간[-3.76,+23.27]%p로 역시 미확정이다. 최초 정답과 합의 반영에서도 Dense 대비 두 지표의 구간이0을 포함한다. 사후에 여러 후보를 탐색한 선택 효과도 보정하지 않은 기술적 구간이다.

원문만의 단어 Hybrid와 비교하면 관점 추가의 효과는 정답 버전에 따라 다르다. 작업용 정답 F1은24.82→26.07%, 합의 반영은19.36→20.60%지만 최초 정답은28.50→27.36%로 낮아졌다. 따라서 후보 전체의 평균 개선을 곧바로 다중관점 자체의 보편적 우위라고 해석하지 않는다.

## 실제 검증

- 원본 검색·정답·모델·Test15를 변경하지 않았다. 유료 호출0회, 새 모델 다운로드0회다.
-240개 후보 순위와3개 정답 버전의 질문별/전체 지표를 토큰 캐시에서 다시 계산해 전부 일치했다. 캐시310개에 해시를 기록했다.
- 별도로 이전 실제 벡터 신경망의 저장 모델10개를 다시 로드해40개 질문·모형 출력과120개 반복 복사 순위를 재현했다. 이 신경망은 성능 개선에 실패한 결과로 보존했다.
- 새 검사9개와 기존6개, 총15개가 통과했다. 단어 점수에서 사례 경계를 섞지 않는 검사, 관점·사례 뷰 유지, 반복의 독립 표본 오인 방지, 평가 질문 학습 제외 등을 포함한다. 이 검사는 정답의 객관적 타당성이나 통계적 우위를 보증하지 않는다.
