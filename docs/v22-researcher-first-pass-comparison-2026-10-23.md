# AX v2.2 — 연구자 1차 블라인드 평가 50건 / AI 3회 평가 비교
기준일: **2026-10-23**. **최종 Ground Truth 아님.**

## 저장 내용
- 연구자가 ChatGPT의 한국어 간략 설명을 읽고 **50개 평가항목 전부 0~4점 제출**. 누락 0. **자유서술식 판단 이유는 v2.2 1차 평가에서 선택사항**이므로 50개 공란은 유효한 1차 평가 결과다.
- 원래 **블라인드 평가표는 수정하지 않음**. 별도 `researcher_first_pass_50.json/csv`에 입력값, 원문 식별자, 단독 평가자 `researcher`, 보류 상태를 저장.
- AI와의 비교는 별도 `researcher_vs_ai_three_pass_50.csv`에 분리; 사람이 판단할 당시 기존 AI 점수는 숨김.
- 동결 v2.1의 91개, v2.2의 93개, 모든 GT 관련 파일 불변.

## 분석 해석을 엄격하게 제한
1. **AI가 틀렸거나 인간이 맞았다는 결론이 아니다.** 일치/불일치만 파악됨. AI 예비점수의 다수결 또는 가운데 값은 Ground Truth가 아니다.
2. 50개는 AI 문턱 불일치·점수 차이 사례를 **의도적으로 많이 뽑은 표본**. 위 26% 또는 60%를 2,790개 전체나 모델 일반 정확도로 일반화하지 않는다.
3. 사람의 50개 검토에는 **판단 이유가 전부 빈칸**이지만 v2.2 점수 전용 프로토콜에서는 **입력 필수 요건이 아니다**. 어떤 근거 문장도 허위 생성하지 않는다. 기존 인터페이스는 GitHub 영어 원문의 **한국어 짧은 의역**을 보여줬으므로, 본문 길이 차이로 점수가 바뀔 가능성도 있다.
4. **제3자 검토는 필수가 아니다.** 연구자 단독 점수를 평가 기준으로 사용할 수 있으며, 26개 불일치 사례의 본인 재점검도 선택적 품질관리로 수행한다. 전체 2,790개 Ground Truth는 아직 미완료다.
5. 이 자료를 논문 최종 Recall@K/Strategy Coverage/성능향상 근거로 사용하지 않는다.

- 사용자 요청에 따라 **이유 작성 없이 0–4점만 입력 가능**. 이미 제출된 50개 점수는 재제출할 필요가 없고 그대로 유지한다.
- 안내·절차: [`data/v2_2/score_only_review_protocol_v2_2.md`](../data/v2_2/score_only_review_protocol_v2_2.md). 검증: `scripts/v22_score_only_review.py`.

## 연구자 후속 결정: 제3자 검토 의무 해제
- 2026-10-23: 연구 여건상 제3자 평가를 확보할 수 없어 **연구자 단독 0~4점 판정**으로 v2.2 연구를 진행한다.
- 제3자 검토와 서술형 판단 이유는 **모두 선택사항**이다. 기존 평가 50개 점수는 그대로 보존하고 재제출을 요구하지 않는다.
- 독립적인 사람이 없는 상태로 연구자 단독 Ground Truth를 만들 수 있으나, 50개 파일럿을 곧바로 전체 Gold로 승격하지 않는다. 평가 범위, 미평가 처리, 연구자 승인, 동결 및 단독 평가자 한계를 먼저 정한다.
