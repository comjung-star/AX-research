## 독립 Test는 실행하지 못했습니다. 미사용 질문·정답 묶음을 확인하지 못해 사전 조건에서 중단했습니다. 아래 숫자는 모두 기존 Dev 결과입니다.

## 1. 연구 목적과 구현

사용자의 업무 문제를 보고 실제로 적용할 만한 기업 AX 사례를 찾는 연구입니다. 같은 업종이나 비슷한 단어보다, 실제 수행한 행동과 대상을 확인하려 합니다.

112개 사례의 Problem·Task·Context와 검색 경로를 보존했습니다. 관점별 후보를 확보한 뒤 A(18개 기능 규칙), B(BGE-M3 필드 임베딩), C(두 방식의 50:50 결합)를 비교했습니다. 현재는 비학습 검증용 구현이며, 교수님이 제안한 학습형 Interaction 신경망의 완성판은 아닙니다.

## 2. 실제 확인한 개발 자료 결과

|방식|원질문 F1@5|원질문+관점 F1@5|독립 Test|
|---|---:|---:|---|
|Single Dense|31.47%|별도 조건|미실행|
|A: 규칙|45.36%|46.10%|미실행|
|B: 임베딩|37.02%|38.76%|미실행|
|C: 결합|47.58%|47.58%|미실행|

C는 관점 조건에서 A보다 약 1.48%p 높았지만 개선은 고객 문의 Q1에 집중됐습니다. C의 원질문 결과도 47.58%여서 이 개선 전체를 다중관점의 기여로 설명할 수는 없습니다. B 단독은 A보다 전반적으로 좋지 않았습니다.

정답은 같은 OpenAI 모델의 3회 중앙값 AI-Silver입니다. 사람 Gold가 아닙니다. 10개 질문 중 양성은 6개 질문·18쌍뿐입니다. Precision은 10개, Recall/F1은 양성이 있는 6개 질문 평균입니다. 서로 다른 처리 조건의 기준선과 관점 효과도 구분해야 합니다.

## 3. 독립 Test를 실행하지 못한 이유

준비 기록에는 독립 Test 질문 0개·준비 false가 남아 있고, 지정한 세 최신 브랜치와 관련 경로에서도 질문·정답 묶음을 확인하지 못했습니다. 미래 Test 예약 자료나 과거 학습 holdout 감사 파일은 독립 Test가 아닙니다. Q11~Q15는 이미 추천을 확인한 목적 파일럿이며 사람 평가 103쌍도 아직 0건입니다.

## 4. 성과와 실패를 구분한 현재 판단

검증한 성과: 검색·관점·후보 결합·기능 매핑을 분리 비교하고, 나쁜 결과도 보존했습니다. 규칙이 인식하지 못한 33개 사례도 임베딩 비교 대상으로 처리했습니다. 새 질문의 블라인드 평가표도 준비했습니다.

남은 한계: 비교 가능해진 것과 정확히 추천한 것은 다릅니다. 33개 미인식 사례는 기존 Dev에서 양성이 0쌍이라 실제 회복률을 입증하지 못했습니다. Output을 양쪽에서 명시 비교한 쌍도 0개입니다. B는 내부 지식 검색과 수요 예측에서 손실을 보였지만, 원인을 Test에서 새로 검증한 것은 아닙니다.

고정 Dense+BM25도 대응하는 Dense보다 성능이 낮았습니다. 후보를 충분히 남기는 것만으로 최종 추천 정확도가 보장되지 않았습니다. 문장 임베딩 유사도는 업무 기능의 정확한 일치나 실제 도입 효과의 보증이 아닙니다.

## 5. 앞으로의 우선순위 - 아직 수행하지 않은 일

첫째, 현재 파일럿 103쌍을 사람이 채점해 기능 판단의 오류를 진단합니다. 이 파일럿을 독립 Test로 바꾸지 않습니다. 둘째, 교수님과 다중관점의 필요성 및 문장 임베딩 매핑의 기여를 입증할 비교를 정합니다. 셋째, 모델·평가 규칙 고정 후 미사용 질문·정답을 별도로 준비하고, 미노출·출처 중복을 점검한 뒤 한 번의 정식 비교를 합니다.

교수님 의견에 따라 모델을 수정한다면, 최종 논문 성능은 새로운 미사용 독립 Test에서 확인해야 합니다. 이번에 새 알고리즘·프로토타입·학습·추론·유료 API 호출은 하지 않았습니다.
