이번 검증으로 E가 C보다 확실히 좋다는 주장을 입증하지 못했다. 검토자 양쪽이 평가 가능한 같은4질문에서 C와 E의 F1@5가 같았고, 보존 품질도 두 모델에서 모두 같은 점수였다. 엄격한 새 판정에는75개 보류가 남아 전체8질문의 확정 성능과 최종 모델 채택 근거는 부족하다.
