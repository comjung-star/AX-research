## 7. 남은 문제

1. 실제 API 잔액 확인이 불가합니다. 모델 조회 GET는 200이었지만 조직 비용 조회 GET는 403, 관리자 키는 없습니다. **잔액 0이라는 뜻도, 응답 생성 권한이 없다는 뜻도 아닙니다.** 실제 잔액을 먼저 확인하라는 사용자 조건 때문에 유료 POST를 보류했습니다. [OpenAI 관리 API 문서](https://developers.openai.com/api/reference/administration/overview)는 별도 관리자 키를 요구합니다. 추가 충전·자동충전 변경·결제는 하지 않았습니다.
2. Test 미판정 1,635쌍이 남았습니다. 이번에는 유료 블라인드 AI 추가 평가를 하지 않았고, 같은 작업 AI가 이미 본 순위를 이용해 임의의 정답을 채우지도 않았습니다. 전체 평가 또는 사전 등록된 제한 지표에 필요한 판정 범위를 채우고 품질을 검증해야 합니다.
3. Test 작성자는 사례 목록을 먼저 봤고 질문·정답을 같은 AI가 작성했습니다. 외부 독립 작성자·사람 정답이 아닙니다. 파일 고정만으로 이 독립성 문제가 없어지지 않습니다. OS 전체 접근 감사도 없어서 모든 과거 열람이 없었다고 증명할 수 없습니다.
4. 문자열이 같은 기존 질문은 없었지만 은행 대사·고객지원 등 업무 영역이 겹칩니다. 문자열 중복 0은 의미 독립성의 증명이 아닙니다. 이번에는 원문 추론과 평가를 수행했으므로 이 자료를 계속 완전 미사용 봉인 자료라고 부르지 않습니다.
5. 개발 정답 보류 1건과 기능적 응용 경계, 짧은 사례 요약·출력 정보 부족이 남습니다. 사람 검증은 이번에도 0건입니다.
