# 고정 작업비교 방식의 기존40질문 전이 확인 — 3~4단계

범위: 기존40개 AI질문과 이미 생성한 관점·판정·로컬자료를 재사용한다. 새 유료API, 질문/관점/정답 생성, Test15 접근, 규칙 수정, 새 학습은 없다. 과거에 평가 결과를 본40질문으로 추가 확인하는 것이며 독립 최종시험은 아니다. 사람이 만든 실제 업무질문/Gold로 간주하지 않는다.

새 질문 적용 정책을 새 예측/평가 전에 고정한다. `work-aligned-dev-v1-20261109`에 저장된5개 외부폴드 모델의14차원 특성/가중치/학습비중을 그대로 사용한다. 각 모델의 기존 score(원문Dense와 해당 모델의 질문내 정규화한 학습점수의 혼합)를 구한 다음5개 점수의 단순 평균을 최종점수로 사용한다. 모델 선택·가중 평균 탐색·전체20개 재학습은 하지 않는다. 이는 앞선 개별 외부예측의 재평가가 아니라 고정 모델들을 새 질문에 적용하기 위한 사전 고정 결합 정책이다.

요청/제외/사람승인 분리와 행동복원 규칙은 동결한다. 인식 실패와 fallback을 그대로 남긴다. BGE-M3는 기존 파일 지문을 검증해 로컬 추론만 한다. Task요약 외 Solution/Outcome을 사용하지 않는다. 명시 output 부족과 얕은 object잔여문자열의 한계도 유지한다.

후보 생성은 앞선 개발20의 기존 절차와 동일하다. 원문Dense20에서 시작해Top10을 유지하고, 원문Dense+원문토큰의50:50정규화점수/기존원문행동/기존원문대상3값이 모두 엄격히 높은 후보만 하위10개에 교체한다. 각 경로는Top20까지만 제안한다. 후보 생성에는 복원 이전의 원문 semantic행동/대상 점수를 사용해, 새 채점과 기존 후보규칙의 역할을 분리한다. 원문토큰·원문BM25·기존E관점Dense를 각각 후보 제안 경로로 사용한다. 관점별 출처와 원문/관점 슬롯 누락을 남긴다. 소스별 채점기는 같은5모델 평균이다.

대조: Dense, 수정BM25, 참고용 기존E, Aligned_DensePool, Aligned_TokenPool, Aligned_SparsePool, Aligned_PerspectivePool. 모두 최종5개/후보20이지만 관점은 검색경로가 많고 점수/특성도 전체112사례에서 계산하므로 계산비용까지 같다는 주장은 하지 않는다. RRF는 새방법에 사용하지 않는다. 기존E만 과거 참고결과다.

추론과 후보는40개 판정자료를 읽지 않고 먼저 저장한다. 이후 기존Claude/Gemini 판정을 변경하지 않고 각각 평가한다. 공급자별 전체40질문을 기본으로 하되F1/nDCG/Recall은 양성질문에서 평균한다. 공급자별 양성질문 집합이 다르므로 두 공급자 모두 양성이 있는 동일질문 집합에서도 같은 비교를 따로 보고한다. 합의하지 않은쌍을 음성으로 만들지 않는다. 현재 불완전합의 자료로 전체Gold를 주장하지 않는다.

핵심은 ①Aligned vs Dense의최종F1@5/nDCG@10 ②동일채점기에서 Perspective vs Token/Sparse/DensePool의최종성능 ③후보Recall@20/새양성/이탈양성이다. 질문 단위로3반복 평균 후 비교한다. 질문bootstrap10,000회95%구간은 재사용개발민감도이며 다중비교/개발선택을 보정한 확증통계가 아니다. 후보 관련 직접 비교도 같은 질문 집합을 쓴다. 수치가 좋아도 새 독립시험 또는 전략추천 개선으로 부르지 않는다. 결과를 보고 이40개에 맞춰 수정/재학습/판정교체하지 않고3~4단계 보고로 종료한다.
