# AX 연구 무결성 재점검 — 1단계 검색 시스템 및 2단계 정답 데이터

2026-11-08 | 원본 보존 연구 브랜치: `research/stage1-stage2-integrity-20261108`

## 실행 상태

**1단계 검색 시스템 진단·BM25 영어 토큰 누락 복구: 완료 (개발 브랜치의 별도 구현과 검증).**

**2단계 정답 데이터 3회 블라인드 AI 평가·원문 근거 검증·불일치 분류: 완료 (자동 품질 감사).**

**단, 정답 데이터 전체에 대한 전문가 확정 판정은 완료되지 않음.** 불일치/미판정 149쌍을 별도 보류했고, 통계적으로 입증된 성능 향상이라는 결론도 내리지 않음.

이번 범위는 새 Validation 20문항 × 고정 AX 사례 112건이다. 실제 독립 Test 15문항과 9,416건 원천 후보의 사실 검수를 수행했다고 주장하지 않는다.

## 1단계 점검

- 기존 BM25 문서 중 **68/112건**이 검색 단어 0개. 원인은 Kiwi 토큰 처리의 `token.tag.startswith("S")` 조건이 영어 단어(`SL`)와 숫자(`SN`)까지 제거한 것이었다.
- 별도 `bm25_repaired.py`에서 영어·숫자를 보존하고 구두점만 제외하도록 수정. **112/112건 모두 검색 토큰 1개 이상으로 복원**되었고, 새 검색기에 대한 회귀 테스트 **4개 통과**.
- 기존 BM25 색인 통계는 원래 코드로 **정확히 재현**되었고, 기존 Dense·A·C·E 검색 순위와 112개 사례 원본은 보존. 초기 Dense/BM25 RRF 및 정밀 매핑 후 단계별 순위를 고정 자료로 검사.
- 검증용 신규 20문항, 단일 AI 잠정 관련성 등급으로 수정 전후 비교:

| 검색 방식 | 수정 전 F1@5 | 수정 후 F1@5 | 해석 |
|---|---:|---:|---|
| BM25 | 4.52% | 4.52% | 토큰 복구만으로 Top-5 정확도 향상 없음 |
| Dense 50% + BM25 50% | 14.63% | 12.25% | 오히려 감소 |
| Dense 단독 (참고) | 25.81% | 미변경 | 같은 고정 원문 임베딩/사례 순위 |

**해석:** 영어 사례의 BM25 색인 누락은 실제 결함으로 수정했으나, 한국어 질문과 영어 사례의 *언어 차이*, 균등 결합 가중치, 기능 매핑이 여전히 낮은 점수의 원인일 수 있음. 영어 단어를 살려도 한국어 질문이 영어 용어와 자동 매칭되지 않는다. 이번 표는 이미 사용한 Validation의 원인 분석 결과이지, 수정 모델이 더 우수하다는 독립 증거가 아니다.

**중요한 적용 범위:** 과거 실험 재현을 위해 기존 검색 코드와 색인 통계는 변경하지 않았다. 새 실험용 `src/ax_research/retrieval/bm25_repaired.py` 및 `scripts/stage12_search_integrity.py`에서 수정본을 실제 실행해 검증했다. 향후 정식 파이프라인을 교체할 때는 별도 버전 전환과 동등성 검사 필요.

## 2단계 정답 데이터 검증

- 기존 채점 **2,240개 질문·사례 쌍**의 Task 직접 인용 근거, 원문 식별자, 중복, Task/Context/evidence_id 누락 여부 확인. 각 사례에 Task·Context·evidence_id가 존재하고 기존 2,240 판정의 형식/인용 구조가 확인됨. 이것이 개별 사례의 원문 URL 사실성까지 검증했다는 뜻은 아님.
- 기존 AI 1회 + 순위·기존 등급을 숨긴 AI 2회 재평가 = **총 6,720개 평가 슬롯**. 유효 점수 **6,644개**, API 미판정/보류 **76개**.
- 유효한 원문 API 출력은 중복 JSON 메시지를 각각 검증해 **80개 판정 복구**. 새 유료 요청으로 같은 응답을 무조건 재호출하지 않음.
- 세 평가가 관련/비관련 여부에 모두 일치한 경우 **2,091/2,240쌍 (93.35%)**.
- 3회 등급 0–3까지 완전히 일치한 경우 **1,667/2,240쌍 (74.42%)**.
- 관련/비관련 경계에서 의견이 갈린 쌍 **76개**; 일부 보류/미판정이 포함된 쌍 **76개**; 중복을 제외한 **149개**는 독립 판정·재검토 대상으로 분리.
- 기존 AI에서 관련 사례(2점 이상) **89쌍**, 새 임시 다수 의견에서는 **35쌍**. 더 엄격한 두 평가에서 상당수 2점이 비관련으로 내려가, 정답 판정 기준과 학습/검증 오염 가능성을 추가 점검할 필요가 있음.
- *임시 다수 의견은 정답 확정이나 Human-Gold가 아니다.* 새로운 판정은 원래 파일을 절대 덮어쓰지 않았으며, 149건을 별도 큐에 보존.

### 대표적 불일치 예시

| 질문과 사례 | 기존 AI | 새 블라인드 2회 | 해석 |
|---|---|---|---|
| 배송 차량 운행 순서 vs 버그 티켓 담당팀 배정 | 2점 | 0점·0점 | 이동 경로 최적화와 업무 티켓 배정은 기능이 다르며 독립 판정 필요 |
| 문서 개인정보 탐지 vs 공장 이미지 인물 익명화 | 2점 | 0점·1점 | 보호 목적은 같지만 대상·출력과 작업이 다름 |
| 민원 관할 부서 분류 vs 채용 지원서 평가 | 2점 | 0점·0점 | 실제 수행 동작이 일치하는지 기존 판정에 의문 |

### 점수 비교 시 반드시 주의할 점

첫 채점에서 F1@5 계산 가능 질문이 17문항, 2차는 10문항, 3차와 임시 다수 의견은 8문항으로 달라졌다. **각 행의 점수를 그대로 비교해 성능이 올랐다/내렸다고 주장하면 안 된다.** 4가지 채점에서 모두 비교 가능한 문제는 **4개뿐**이라서 최종 모델 선택이나 유의미한 성능 향상 주장에는 부족하다.

현재 실험 결과를 토대로 **알고리즘 개선 효과에 관한 결론은 보류**하는 것이 적절하다. 별도의 진짜 독립 Test는 유지·미사용.

## 다음 단계의 우선순위

1. **149건 의견 불일치/미판정에 대한 독립 검증:** 동일 공급자의 동일 모델 3회가 아니라, 가능하면 다른 모델·원문 증거 기반 재판정. 확신할 수 없는 것은 보류한다.
2. **기준 확정 후 재평가:** 정답 기준을 먼저 고정하고 그다음 성능 비교. 동일 질문·동일 정답·동일 후보로 실험한다.
3. **검색 개선 통제 실험:** 새 BM25의 언어교차 문제와 Dense/BM25 가중치·정밀 매핑을 한 번에 바꾸지 않고 항목별로 검증한다.
4. **새 독립 Test:** 위 기준과 알고리즘이 확정된 후 미사용 Test로 일반화 확인.
