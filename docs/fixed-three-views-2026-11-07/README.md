단어 검사는 3슬롯 전체에서 원문 핵심 표현을 찾는 진단이다. 다른 말로 충실히 옮긴 내용과 부정 표현의 뒤집힘은 이 숫자만으로 구별하기 어렵다.

- 04번 1회차의 예비 고정 응답은 기술·운영을 비웠다. 보완 응답은 증빙자료, 확인 기능, 표시 결과와 사람의 최종 승인을 역할에 맞춰 담았다.
- 06번 보완 1회차는 은행 내역과 장부의 대조, 불일치 발견 및 알림과 근거 없는 자동 수정·송금 제한을 유지했다. 현업과 기술의 내용이 크게 겹쳤다.
- 07번 보완 1회차는 원문의 안내 후 직원 인계를 운영에 담았다. 기술은 안내 설명에 집중했으며 인계 결과는 3슬롯 전체에서 확인된다.
- 10번 보완 1·2회차는 현재 확인 우선이라는 원문을 수요 예측·고장 원인 추론 제외로 강화했다. 3회차 현업은 원래 우선순위를 유지했다. 단어 보존과 의미 보존의 차이다.
- 보완 프롬프트는 관점 종류 외에 명시 정보 누락 방지와 제약 보존도 구체화했다. 이번 비교는 두 프롬프트 묶음의 효과이며 관점 이름만의 효과를 분리할 수 없다.

기존 C1 규칙이 기능을 하나 이상 찾은 입력은 원문 2/10, 동적 20/90, 고정 36/90였다. 기능 ID 검출은 정확한 기능 매핑을 보장하지 않는다.

01번의 이탈 원인을 점수로 확인했다. 동적 관점의 짧은 문서 위치 확인 문구에서는 C1이 지식 검색 기능을 인식해 규칙 점수가 4였다. 보완 고정 현업은 확인 기능을 잡았으나 이 사례의 지식 검색 기능과 겹치지 않았고, 운영·기술도 공통 기능을 찾지 못해 최고 규칙 점수가 2였다.

해당 사례의 의미 점수는 B 0.483, C 0.475였다. 최종 점수는 B 0.871에서 C 0.619로 내려갔다. 이 사례는 기능을 하나 이상 찾는 비율과 올바른 기능을 연결하는 능력이 다르다는 점을 보여준다.

질문별 세 회차의 원점수와 관련 사례 진입·이탈은 결과 파일에 있다. 반복에서 같은 사례가 여러 번 움직이면 각 회차에 기록했다.

## ⑤ 연구적 결론

동적 3관점 대비 고정 3관점의 F1@5 차이는 -8.08%p, nDCG@10 차이는 -3.08%p다.

두 지표에서 고정 관점의 개선을 확인하지 못했다.

F1@5의 회차 변동은 B 4.95%p, C 2.91%p였다.

nDCG@10의 회차 변동은 B 4.14%p, C 5.39%p였다.

F1@5에서 B→C가 달라진 질문은 01번 -48.48%p.

nDCG@10에서 B→C가 달라진 질문은 01번 -52.85%p, 02번 +45.44%p, 03번 +0.88%p, 04번 -0.34%p, 05번 +4.34%p, 06번 +2.11%p, 07번 +2.53%p, 10번 -26.77%p.

01번을 제외하면 B·C의 F1@5는 둘 다 38.27%이고, nDCG@10은 B 48.17%, C 52.20%다. 전체 F1@5 하락은 이 질문 한 개에 집중됐다. 예비 고정의 높은 nDCG@10은 빈 슬롯이 있는 별도 결과여서 보완 고정의 동등 경로 비교와 나눠 해석한다.

고정에 원문을 더하면 Top-5 F1과 Top-10 nDCG는 조금 올라갔다. 반대로 F1@10·20에서는 고정관점만 사용한 D가 더 높았다. 원문 결합 효과는 추천 길이에 따라 달랐다.

세 회차 표준편차는 동일한 개발 질문에서의 생성 흔들림을 나타낸다. 개발 질문 수와 AI 평가표의 한계 때문에 다른 질문에서 같은 효과가 유지되는지는 아직 확인되지 않았다.
