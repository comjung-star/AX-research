# 고정 3관점 실험 설계

2026-11-07. 책임님 제안의 관점 종류를 고정하고, 개발 질문에 따라 각 슬롯의 내용만 생성한다.

| 관점 | 목적과 범위 |
|---|---|
| 현업 BUSINESS | 실제 업무 담당자, 겪는 문제, 업무 목적, 개선하려는 작업 |
| 운영 OPERATIONS | 명시된 처리 순서, 담당자 인계, 점검·관리, 장애·유지관리 |
| 기술 TECHNICAL | 원문이 명시한 입력, 처리 행동과 대상, 출력. 시스템과 기술은 원문에 있는 것만 사용 |

| 비교 항목 | B 동적 3관점 | C·D 고정 3관점 |
|---|---|---|
| 관점 선택 | 기존 동적 프롬프트를 3개로 제한 | 고정 ID와 정의에 따라 슬롯 3개 반환 |
| 구조 | ID·제목·설명·키워드·정확한 원문 인용 | 동일 필드와 상태. 정보 없음은 MISSING과 빈 내용 |
| 검색 | 각 제목과 설명을 줄바꿈으로 연결 | 같은 방식. MISSING 슬롯은 검색 경로에서 제외하고 기록 |
| 내용 확인 | 원문 인용 일치, 행동·대상·결과·제약 보존 점검 | 동일 기준. 역할·흐름·기술을 추측해서 채우지 않음 |

A는 기존 C1 원문 순위를 재사용한다. B·C는 기존 C1 원문+관점 결합을 그대로 사용한다. D는 C의 같은 관점별 점수를 재사용한다. 원문 항이 없는 D에서는 기존 관점 요약인 최대 규칙 점수·최대 의미 점수를 각각 사용하고, 기존 50:50 점수 함수와 관점 평균 Hybrid 동점 규칙을 적용한다. 원문 항의 제거를 위한 실험 정의이며 신규 가중치나 검색 알고리즘을 추가하지 않는다.

기준은 11월 3일 개발 검증 10질문, 사례 112개와 동결 v2 AI-Silver다. 관련 기준은 2점 이상이다. 질문 내 3회 평균 후 질문마다 같은 비중을 준다. 지표마다 네 조건 모두에서 값이 있는 완전 판정 질문을 주 비교에 사용한다. 양성 0건이면 Recall·F1은 미정의다. 관점별 발견 수는 같은 원질문 라벨을 사용한 진단이며 관점 자체의 별도 정답을 뜻하지 않는다.

출력 제목·설명만 BGE-M3와 BM25 검색에 사용한다. 원문 인용과 키워드는 감사용이다. 한 관점에서 기능, 목적 또는 부정 제약이 누락될 수 있으므로 원문 핵심 항목의 3슬롯 합집합과 개별 관점을 함께 점검한다. 형태 검사와 의미 검토를 구분한다.
