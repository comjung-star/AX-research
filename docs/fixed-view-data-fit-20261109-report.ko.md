# 데이터가 현업·운영·기술 관점에 맞지 않는가?

2026-11-09. **일부 질문에서 특정 관점의 근거가 부족하거나 경계가 모호할 가능성은 있다. 다만 현재112개 사례가 세 관점 어디에도 속하지 않아 성능이 나빴다는 증거는 확인하지 못했다.** ‘세 관점 모두를 충분히 설명할 수 있는가’와 ‘세 관점 어디에도 맞지 않는가’를 구분해야 한다.

## 우선 구조를 구분해야 한다

- 사례DB의필드: **Problem / Task / Context** — 문제, 수행 업무, 적용 맥락.
- 최근질문분해의틀: **BUSINESS / OPERATIONS / TECHNICAL** — 현업 목적, 운영 흐름, 입력·행동·대상·출력.

둘은 일대일 대응하는 분류표가 아니다. 최근 코드는 각 사례를 세 관점 중 하나로 미리 분류해두고 찾는 방식도 아니다. 원래 사용자 질문을 세 틀로 풀어 검색하고 같은 사례DB에서 후보를 찾는다. 한 사례가 여러 관점에 관련될 수도 있으며, 특정 질문의 한 관점에 관련되지 않는다고 데이터셋에서 제외할 이유는 없다.

현재TECHNICAL은특정AI기술이나제품명이있어야한다는뜻이아니다. 기존보완프롬프트는 입력/행동/대상/출력 중 **어느 하나라도** 있으면기술관점의근거로보도록한다. OPERATIONS도간단한처리단계/정기확인/인계/알림/사람판단이면근거가있다고정의했다. 범위가넓어세관점이겹칠수있다.

## 사례112개에서 확인한 것

저장된요약112개를대조했고Problem/Task/Context는각각112개모두비어있지않았다. Task에는문의답변, 서류추출, 예측, 사진검사, 로봇하역, 광고이미지생성, 의료판독등구체적업무가있다. 따라서현행기술관점의넓은정의로는수행행동/대상에대한문자근거가있다. 세범주전체밖으로분류해야할명백한사례는이번요약점검에서찾지못했다.

이는 모든사례가세관점에독립적으로충분한정보를준다는뜻이아니다. 예를들면:

|사례|있는 정보|한계|
|---|---|---|
|AXV2H_0081_01 고객상담 대화록 요약|상담노트정리의업무부담, 대화록요약이라는작업|입력부터검토·인계까지상세단계는요약에모두있지않음|
|AXV2N_0114 광고이미지 생성|촬영·디자인비용문제, 광고이미지생성, 광고캠페인맥락|구체적승인·전달절차는이요약에없음|
|AXV2P2_0097_01 냉동창고 박스 하역|저온환경의수작업부담, 박스하역이라는작업|입력·출력데이터형식보다는물리적작업의설명이중심|

없는단계나AI기술을임의로채워세관점을완성하면안된다. 빈필드0개라는구조검사와세관점의의미적충분성검사는다르다. 원출판물전체를재감사하거나사람의관점분류Gold를만든작업은아니다.

## 실제 관점 생성 기록에서 확인한 것

최근40질문×3반복=120회, 총360관점슬롯을확인했다.

|관점|PRESENT|MISSING|
|---|---:|---:|
|BUSINESS|120|0|
|OPERATIONS|110|10|
|TECHNICAL|120|0|

운영관점의MISSING은7개질문에서발생했다.

|질문|내용|운영관점누락반복|
|---|---|---|
|IVQ009|점포별신선식품폐기·발주패턴요약|2회차|
|IVQ012|쿠폰발행의추가구매효과평가|2·3회차|
|IVQ021|외래예약부도패턴분석|3회차|
|IVQ025|민원부서배정오류유형분석|1·3회차|
|IVQ030|직원설문불만·요청주제보고|2회차|
|IVQ033|공정지연의원인후보정리|2·3회차|
|IVQ036|강우에따른공정지연위험·일정후보검토|3회차|

**어느질문도모든3반복에서같은관점이계속MISSING은아니었다.** 예를들어쿠폰효과평가의운영관점은1회차에생성됐지만2·3회차에는누락됐다. 이는같은원문에대한생성판정이달랐다는관측이다. 실제운영근거가없다고확정하거나모델오류라고확정할수는없다. 일부질문에는분석·보고요구가중심이고인계·승인·실행절차는분명하지않아, 운영관점을어디까지인정하는지에따라판정이달라질수있다.

고정프롬프트는근거없는관점을MISSING으로남기도록허용했다. 따라서‘고정3슬롯’이‘모든질문에서3관점이반드시내용을가져야함’을뜻하지않는다. 또한PRESENT는AI생성결과의상태일뿐원문근거가완전히맞는다는인증이아니다.

## 이번 질문에 대한 판단

1. **셋 중 특정 관점에 충분히 맞지 않는 질문/사례 정보가 있는가?** 그럴수있고, 실제운영관점누락기록도있다. 상세원문근거의충분성은별도판단이필요하다.
2. **현재 사례들이 셋 어디에도 맞지 않는 데이터인가?** 저장된112사례의구체적Task와현행넓은정의상그런결론을낼근거는찾지못했다.
3. **이것이 추천 성능이 안 나온 원인인가?** 아직검증하지않았다. 같은내용을세번비슷하게표현하는문제, 정보누락, 채점기/평가기준의영향과구분해야한다.

따라서지금데이터를삭제하거나추가관점실험을바로시작하지않는다. 먼저고정3관점이서로다른검색근거를제공하는지와, 질문에없는관점은비워둘수있는지를원래논문구조와구분해해석해야한다. 이감사는적합성점검이며새성능실험이나새채점이아니다.
