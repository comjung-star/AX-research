# 新 추출 정보의 채점기 재학습 — 1~5단계 종료 규칙

범위: 질문이해v2/특성14개/사례112개/기존후보를 그대로 두고 채점기만 같은 pairwise ridge 절차로 다시 학습한다. 이전 기준본과 고정가중치v2를 보존한다. 추가 규칙/추출/후보/정답 생성·변경이나 유료API는 없다. 새 대형모델 학습도 없다.

1. 비교기준: Dense, 작업비교v1, 새추출+옛가중치v2, 새추출+재학습(RetrainedV2). 주성능 비교는 단일Dense후보에서 시작하며, 관점 고유 기여는 같은 재학습 채점기의 관점후보−Dense/토큰/BM25후보로 따로 판단한다.

2~3. 기존개발20의 working_transfer만 학습/설정선택에 사용한다. 기존5개 외부폴드(각4평가/16학습), 그16개 안의4개 내부폴드(각12학습/4검증)를 그대로 쓴다. λ={0.1,1,10}, 학습점수비중={0,0.5,1}만 비교한다. 내부Dense후보의 질문평균F1우선/nDCG차선, 동점은 학습비중 작게/λ크게. 평가질문은 해당모델의학습/선택에서배제한다. 사례ID/질문ID는특성으로쓰지않고 사례DB만공유한다. 2240쌍을2240독립질문으로보지않는다.

재학습5모델을 같은 기존정책의 점수동일평균으로 재사용40개에 적용한다. 40개에 대한 학습/설정선택은 하지 않는다. 각자료의 새예측을 저장한뒤 세개발정답표와 두기존AI판정으로 평가한다. 40개는공급자별양성질문수와두공급자공통양성12질문을모두보고한다. 둘다이미관찰한개발/재사용자료이며독립시험이아니다. Test15는사용하지않는다.

4. 모든조건 후보20/출력5, 반복3회를질문내평균한다. 후보는고정해Recall변화가순위학습효과로오인되지않게한다. F1/nDCG는무양성질문제외/P@5는모든질문. 질문bootstrap10,000회95%구간은개발선택/다중비교보정없는기술통계다.

5. 이한번의재학습가족을끝낸뒤결과기반추가탐색없이종료한다. 개선을후속평가로넘길기준은 (a)개발세정답표모두 단일조건F1이v1및Dense보다높고nDCG가v1보다낮지않음 (b)working의v1대비F1차이구간하한>0 (c)40공통양성질문에서두판정모두v1/Dense대비F1비감소·v1대비nDCG비감소다. 충족해도개발후보확정이지논문최종시험성공이아니다. 관점효과는별도비교하며단일조건의성공으로대신하지않는다.

미충족이면규칙추가반복을멈추고 기존자료로질문수/양성질문수/정답판정불일치/사례후보범위/추출결측/평가주장의범위를감사한다. 기존판정을재생성하거나사람Gold라고승격하지않는다. 질문/사례의추가수집또는판정정책결정은감사보고의권고로만남기고이번에는수행하지않는다.
