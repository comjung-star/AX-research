# AX 개발용 관련성 정답: 보류 75건 AI 직접 검토

2026-11-07 · 연구 개발용 잠정 판정 / 사람 Gold 아님

## 무엇을 했나

기존 정답 표의 **821개 기존 판정을 건드리지 않고**, 보류 중이던 질문·사례 **75개**를 GPT-6(현 대화)가 구조화 원문 `Task`/`Context`와 질문의 핵심 업무를 비교해 잠정 채점했다. 추천 순위·현재 알고리즘의 점수를 검토 입력으로 사용하지 않았다. **평가자는 연구의 과거 맥락을 알고 있어 독립 검토자가 아니다.** 실제 외부 게시물이나 도입 사실을 새로 전수 검증한 것도 아니다.

서로 다른 문제 두 가지를 분리했다.
- **사례 적격성**: 실제 도입·운영 사례인가? 기존 사례 데이터셋의 검수 범위로 유지; 이번에 새로 확정하지 않음.
- **사례 관련성**: 사례 Task/Context에 나타난 작업을 사용자의 업무 문제에 얼마나 활용할 수 있는가? 이 문서의 0–3점 잠정 판정.

## 기준

| 점수 | 기준 |
|---|---|
| 3 | 실제 수행한 핵심 행동·대상·결과가 질문과 직접 일치 |
| 2 | 업무 분야는 달라도 사례가 수행한 핵심 기능을 전이해 문제의 핵심을 지원 |
| 1 | 일부/준비/보조 기능만 같거나 핵심 기능을 새로 구현해야 함 |
| 0 | 실제 확인된 수행 기능이 질문의 핵심 기능과 실질적 관련이 없음 |
| 보류 | 실제 수행 작업 자체를 확인할 수 없는 경우. 이번 75건의 Task/Context는 잠정 개발 판단을 위한 최소 정보를 갖춤 |

업종·기술명·키워드 일치만으로 높은 점수를 주지 않았다. `Problem`의 문제상황을 수행된 기능으로 주장하지 않았다. 직접적 증거가 없는 안전성 제약·산출물·권한은 수행 사실로 추가하지 않았다.

| 점수 | 건수 |

| 3점 | 2 |
| 2점 | 19 |
| 1점 | 32 |
| 0점 | 22 |
| 합계 | **75** |

이 가운데 **24건**은 낮거나 중간 수준의 확신으로 추후 판정 민감도 분석을 권장한다. 이번 버전은 **개발용 AI-Silver 잠정 정답**이지 사람의 확정 정답이나 독립 Test 정답이 아니다.

## 대표적인 판정

- CPD05 × 뉴스 기사 영문 번역·현지화 (`R044`): **3점**. 뉴스 기사 한영 번역이라는 핵심 작업이 직접 일치.
- CPD07 × 브랜드 생활 장면 광고 이미지 생성 (`R073`): **3점**. 핵심 이미지 생성 업무가 직접 일치.
- CPD03 × 결제 기술문의 검색·답변 (`R025`): **2점**. 다른 도메인이지만 자료 검색·질문 응답 핵심 기능 전이 가능. HR 규정·담당자 인계는 별도 적용 필요.
- CPD04 × 고객 회의 요약 (`R036`): **1점**. 개별 회의 요약은 가능하나 여러 고객 의견의 주간 주제별 경향 분석은 수행 근거 없음.
- CPD06 × 청구 전 주문 가격 검증 (`R062`): **2점**. 가격 검증 기능은 전이 가능하지만 운송비 요율 대조 및 근거 출력은 미확인.
- CPD08 × 생산 계획 (`R075`): **1점**. 향후 계획 수립은 유사하나 과거 판매량에서 수요를 예측하는 핵심 기능은 미확인.

## 별도 개발용 정답 버전

`development_qrels_ai_provisional.json`에 **8개 개발 질문 × 112개 사례 = 896쌍**을 모았다.

- 기존 821쌍: 원점수·근거 보존
- 이번 75쌍: AI 잠정 점수로 개발용 버전에만 반영
- 원본 `labels_primary_unchanged.json`: **불변**
- 독립 Test 15문항: **접근하거나 사용하지 않음**
- 검색 코드·모델·가중치·예측: **수정하지 않음**

이 개발용 정답은 성능 최적화의 **탐색용 기준**으로만 쓴다. 동일 질문 집합·동일 정답 버전에서 기존 A/B/C/E를 비교하고, 새 성능 수치는 반드시 `AI-provisional`이라고 표시해야 한다. 기존 신뢰성 검증의 75건 보류가 해결되었다고 표현하면 안 된다.
