# 후속 가설: 행동과 대상의 근거가 함께 나아질 때만 교체

첫 사전 실험에서 상위3개 보존은 성공했으나4·5위의 양성 이탈을 막지 못했다. 전체 문장의 평균 토큰 점수만 높아지는 것을 충분한 근거로 인정한 것이 원인일 수 있다. 이번에는 이미 저장된 원문/실제Task의 행동·대상 필드별 cosine을 함께 확인한다. 행동·대상 추출은 기존 얕은 규칙이며 의미 검증된 역할 정답이 아니므로 보수적 진입 조건으로만 쓴다.

새 가설 하나를 고정한다. DenseTop3는 순서까지 유지한다. 원래Top5를 시작점으로 삼고 교체 후보가 현재 교체할 사례보다 원문Hybrid·행동 cosine·대상 cosine의 세 값에서 모두 엄격히 높을 때만4·5위를 교체한다. 후보나 비교 사례의 행동/대상 필드가 없으면 교체하지 않는다. 교체가 없으면 Top5뿐 아니라 원래 Dense 순서를 유지한다. 관점 점수는 최종 승격 근거에 쓰지 않는다.

원문 조건의 후보는Dense20이다. 관점 조건도Dense20에서 시작해DenseTop10을 후보 안에 유지하고, 관점별 순환 검색에서 찾은 후보가 나머지10개 중 한 사례를 위 세 값에서 모두 이길 때만 후보를 교체한다. 최종Top5 교체에는 같은 강한 조건을 다시 적용한다. 최종Top5 뒤는 후보집합 안에서 원래Dense 순서, 후보 밖도 원래Dense 순서다. 후보20·출력5는 동일하고 관점별 원래 순위와 진입 근거를 보존한다.

보호 개수/가중치/마진의 격자 탐색은 하지 않는다. 기존20질문·세 고정 정답 버전으로 진입·이탈·후보Recall·F1/nDCG를 모두 보고한다. 새40질문은 사용하지 않는다. 예측 저장 뒤 평가한다. 유료 호출·추가 임베딩·정답 변경은 없다.
