# 새 추출 정보 재학습·분리 검증·자료 감사 — 1~5단계 완료

2026-11-09. **새 추출 정보로 채점기를 다시 학습해도 이전 개선 버전v1을 일관되게 넘지 못했다. 이번 재학습 버전은 채택하지 않는다. 같은 자료에서 규칙/가중치를 더 조정하는 반복을 여기서 종료하고, 평가 기준과 자료가 뒷받침하는 주장 범위를 정리했다.**

Claude판정의 추가질문 평균은 조금 좋아졌지만, 개발20의 세 정답표와Gemini판정에서는v1보다 낮았다. 다중관점의 추가F1이득도 확인하지 못했다. 모델 효과가 작거나 없을 가능성과, 현재 판정/자료로 안정적 차이를 확인하기 어려운 가능성이 모두 남아 있다. 이번 결과를 정답표 탓으로 단정하지 않는다.

## 1. 비교 기준을 고정

기존Dense, 작업비교v1, 새추출+이전가중치v2, 새추출+재학습 버전을 비교했다. 질문이해v2·특성14개·사례112개·후보풀을 바꾸지 않고 채점기만 다시 학습했다. 후보20/최종5개, 기존 반복3회도 유지했다. 원본·규칙·계획·특성·기존예측의 해시와 [소스 묶음](source-snapshot.zip)을 저장했다.

## 2. 새 정보로 실제 재학습

대형BGE모델을 다시 학습한 것은 아니다. 기존 개발20질문의 새 추출 특성으로 작은 pairwise ridge 채점기를 학습했다. working_transfer정답만 학습/설정 선택에 사용했다.

질문마다 양성–음성 사례의 차이를 학습하고, 질문별 총 가중치는 동일하게 했다. λ={0.1,1,10}, 학습점수비중={0,0.5,1}만 비교했다. 다른 규칙/새 신경망/추가 탐색은 없었다. 최종5개 폴드모델의 (λ,학습비중)은(10,0.5)/(1,0.5)/(10,0.5)/(0.1,0.5)/(0.1,0.5)로 선택됐다.

## 3. 학습에 쓰지 않은 질문으로 검증

- 개발20: 기존5개 외부폴드에서16개 학습/4개 평가. 그16개 안에서 다시12개 학습/4개 검증으로 설정을 선택했다. 각 평가질문은 해당 모델의 학습과 설정 선택에 들어가지 않았다.
- 추가40: 새로 학습한5개 모델의 점수를 기존 정책대로 동일 평균했다. 이40개는 학습과 설정 선택에 사용하지 않았다.
- 새 순위를 먼저 저장한 뒤 다른 정답표와기존Claude/Gemini판정으로 평가했다. 반복은 질문 안에서 평균했고, F1/nDCG는양성질문만, P@5는전체질문으로 평균했다.

**두 자료 모두 과거에 관찰한 개발/재사용 질문이다.** 이번 학습 분리는 지켰지만 독립 최종시험은 아니다. 사례DB도 폴드가 공유하므로 미관측 사례 일반화 검증이 아니다.

## 5. 채택 판단 및 자료 적합성 점검

사전에 고정한 조건은 개발 세 정답표의v1/Dense대비F1개선과v1대비nDCG비감소, working의v1대비F1구간 하한>0, 그리고 공통40질문에서 양쪽 판정의 성능 비감소였다. 미충족으로 **재학습 버전 미채택·자료 감사**를 결정했다. 결과를 본 뒤 추가 단어나 가중치를 탐색하지 않았다.

### 자료 감사에서 확인한 사실

**독립적인 질문 수가 쌍 수보다 훨씬 적다.** 기존84×30라벨은10원문질문×3참조관점×84사례다.30개독립질문이아니다. 이번학습도20질문이고, 세정답표는같은20질문의판정버전이지서로다른60질문이아니다. 추가40개도이미관찰한AI작성자료라최종시험으로쓸수없다.

**양성판정의 차이가 크다.** 개발20의2,240쌍중양성은작업용54쌍/원본89쌍/부분재검토53쌍이다. 작업용과원본의양성/음성판정이다른것은45쌍, 작업용과부분재검토는11쌍이다. 부분재검토는전체중464쌍만별도검토한버전이며인간Gold가아니다.

추가40의같은4,480쌍에서:

|판정 조합|쌍 수|
|---|---:|
|둘 다 관련 있음|44|
|Claude만 관련 있음|4|
|Gemini만 관련 있음|338|
|둘 다 관련 없음|4,094|

Claude양성은48쌍, Gemini는382쌍이다. 전체 이진 일치율은92.37%지만 대부분 ‘둘 다 관련 없음’이다. 한쪽이라도 양성으로 본386쌍 중 공통 양성은44쌍으로 **양성집합의 겹침은11.40%**다. 이는 분류 정확도나 사람 정답 대비 신뢰도를 뜻하지 않는다. 어느 판정이 옳은지는 현재 자료만으로 확정할 수 없다.

**순위만 바꿔 해결하지 못하는 질문도 있다.** 작업용정답에서VQ003/006/020은Dense후보20안에양성이없다. 이는해당판정기준의후보범위문제이며정렬만으로회복할수없다. 양성자체가없는질문도작업용4개/원본3개/부분재검토2개, 추가40에서는Claude28개/Gemini2개다. 이차이가실제사례부족인지판정엄격성인지구분하지못했다.

**정보와 주장 범위의 간격이 있다.** 사례112개중명시출력필드는1개뿐이다. 완전한산출물일치나전략추천효과를평가했다고볼수없다. ‘같은업무를직접수행’과‘다른업종의작업방식을전이가능’도별개의관련성주장인데현재AI Silver가이를다르게해석할여지가있다. 형식/ID/누락/재현검증을마친정답파일이어도이의미적합성까지인간Gold로확정되는것은아니다.

### 지금 내리는 결정

- **유지:** 기존Dense와 개발 기준본v1, 모든 실패 실험/원본/판정 버전.
- **종료:** 같은 질문·같은 정답표에서 어휘 규칙이나 가중치를 더 붙여 성공할 때까지 탐색하는 방식.
- **다음 연구 결정의 우선순위:** 관련 사례의 의미를 직접 업무 일치/기능 전이로 명시하고, 후보 발견·최종5개 선택·전략 추천 중 어떤 주장을 검증할지 분리해 고정한다. 기존AI판정의 불확실성을 함께 보고하고, 그 기준에 맞는 미열람 질문 평가를 계획해야 한다. 이는 유리한 결과가 나오도록 정답을 바꾸자는 권고가 아니다.

현재 자료는 개발 가설을 찾고 실패를 분석하는 데에는 쓸 수 있지만, **다중관점의 안정적 우위를 확정하기에 충분한 근거는 확보하지 못했다.** 더 큰 모델/더 많은 학습으로 반드시 해결된다고도 말할 수 없다. 원본 판정의 전면 재생성이나 새 질문/사례 수집은 이번에 실행하지 않았다.
