# LLM 관점 선택 시범 1~3단계

사용자 승인 범위는 4개 시범 관점의 설명 준비, LLM 선택 구현, 개발 질문 검토와 지시문 고정이다. 사례 검색·정답 채점·성능 비교(4단계), 전체112 확장(5단계)은 수행하지 않는다. 기존 규칙 선택기와 추천기, 관점-사례 연결은 수정하지 않는다. 교수 모델 대체가 아닌 별도 실험이다.

## 1. 관점 설명

기존 검토 카드의 정의·포함·제외·질문 적용 조건을 토대로 `configs/llm_catalog_selector_20261109.json`의 질문 선택 설명을 작성한다. 사례 연결용 기준과 질문 선택용 기준을 구분한다. 원문 카드와 지문을 함께 보존하며, 설명은 assistant의 실험용 정리이지 교수·전문가 인증이 아니다. 관점 수와 연결 사례는 바꾸지 않는다.

LLM은 새 관점을 발명하지 않고 P01~P04 각각 SELECTED/PENDING/NOT_SELECTED로 판단한다. 명시 요청과 명확한 하위 작업을 구분하고 배경·과거·금지는 현재 요청으로 만들지 않는다. 뜻이 같으면 단어가 달라도 선택한다. 모호하면 질문 속 근거와 부족한 정보를 남긴다. 여러 관점 선택, 일부 범위 밖, 전부 범위 밖을 허용한다. 원문에 없는 조건·능력을 추정하지 않는다.

각 선택에 작업과 대상의 질문 인용을 요구하고 P03은 비교 기준·자료, P04는 용량·시간 문제의 인용도 요구한다. 프로그램은 인용을 원문에서 찾아 위치를 부여한다. 문자 일치는 의미 해석의 정확도를 보장하지 않는다. 설명·인용은 관측 가능한 선택 근거이며 모델의 내부 추론 과정을 요구하지 않는다.

## 2. 실행과 비용

Claude Sonnet5.5, effort high, 출력 상한4096 tokens, 구조화 JSON을 사용한다. temperature와 thinking disabled는 사용하지 않는다. 모델 ID와 형식은 공식 문서를 확인하고 사용 가능 여부를 무과금 Models API로 확인한다. 기존 Anthropic 키는 환경에서 읽고 저장·출력하지 않는다.

합성 개발20개+이미 관찰한 회귀4개+4개 카드 순서 반전 재실행=최대28회다. 요청당 비용은 입력 UTF-8 바이트 수+여유8192를 입력 토큰 상한으로 예약하고 출력4096 전량을 예약한다. 전부 합산해3달러 안일 때만 실행한다. 공식 단가 입력$2/백만·출력$10/백만을 기록한다. 생각 토큰도 출력 사용량 비용에 포함한다. 실제 비용은 응답 usage 기반 추정이며 청구서 확정액은 아니다.

요청과 예약을 전송 전에 저장하고 재전송·자동 재시도는 하지 않는다. timeout/불명확 전달은 예약을 유지한다. 기술·파싱 실패는 원본 응답과 사유를 보존하고 올바른 응답으로 바꿔치기하지 않는다. 도구 호출·사례 검색·사용자 메시지 발송 권한은 LLM에 제공하지 않는다.

## 3. 검토·고정·종료

합성20개 기대 선택 집합을 출력 확인 전에 정한다. 회귀4개는 앞서 관찰한 IVQ010/015/020/029이며 모호한 해석의 허용 집합도 사전에 정한다. 기대 집합은 assistant 작성 개발 기준이지 사람 Gold가 아니다. 반복4개는 카드 순서 민감도의 소규모 진단으로만 사용한다. 다른60개 질문·추천 정답표·검색 성능은 이번에 평가하지 않는다.

소스·질문·기대 집합·지시문·카드를 API 호출 전에 동결한다. 기대 집합과 검색 정답·사례ID는 LLM에 보내지 않는다. 프롬프트에는 질문과 관점 카드만 넣는다. 후처리는 유효 관점ID·4개 결정·중복·인용 원문 일치와 선택별 필수 근거를 검사하고 의미 판정은 하지 않는다. 규칙 선택기로 LLM의 의미 판정을 덮어쓰지 않는다.

모든 출력과 미충족 항목을 보고한다. 개발 기준의 선택 일치, 여러 관점 구별, 범위 밖과 보류, 제외·승인 조건 보존, 근거 문자 일치와 카드 순서 안정성을 각각 분리한다. 4개 반복을 독립 표본처럼 합산하지 않는다. 결과를 보고 지시문을 수정해 통과시킬 때까지 반복하지 않는다. 미해결 문제가 있으면 지시문은 실험본으로 고정하되 준비 상태를 REVIEW_REQUIRED로 남긴다.

관련 회귀 검사와 저장된 API 응답 재파싱 재현을 마친 뒤 종료한다. 선택이 잘돼도 추천 성능이 올랐다고 보고하지 않는다. 실제 사용자 질문의 일반 정확도, 독립 평가 또는 모델 추가 학습 효과도 주장하지 않는다.
