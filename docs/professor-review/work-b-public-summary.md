미판정을 0점으로 치환하지 않는다. 전체 Recall/F1/전체 코퍼스 nDCG는 계산할 수 없다. 부분 Precision도 해당 TopK 전부가 판정됐을 때만 정의한다.

질문 작성자는 기존 Dev/파일럿과 사례 목록을 확인했다. 모델 순위 기반 선택은 아니지만 판정할 사례를 작성자가 선택했고 평가자 선택 편향이 있다. 의미 중복·작성 독립성·기능 전환 경계를 외부 검토해야 한다. 사례를 모르는 독립 평가자가 만든 최종 시험이라고 주장할 수 없다. 원 출판물 재방문 없이 저장 요약을 사용했다.

실행기는 예측 후 평가하도록 분리돼 있으나 동일 Windows 계정에서의 파일 접근 가능성까지 제거하지 않는다. 봉인 원본은 Git/OneDrive 밖에 있으며 이 통합 작업은 해당 경로에 접근하지 않았다. 이 진술은 이번 작업의 도구 사용 범위이며 OS 수준의 전체 접근 감사 증명은 아니다.

다음 단계는 미판정 1,635쌍과 사람 검토·독립성 검토를 보완하고, 동결 정책과 노출 이력을 승인한 뒤 별도 담당자가 실행·평가하는 것이다. 이 브랜치는 Test 원본을 배포하지 않는다.
