# 최종 추천 순위 감사·개선·분리 검증 결과

2026-11-09. 사용자 요청의 1~5단계를 완료했다. **채점기 개선안은 구현하고 검증했으나 채택하지 않는다.** 한 정답표의 F1은 좋아졌지만 다른 두 표에서는 떨어졌고, 순위 품질도 일관되게 개선되지 않았다. 이는 이번 개선안의 기각이며 성능 개선이 불가능하다는 결론은 아니다.

## 1. 왜 잘못 골랐는지 확인

질문·사례의 Problem/Task/Context 원문과 저장된 점수 및 세 정답표를 대조했다. 전체 정답을 사람이 재판정하거나 새 정답을 만든 작업은 아니다.

- **분야와 작업의 혼동:** VQ001은 공장 제품 사진에서 균열·긁힘을 찾으려는 질문이다. Dense 3위인 AXV2N_0136은 생산 이미지 속 사람을 익명화하는 사례(working 1점)다. 반면 차량 하부 용접 찌꺼기를 탐지하는 AXV2N_0117(2점)은 6위였다. 이미지/생산 맥락이 같다는 것과 원하는 작업이 같다는 것은 다르다.
- **행동 유사도도 정답을 보장하지 않음:** VQ006은 납품 지연 위험 예측 질문이다. 1위 직원 신원조회 보고서 검증 사례(AXV2H_0003_01, 0점)는 행동 cosine이 0.817이었다. 반면 정답표의 설비 고장 위험 예측 사례(AXV2N_0119, 2점)는 행동 0.603, Dense 43위였다. 높은 행동 cosine만으로 승격하면 안 된다.
- **정답의 범위는 업종 간 기능 전이를 포함:** 납품 지연과 설비 고장 예측은 직접 같은 업무가 아니다. VQ014의 병원 예약 기록 대조 질문에 채용 지원서·증빙 대조 사례가 양성인 것도 이 기준이다. 세 표에서 모두 2점이라는 사실은 확인했지만 사람이 타당성을 확정한 Gold는 아니다. 업종 일치만 요구하는 개선은 현재 정답 기준과도 충돌할 수 있다.
- **행동 표현 추출의 구체적 누락:** 사례112개 중 동일한24개에서 의미 비교용 action 필드가 비어 있었다. 따라서 질문20개와의 480/2,240쌍(21.43%)에 행동 cosine이 없다. 원문에 행동 자체가 없는 것과 다르다. 예를 들어 ‘보험 자격·보장 음성 문의 응대’에서 ‘응대’가 의미 필드 추출용 action_pattern에 없어 action은 빈 문자열이고, object에는 ‘음성 문의 응대’가 남았다. 다른 기능 규칙 파서는 같은 사례의 ‘응대’를 인식한다. **두 파서의 처리 범위가 다르다.** 이 문제를 과거의 다른 파싱 오류 전체가 미수정됐다는 뜻으로 확대하지 않는다.

마지막 항목은 source semantic case_profiles의24개와 실제480개 누락이 정확히 일치하는지 재현 확인했다. 대상 필드의 cosine은 모두 존재하지만, 잔여 문자열로 만든 얕은 추출이므로 올바른 의미 역할을 보장하지 않는다. 조건/제외사항을 정밀하게 이해했다는 근거도 현재 없다.

## 2. 확인한 문제에 맞춰 채점기 구현

Dense·원문 토큰·수정 BM25·기존 Task/행동/대상 점수와 필드 존재 여부를 조합하는 작은 pairwise ridge 채점기를 실험 모듈에 구현했다. 같은 질문의 양성/음성 사례를 구별하도록 학습했고 질문별 학습 가중치는 동일하게 했다. 사례 ID와 질문 ID 자체는 입력으로 넣지 않았다.

이 개선은 기존 점수 조합을 학습하는 방식이다. 누락을 표시해 다루지만, 누락된 행동 표현을 복원하거나 새 조건 의미 점수를 만든 것은 아니다. 따라서 전면적인 행동·대상·조건 이해 모델로 설명하면 안 된다. 운영 모델이나 기존 E는 교체하지 않았다.

## 3~4. 기존 비교 및 질문을 나눈 검증

20질문을4개씩5묶음으로 고정했다. 매번16개로 학습하고4개를 평가했다. 설정 선택도 그16개 안에서 다시12개 학습/4개 검증으로 분리했다. 외부 평가 질문의 정답은 해당 모델 학습과 설정 선택에 사용하지 않았다. 모든 질문이 정확히 한 번 외부 평가에 참여했다.

학습 정답은 working_transfer만 사용했다. 다른 두 정답표는 예측 파일을 고정한 뒤 민감도 평가에만 사용했다. 동일 채점기를 Dense 후보20, 원문토큰 보완 후보20, 관점 보완 후보20에 적용해 후보 검색 효과와 순위 채점 효과를 분리했다. 최종 출력은 모두5개다. 임베딩/관점은 기존 캐시이며 이번 유료 호출은0회다. 신규40질문과 Test15는 열지 않았다.

**이20질문은 과거에 검토한 개발 자료다.** 질문별 학습 혼입을 막았지만 새 독립 시험으로 바뀌지는 않는다. 동일112사례 검색 DB도 각 묶음이 공유하므로 미관측 사례 일반화 검증이 아니다. 세 정답표 역시 같은 질문을 다르게 판정한 AI Silver 버전으로 독립 실험 세 번이 아니다.

|정답표|양성 질문|기존 Dense F1@5|새 채점+Dense후보|새 채점+원문토큰후보|새 채점+관점후보|
|---|---:|---:|---:|---:|---:|
|working_transfer|16|0.23205|0.25686|0.25686|0.25686|
|original|17|0.25809|0.24250|0.24250|0.24250|
|scoped_consensus_464_only|18|0.20256|0.18547|0.18547|0.19605|

F1은 클수록 좋다. working에서 좋아진 점은 실제 관측 결과다. 그러나 관점 후보를 쓰지 않아도 동일하게 좋아졌으므로 이 향상을 관점의 기여로 돌릴 수 없다. scoped에서 관점 후보가 같은 채점기의 Dense 후보보다 나은 것은 한 질문의 개선이며, 기존 Dense 자체보다 여전히 낮다.

|정답표|기존 Dense nDCG@10|새 채점+관점후보|F1 차이의 질문 bootstrap 95% 구간|
|---|---:|---:|---|
|working|0.50551|0.48952|−0.04272~+0.10050|
|original|0.46938|0.48339|−0.07003~+0.03769|
|scoped|0.42086|0.42002|−0.05861~+0.04965|

working에서는 F1이 좋아진 질문3개, 나빠진 질문3개였다. 평균 차이는+0.02482이나 구간이0을 포함한다. VQ001은 F1 0.4→0.2, VQ014는0.15385→0으로 악화했다. 설정 탐색/개발 반복의 영향을 보정한 확증 통계로 이 구간을 제시하지 않는다. 양성이 없는 질문은 F1/nDCG 평균에서 제외하고 P@5에는 포함한다. scoped 정답표도 전체2,240쌍 중464쌍만 별도 검토된 부분 검토본이다.

후보 집합은 고정했으므로 Recall@20은 이전과 같다. 관점 후보는 working 0.66668, Dense 0.65019다. **후보 발견 이득은 유지했지만 이를 안정적인 최종 추천 향상으로 전환하지 못했다.**

개발 정답을 미리 안다고 가정해 후보 안의 정답을 완벽하게5개까지 골랐을 때, working F1 상한은 Dense후보0.41911/관점후보0.43273이었다. 이는 정답표를 이용한 진단용 상한으로, 달성한 모델 성능이나 달성 가능성 보장이 아니다. 후보 안에도 놓친 정답이 있어 순위 개선 여지는 남아 있다. 반대로 working 양성16질문 중3개는 Dense20안에 양성이 하나도 없어 순위만 바꿔서는 회복할 수 없다.

## 5. 채택 결정과 다음 연구 판단

사전에 정한 ‘세 표 모두 F1 향상, nDCG 비감소, working F1 차이 구간 하한>0’ 조건을 어느 개선안도 통과하지 못했다. **이번 학습형 채점기는 채택하지 않는다.** 좋은 정답표 한 개만 골라 성공으로 보고하거나 결과를 본 뒤 가중치를 추가 탐색하지 않았다.

남은 개선 지점은 더 구체적이다. ‘채점 점수를 섞으면 된다’는 접근보다 **행동 표현 누락과 역할 추출의 범위를 먼저 바로잡아야 한다.** 사례 원문에 있는 응대/안내/접수/영문 행동 등을 빠짐없이, 근거 문자열과 함께 추출하는지 점검하고, 질문의 원하는 작업과 제외한 작업을 구분하는 입력을 만들어야 한다. 누락 복원 자체는 점수 향상을 보장하지 않으므로 별도 규칙 고정 후 같은 질문 분리 검증이 필요하다. 이번 실험 결과를 보고 그 수정을 소급 적용하지 않았다.

정답표를 처음부터 다시 만드는 작업은 권하지 않는다. ‘업종 간 기능 전이를 어디까지 관련 사례로 볼지’라는 현재 판정 범위를 명시하고, 논문에서 직접 업무 일치와 전이 가능성의 주장을 구분해야 한다. 신규40개는 이미 결과를 본 재사용 평가이며 최종 미열람 시험이 아니다.
