# 실시간 관점 시연 검증

- 기존 OpenAI Responses 관점 생성 함수를 재사용했다. 현재 연결 모델 gpt-6-luna. 모든 검색에서 새 API 응답을 받으며 캐시 관점을 재생하지 않는다.
- HTTP 실실행 2회 통과: 고객상담 입력 2개 관점/8.13초, 문서처리+규정 검색 입력 3개 관점/6.85초. 각 관점에서 112개 검색, 관점별 Top5, 최종 Top5, 응답 ID 및 토큰 수 보존.
- 브라우저 추가 실실행 1회: 고객문의 입력에서 2개 관점, 총 5.59초. 관점 목록·설명·실제 응답 ID·관점별 Top5 펼침·결합 Top5·원문 출처 및 관점별 근거 표시 확인.
- 기존 기능 테스트 27 passed, 보존 파일 10개 SHA256 일치, 최종 C 점수 공식 재계산 일치.
- 앱을 재시작해 현재 포트 8766에서 최신 버전을 제공한다. 기존 바탕화면 실행기 경로 유지. 실행기는 숨겨진 Python 콘솔을 사용하도록 수정해 pythonw 초기화 지연을 회피했다.
- API 호출은 입력을 OpenAI에 전송하며 계정 사용료가 발생한다. 실패 시 정적 결과로 대체하지 않는다. API 키는 로그/응답/커밋에 포함하지 않는다.
- 기존 동결 설정/사례/알고리즘/독립 Test 파일 수정 없음. 독립 Test 열람·실행 없음. 이 기록은 동작 확인이며 정확도 검증이 아니다.
- 과거 실험의 전체 hybrid 후보집계/동점 설정 및 생성 프롬프트 전체를 재현했다고 주장하지 않는다. 기존 prototype 관점 생성과 마지막 semantic 집계 공식을 연결한 실시간 시연이다.
