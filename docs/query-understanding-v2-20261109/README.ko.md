# 질문 이해 개선·기능 검증·추천 재비교 — 요청한1~3단계 완료

2026-11-09. **질문 추출의 일부 구체적 오류와 누락은 보완했지만, 기존 가중치를 유지한 추천 실험에서는 이전 버전보다 최종F1이 낮아졌다. 이번v2를 추천 파이프라인에 채택하지 않고 기존 개발 기준본v1을 유지한다.** 다중관점을 더했을 때의 최종 추천 이득도 확인하지 못했다.

이는 ‘질문 이해 개선이 불필요하다’ 또는 ‘더 좋은 추출기를 학습한 채점기로도 효과가 없다’는 결론은 아니다. 이번에 검증한 것은 **고정된 기존 모델에서 질문 추출만 교체했을 때의 효과**다. 새 입력에 맞춘 채점기 재학습은 하지 않았다.

## 1. 질문 이해 부분을 별도 버전으로 개선

기존 추출기·가중치·후보 자료는 수정하지 않고 query-only `query-understanding-v2-20261109`를 만들었다.

- ‘목록을 만들고 싶습니다’, ‘목록이 필요합니다’, ‘목록으로 정리해 주세요’ 등 명시 요청의 표현 범위를 보완했다.
- ‘목록이어야 하며, 원인을 단정하지는 않아야 합니다’처럼 한 문장에 요청과 금지가 함께 있을 때, 근거가 있는 절 경계에서 나눴다.
- 사람이 승인하는 조건을 요청/금지와 구분했다.
- ‘사업자 식별자’의 ‘식별’, ‘지원자’의 ‘지원’을 행동으로 잘라내는 것을 막았다. 원문에 있는 비교/대조/정리/찾기/묶기/표시/제공 등의 표현을 추가했다.
- 원문에 없는 동의어를 생성하지 않았고, 확실한 요청을 인식하지 못하면UNKNOWN으로 남겼다. 배경 전체를 강제로 요청으로 채우는 기존fallback은 사용하지 않았다.

대상 필드는 여전히 얕은 잔여 문자열이다. 일부 기능 오류를 고쳤다는 것과 모든 의미 역할을 정확하게 이해했다는 것은 다르다. 이번 변경은 질문에만 적용했고112사례의profile은 그대로다.

## 2. 추천 점수와 분리해 기능 검사 후 고정

추천 점수를 읽는 실험과 별도 단계에서 assistant가 작성한 합성 문장20개를 검사했다. 요청 표현을 바꿔도 핵심 요청이 남는지, 금지 문장이 요청에 섞이지 않는지, 명사 일부를 행동으로 오인하지 않는지, 모르는 경우를 미확정으로 남기는지, 모든 근거가 실제 원문 위치와 일치하는지 확인했다.

첫 검사에서 ‘비교한’의 어미 처리와 ‘하지 마세요’의 금지 처리가 실패해, 추천 결과를 보기 전에 기능적으로 수정했다. 이후20개 검사를 통과한 시점에 소스/검사문장/규칙 해시와원본묶음을 저장했다. 고정 후 추천 비교 결과를 보고 다시 고치지는 않았다.

**이20개는 기능 계약 검사다. 사람이 검증한 의미Gold나 독립 정확도 평가는 아니며, 통과율을 실제 질문 이해 정확도100%로 보고하지 않는다.** 관련 회귀/행동 테스트60개와하위검사6개도통과했다.

|확인 항목|이전v1|새v2|의미|
|---|---:|---:|---|
|개발20질문의 빈 행동 필드|4|0|문자열 추출 누락 감소|
|재사용40질문의 빈 행동 필드|15|6|완전한 행동 이해는 아직 아님|
|재사용40질문의 요청 직접 인식 실패 처리|배경fallback8개|요청UNKNOWN2개|처리 정책이 달라 단순 오류율 감소로 해석하지 않음|

남은 빈 행동은IVQ004/006/012/018/024/025이고, 요청 자체가UNKNOWN인 것은IVQ012/018이다. 미확정 내용을 임의로 채우지 않았다.

원문에서 확인한 보완 예:

- VQ013의 행동은 ‘식별’ 대신 원문의 ‘비교·묶·보여주’가 됐고, 대상에는 ‘식별자’라는 단어가 온전히 남는다.
- IVQ001에서 ‘결과는…후보 요인 목록이어야 하며’가 요청으로 보존되고 ‘원인을 단정하지는 않아야 합니다’는 제외로 분리된다.

## 3. 고정 후 추천 성능 다시 비교

추천 후보20개/출력5개,14개특성의정의, 기존Dense/토큰/BM25값, 모델가중치를 유지하고 질문 추출만 바꿨다. 같은로컬BGE로 새필드문자열81개만 계산했다. 새로운대형모델/유료API/새학습/정답변경은없다.

- 개발20질문: 각 질문의 기존외부폴드 모델1개를 사용했다. 해당질문은 그모델의기존학습질문에포함되지않는다. v1과v2가 정확히 같은 가중치를 사용한다.
- 재사용40질문: 이전에 정한 기존5모델의동일점수평균을 유지했다. 전체20개로새로학습하거나 모델을선택하지않았다.
- 먼저 단일Dense후보에서v2−v1을 비교하고, 같은v2채점기에서 관점후보−단일질문후보를 따로 비교했다.
- 순위를먼저저장한뒤 기존정답표로평가했다. 세반복은질문별로평균했고, F1/nDCG는양성질문만평균하며P@5는전체질문으로계산했다.

### 먼저 단일질문 방식: 최종5개 F1@5

|자료/정답표|F1평균 질문 수|기존Dense|이전v1 단일Dense후보|새v2 단일Dense후보|
|---|---:|---:|---:|---:|
|개발20 작업용|16|0.23205|**0.28035**|0.26292|
|개발20 원본|17|0.25809|**0.29852**|0.28180|
|개발20 부분 재검토|18|0.20256|**0.21111**|0.19561|
|재사용40 Claude|12|0.39215|**0.41973**|0.40306|
|재사용40 Gemini|38|0.28387|**0.30472**|0.29427|

전부v1보다 낮았다. 개발20 작업용의v2−v1은−0.01743이고95% 질문bootstrap구간은−0.04267~0이다. 재사용40에서는 Claude−0.01667(구간−0.05~0), Gemini−0.01044(구간−0.03425~+0.00961)다. 악화를 통계적으로 확정했다고 표현하지 않으며, 개선이라고 채택할 근거도 없다.

40개에서 두 공급자가 양성으로 본 동일12질문으로 맞추면:

|판정|Dense F1|v1 단일Dense후보 F1|v2 단일Dense후보 F1|
|---|---:|---:|---:|
|Claude|0.39215|0.41973|0.40306|
|Gemini|**0.35915**|0.33657|0.33393|

동일 질문이라는 뜻이며 사례별 정답 판정까지 일치한다는 뜻은 아니다. Gemini의 공통12질문에서도F1이 더 낮아졌다.

모든 지표가 같은 방향인 것은 아니다. 재사용40의Claude nDCG는v1단일0.60130→v2단일0.61131로 올랐고, Gemini 공통12질문nDCG도0.55127→0.56886으로 올랐다. 하지만 주요 목표인 최종5개F1이 개선되지 않았으므로 순위 지표 일부만 골라 성공으로 보고하지 않는다.

실제F1 하락 질문도 기록했다. 개발20 작업용에서는VQ014(기록대조), VQ018(현장작업일지정리)이 낮아졌다. 재사용40에서는Claude의IVQ010, Gemini의IVQ005/018/020이 낮아졌다. IVQ018은 새 규칙에서 요청이UNKNOWN으로 남은 질문이지만, 이 사실만으로 전체 성능 변화의 원인을 단정하지 않는다.

개발20에서는 관점 조건이 낮고, 재사용40에서는F1이 같았다. 원문토큰/BM25후보와의 전체 비교도 원본에 보존했으며, 이번 결과로 관점 추가의 최종 추천 우위를 입증하지 못했다. 후보풀을 바꾸지 않았으므로 각 조건의Recall@20은v1과 동일하다. 새 후보 발견 효과를 시험한 실험이 아니다.

## 판단과 이번 작업의 한계

1. 질문 이해 별도 개선: 완료. 구체적인 명사 오인/요청 누락/혼합 부정 처리를 보완했다.
2. 추천 점수와 분리한 기능 검사 및 고정: 완료. 합성 계약검사20개와 소스 묶음을 추천 평가 전에 고정했다.
3. 고정 후 단일질문→다중관점 성능 비교: 완료. 기존 가중치 조건에서v1대비F1이 낮아져v2추천 교체는 채택하지 않는다.

문자열을 더 잘 뽑는 것, 의미 역할을 정확하게 해석하는 것, 정답 사례를 잘 고르는 것은 별개다. 현재 가중치는v1표현으로 학습돼 있어 새 특성 분포와 맞지 않을 가능성도 있지만, 이번 실험은 재학습하지 않았으므로 그 가설을 입증하거나 기각하지 않았다. 추출v2는 검토용으로 보존하고 추천 실험의 개발 기준본v1은 그대로 유지한다. v1도 아직 최종 채택된 운영 모델은 아니다.

두 자료는 이미 관찰한 개발/재사용 질문이다. 기존 실패를 알고 추출기를 설계했으므로 이번 평가에서 정답 파일을 나중에 열었다고 개발 편향이 사라지지 않는다. 정답은AI Silver이며 부분 재검토표도 전체Gold가 아니다. 질문bootstrap구간은 개발 선택/다중비교 보정 없는 기술통계다. 독립적인 최종시험/사람의 의미 정확도 인증/전략 추천 성능 향상으로 주장하지 않는다.

요청 범위를 모두 완료했고, 결과를 보고 추가 규칙이나 가중치를 탐색하지 않았다. 유료 호출0회, 새 학습0회, 정답 변경0회이며Test15에는 접근하지 않았다.
