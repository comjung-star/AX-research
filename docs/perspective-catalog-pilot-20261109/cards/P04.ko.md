# P04 — 문의량·접수 시간대가 응대 가능 용량을 넘어 대기·누락이 생김

문의가 몰리거나 기존 응대경로가 처리하지 못해 사람의 응대용량과 시간대 한계를 넘어 대기·누락이 생긴다.

## 포함 조건

- Problem에 문의량·응대공백·상담원 쏠림과 대기/처리 부담이 있음
- Task에 실제 문의 응대가 명시됨

## 제외 조건

- 고객상담 업종이라는 이유만으로 연결
- 검색 품질·상담 후 요약이 문제의 중심이고 응대용량 근거는 없음

## 사용자 질문에 적용할 조건

- 사용자 질문에 문의처리 대기·공백·용량 문제의 근거가 있음
- 야간 응대·음성/문자 채널·사람 인계는 각 사례의 지원 근거를 개별 확인

## 아직 모르는 부분

- 지원 시간대·채널·예외처리 범위
- 모든 문의의 완결 처리나 거래 실행 여부

## 연결별 원문 검토

아래는 저장된 요약에 대한 assistant의 내부 검토다. 새 사용자 질문의 정답 판정이나 독립 전문가 검증이 아니다.
