# P03 — 업무 자료를 기준·다른 자료와 대조하는 검증 부담

업무 문서·등록 데이터의 내용이나 필수항목을 다른 자료 또는 기준과 대조해야 하므로 검토 부담·오류·누락이 생긴다.

## 포함 조건

- Problem 또는 Task에 자료·기준·필수항목을 대조하는 확인 부담이 있음
- 실제 Task에서 검증·대조·완전성 점검·감사를 수행함

## 제외 조건

- 같은 문서·업종·검증 단어만 공유
- 추출만 수행
- 물리 제품 영상검사 또는 이상탐지만 있고 문서/기준 대조는 불명확

## 사용자 질문에 적용할 조건

- 문서·등록 데이터의 확인 대상과 기준을 식별할 수 있음
- 검토 목록 작성과 수정·승인·차단은 분리

## 아직 모르는 부분

- 검증 규칙과 오류 유형의 세부 범위
- 수정·병합·지급 보류·자동 승인 권한

## 연결별 원문 검토

아래는 저장된 요약에 대한 assistant의 내부 검토다. 새 사용자 질문의 정답 판정이나 독립 전문가 검증이 아니다.
