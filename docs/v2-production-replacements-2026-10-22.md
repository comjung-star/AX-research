# 운영 사례 교체 결과 — 2026-10-22

## 적용한 결정

사용자가 근거 미해결 사례를 제외하고 검증 가능한 실제 운영 사례로 교체하도록 승인했다. 원천을 확인하지 못한 사실을 기존 라벨이나 다른 회사의 성과로 채우지 않았다. v1 및 기존 실험 산출물은 수정하지 않았다.

- 상세 근거 미해결 부모 28개와 구현 상세 보류 AX0098, 합계 **부모 29개**를 활성 후보에서 제외했다.
- 분할 보류 가설 **11개**도 제외했다. 파일럿 제외·범용 분할 기각은 기존 판정을 유지했다.
- **29개 조직, 31개 공식 출처에서 운영 업무 40개**를 새로 구성했다. `replacement_cases_v2.json`에 문제·맥락·구현·운영 도입·성과별 문단 위치, 해석, 불확실성을 남겼다. 문단 위치는 재확인용 설명이며 원문 직접 인용이나 독립 검토자 승인이 아니다.
- `active_candidate_corpus_v2.json`은 **101개 활성 후보**를 모은 재현 가능한 검토본이다. 구성은 새 교체 40 + 분할 재구성 20 + 부모 재구성 22 + 기존 1차 검토 이력 19다. **101개 최종 승인본이라는 뜻이 아니다.**

교체 대장 `replacement_ledger`의 대응은 행정적인 수량 대체다. 대응한 이전 사례에서 새 사례의 사실이나 라벨이 유래했다는 뜻이 아니다. 실제 동일 원천에서 새 업무를 추출한 경우에만 별도의 `parent_v1_case_id`를 기록했다. 가령 Starling의 도움말/지출분석과 기존 상담요약, Sandvik의 신규 영업담당자 교육과 제품지원 검색은 별개 업무다.

## taxonomy와 표본 한계

`strategy_taxonomy_v2.csv`에 새 작업 분류 `S7_GENERATIVE_CONTENT_CREATION`을 추가했다. IBM 고객 스토리 초안, Oneisall 광고 이미지, FyterTech 광고 이미지, Hisense 광고 이미지의 네 조직·네 출처가 같은 '새로운 브랜드 콘텐츠 제작' 패턴을 뒷받침한다. 추출/요약(S3), 판별/마스킹(S4), 상품 추천(S5)과 구분한다. 모든 v2 분류는 아직 `WORKING_V2_NOT_GT`이며 v1 사전은 그대로다.

이 선택은 편의·목적 표집이다. S7 경계를 확인하려고 광고 이미지 사례를 추가했으므로 산업 및 전략 비율을 모집단 분포로 해석할 수 없다. 동일 기업의 다른 업무와 동일 출처를 공유하는 사례도 존재한다. 향후 분할은 조직·출처·부모 계보의 군집을 함께 관리해야 하며, 이를 독립 표본 101개로 간주한 Wald 분석은 아직 수행하지 않았다.

## 접근 감사와 재현

`replacement_source_access_v2.csv`는 40개 사례와 31개 URL의 직접 다운로드 시각·상태·응답 해시를 기록한다. 21개 고유 URL(27개 사례 연결)은 다운로드됐고 10개 URL(13개 연결)은 직접 요청에 실패했다. 후자는 이번 저자 검토에서 웹 리더로 확인한 공식 문단 위치를 사례 파일에 남겼으며, 실패한 다운로드의 해시나 성공 상태를 조작하지 않았다. `parent_case_id` 열은 기존 수집기 형식을 재사용한 것으로 이 파일에서는 **새 사례 ID**다. 다운로드 성공도 내용 검증이나 독립 승인은 아니다. 전문과 캐시는 Git에 공개하지 않는다.

```text
python scripts/build_v2_replacement_release.py
python scripts/validate_v2_dataset.py
python scripts/validate_v2_evidence.py --check-immutable
python scripts/validate_v2_replacements.py
python -m unittest discover -s tests -p "test_v2*.py" -v
```

CI는 생성 파일을 재생성해 불일치를 감추지 않고 저장된 파일이 결정적으로 재현되는지 검사한다. 잘못된 계보, 중복, 운영 근거 누락, 파일럿 성과 승격, 무근거 요인, 사전 근거 불일치, 작성자의 독립 승인 자칭을 거부한다. 이 검사는 구조 검증이며 원천 주장의 진실을 자동 판정하지 않는다.
