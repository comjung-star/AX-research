# 신규 검증 질문·평가 정책 사전 고정

질문은 IT2/인사2/재무·문서2/고객지원1/구매1/제조1/물류1의10개로 확정한다. 기존사례ID나추천결과를찾아질문을작성하지않고사용자가지정한업무영역·기능차이행렬에서새문장을작성했다. 다만같은AI가이전연구와코퍼스를이미알고있어완전히독립적인질문작성이라고주장하지않는다. 기존Dev/공개파일럿과정확·정규화중복및문자유사도를점검하며같은업무기능이포함된의미중복도한계로남긴다. WorkB데이터를비교목적으로열지않는다.

먼저질문·정책SHA와Git커밋을남긴다. 이후질문추가/삭제/수정·평가지표변경·모델튜닝을하지않는다. 새정답은0~3/관련>=2로기존Dev와척도가다르다. 새비교는동일신규질문에서C0vsC1및C1의임베딩중립진단만한다. C2/C3/C_ALL을이번모델로사용하지않는다.

유료API없이원문조건만실행한다. 기존BGE-M3모델/벡터/프로필/가중치와Dense/BM25동점조건을보존하고새질문과필드의벡터만로컬CPU로계산한다. 모델/코드/입력해시·환경을기록한다. 예측전체112순위를먼저저장·봉인하고검토자료에는점수·순위·모델명을표시하지않는다. 새LLM관점생성없음;다중관점은미완료로명시한다.

검토자는같은대화의AI다. 별도독립모델/인간평가자없음. 순위가표시되지않은112개사례의Problem/Task/Context를읽고Action/Object/Output목적을판단한다. 그판단은AI-Silver로만표시하고독립합의정답·Human-Gold로승격하지않는다. 평가도중새예측을열지않는다. 임의의기본0점채우기대신사례별명시판정행렬을기록하고불확실하면ABSTAIN으로남긴다. 원문인용은기존구조화요약이며원출판물의재검증이아니다.

모든112사례가확정판정된질문만전체Recall/F1/nDCG를보고한다. 불완전질문은결과에서삭제하지않고가능한TopK Precision/판정률과미정이유를보고한다. 무양성은Recall/F1미정,IDCG0은nDCG미정. 모델비교는같은지표에같은평가가능질문집합을사용한다. 사람확인필요항목은20개이하로추리며수백건채점을요구하지않는다. 결과후알고리즘/질문/정답을수정하지않는다.
