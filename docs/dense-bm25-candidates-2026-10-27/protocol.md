# Dense+BM25 후보 확보 — 결과 확인 전 고정

기준2140dc27006e0d8d0132b2be20af20f1eb64e5b1. 신규 research/dense-bm25-candidates-20261027.

이번 실험은 후보 검색 채널을 추가하는 효과만 본다.112사례·10질문·108생성관점·3360원점수·1120중앙값·기존임베딩·Dense순위/유사도·기존BM25/결합결과를 읽기 전용으로 보존한다. LLM·API키·추가Dense추론·학습·가중치변경·새라벨·Stage4 열람은 없다. 기존 Kiwi+BM25로 원질문10개와 기존관점108개에 대한 점수만 로컬 계산한다.

## 통제할 두 결합 수준

- 각 검색 경로에서 Dense와BM25의 순위 점수는 `0.5/(60+Dense순위)+0.5/(60+BM25순위)`다. 순위는1부터, 동점은사례ID순이다. 두 원점수를 더하지 않는다.
- 다중관점의 최종 결합은 모든 조건에서 **관점별 점수의 평균**으로 동일하다. Dense만 쓸 때는 `평균(1/(60+Dense순위))`로 이전 실험의 평균RRF와 정확히 같다. 하이브리드는 위 두채널 점수를 관점별로 평균한다.
- 관점M개에서 각 Dense/BM25 경로 비중은1/(2M)이다. 총Dense0.5/BM250.5이며 관점 수에 비례해 커지지 않는다. 중간 하이브리드 순위는 보존하지만 이를 다시 RRF로 변환하는 이중 결합은 하지 않는다.
- 원질문 단독 하이브리드는 위 한경로 점수로 정렬한다. 다중관점 조건에 원질문 경로를 추가하지 않는다. 이전Round-robin·원질문혼합은 과거 참고 결과로만 남긴다. Hybrid의 효과를 계산할 때는 같은 최종결합의 Dense-only와 비교한다.

## 사전 고정 비교표

주실험 A=원질문Single, B=원질문3View, C=원질문Single+BM25, D=다중관점Single, E=다중관점3View, F=다중관점Single+BM25다. 하이브리드의Dense 구조가 모호하지 않게 Single을 주실험으로 고정한다. 보조로원질문3View+BM25와다중관점3View+BM25를추가해 B/E와동일구조비교도한다. BM25단독 원질문·관점검색도보조로저장한다. 좋은Dense 구조만사후선택하지않는다.

원질문 Dense와BM25를먼저재현하고저장된순위와일치검사한다. Dense점수는기존파일을사용하며임베딩파일은ID/형상/해시확인에만사용한다. BM25문서는이전Stage2와같은PTC연결문자열,관점검색문장은저장된branch_query를그대로쓴다. 전체112개를검색하고 초기Top10/20절단이없다. 기존원질문BM25순위가재현되지않으면원인을확인하기전새성능을보고하지않는다.

최종K5/10/20, Silver≥3,18양성쌍을유지한다. Precision평균10질문,Recall/F1평균은양성있는6질문이다.4개무양성질문은평가불가로표시한다. 원질문은한번,동적은질문내3회평균후10질문단위평균한다. 관련발견·유지·신규·누락·순위이동을고정Dense조건에대해계산한다. 후보합집합112개자체를Recall개선이라고주장하지않는다.

필수사례는V21D001의도움말센터답변/HR규정질문답변/제조품질원인분석이다. 두Dense구조·모든회차의Dense/BM25/Hybrid순위와실제Task·기존Silver를함께보존한다. 관점별순위와최종순위는구분한다. BM25의동점·0점·일치토큰을진단하고,같은점수의ID순서가영향을줄수있음을표시하되동점규칙은바꾸지않는다.

다음정밀매핑에넘길구조는원질문/관점등록표,사례PTC등록표,모든후보의Dense/BM25순위·점수·통합기여·출처로정리한다. 정답은평가파일에분리하고모델입력기능에섞지않는다. 정밀매핑알고리즘·새평가·Dense+BM25외후속알고리즘은이번에구현하지않는다.
