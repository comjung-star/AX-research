# 6단계: 17개 사례 범위의 고정 개발 비교

## 질문·범위·종료 기준

기존 개발 질문 20개와 기존 Claude 작성 질문 40개를 모두 재사용한다. 방법별 결과를 보고 질문을 고르거나 다시 쓰지 않는다. 5단계 합성 예시 14개는 조건 처리 동작 진단으로만 별도 보고하며 정확도 평가에 섞지 않는다. 이번 질문과 사례 목록은 이미 관찰한 개발 자료다. 독립 시험이나 논문 최종 성능을 주장하지 않는다. 봉인 Test 15는 열지 않는다.

검토된 4관점·18연결·고유17사례, 관점 선택기 v1.1, 사례 제시기 v1.2를 변경하지 않는다. 원문 112개 중 이 17개만 주 비교의 검색 대상으로 사용한다. 전체112 Dense 결과는 목록 밖 정답과 검색 가능 범위를 설명하는 참고용이며 주 비교와 우열을 직접 주장하지 않는다.

모든 주 비교는 같은17개에서 후보 최대20·출력 최대5다. 가능한 후보가 적으면 채우지 않는다. 정답·가중치·관점·조건 규칙을 결과 확인 후 수정하지 않는다. 한 번의 고정 실행과 재현 검사 후 종료한다. 새 유료 API·새 학습·새 정답 생성은 없다.

## 비교 방법

- A_Dense17: 기존 저장된 단일 Dense 순서에서 동일17개만 남긴다. 기존 표현·점수를 보존하며 재학습하지 않는다. 이는 과거 전체 제안 모델을 재현하는 비교가 아니라 단순 Dense 기준선이다.
- B_Task17: 동일17개 Task 원문과 질문 전체의 기존 로컬 BGE cosine으로 순서를 정한다. 관점 선택·조건 차단·직접/응용 구분은 없다. 사례 목록과 수행 업무를 정리한 기준선이다. A→B에는 사례 표현 변화가 함께 포함되므로 목록 정리만의 순수 효과라고 부르지 않는다.
- C_Catalog17: 5단계 그대로 관점 선택, 관점별 작업문장, 원문 조건 확인, 직접/응용 구분, 늦은 관점별 배정으로 후보를 제시한다.
- D_ViewsNoConditions17: 보조 절제 비교. C와 같은 관점·작업문장·연결과 관점별 배정을 사용하되 입력 조건 차단과 직접/응용 우선순위는 제거한다. B→D는 관점 처리 묶음의 효과, D→C는 조건 확인과 유형 우선순위 묶음의 효과다. 각각 하나의 원자적 기능만 분리한 효과는 아니다.

모든 새 유사도는 기존 로컬 BGE를 사용하고 저장된 벡터로 재현한다. 원본 Dense 점수와 다르게 B의 질문/Task cosine은 새 보조 기준선이다. 새로운 임계값·가중치·최적모델 탐색은 없다.

## 채점과 통계

순위와 소스 지문을 먼저 저장한 뒤 기존 채점표를 읽는다. 20개는 기존 original·working_transfer·464쌍만 부분 재검토한 scoped_consensus 표를 각각 보고한다. 부분 재검토표는 전체 검증된 Gold가 아니다. 40개는 Claude·Gemini의 기존112사례 전수 판정을 각각 사용한다. 두 공급자의 사례별 이진 양성 교집합·합집합도 민감도 자료로만 계산한다. 합집합을 타협 정답으로 채택하지 않는다. 모든 정답표는 AI Silver다.

양성은 기존 grade>=2로 고정한다. 17개 안의 양성 질문에 대해 macro Recall@5, F1@5, nDCG@5, 후보 Recall@20을 계산한다. F1은 실제 제시 수를 사용한다(2TP/(제시수+전체양성수)). nDCG gain은 양성에만 2^grade-1, 그 외0이며 이상 순위는 동일17개다. P@5는 빈칸을 포함한 TP/5, 별도로 실제 제시 후보 중 양성 비율을 보고한다. 양성인데 빈 답변인 질문 수와 양성 없는 질문의 불필요 출력 수도 보고한다. 전부 비우는 방법을 성공으로 판정하지 않는다.

전체112개 양성 중17개에 포함된 비율, 17개 안에 정답이 전혀 없는 질문 수를 반드시 함께 보고한다. 전체112 정답을 분모로 한 Recall/F1도 별도 보고한다. 40개의 두 공급자는 양성 질문 집합이 다를 수 있으므로 동일하게 양성인 질문 집합의 비교도 함께 제시한다. 교집합/합집합 민감도 지표는 참 성능의 수학적 상한·하한이 아니다.

C-A, C-B, D-B, C-D의 질문별 paired bootstrap을 seed20261109·10000회로 계산한다. F1@5·nDCG@5의95%구간과 함께, 정답표별4비교×2지표=8검정에 대한 보수적 Bonferroni 보정 구간(각 구간99.375%)을 저장한다. 이 보정도 개발 선택·정답 편향·여러 정답표 탐색을 없애지 못한다. 표본이 매우 작으면 구간을 과신하지 않는다.

개선 채택은 C의 관련성 개선과 정답 누락의 비악화, 공급자별 일관성, 관점 처리 D-B의 추가 이득이 함께 뒷받침될 때만 검토한다. 불충족이면 어떤 조건에서 도움이 되거나 실패했는지 기록하고 규칙을 고쳐 반복하지 않는다. 성공/실패 여부와 관계없이 이번 단계는 비교 결과 보고로 종료한다.

## 조건·근거 진단의 한계

야간/PDF/음성 등의 명시 조건 근거 부족 후보 수는 동결 메타데이터 기준 진단이다. 새 방식과 같은 메타데이터로 평가하므로 독립 정확도 증명이 아니다. 복수 작업의 조건 적용이 불명확한 질문은 전역 조건으로 잘못 채점하지 않고 별도 미평가로 남긴다. 원문 요약에 미기재는 실제 기능 불가능과 구별한다. 관점 coverage도 독립 관점 Gold 없이 의미 정확도로 계산하지 않는다. 소스 인용·조건 확인 기록과 관점 선택/미선택 현황을 보존한다.
