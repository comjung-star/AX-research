# 메인화면 연구 소개 팝업 · 2026-10-25

바탕화면 **AX나침반.exe**의 메인화면 오른쪽, 84개 사례 안내 아래에 두 버튼을 추가했습니다. 이미 열어둔 브라우저는 새로고침하면 됩니다.

## 1. 아키텍처 한눈에 보기

자연어 업무문제 → AI 관점 분해 → 문제·업무·맥락의 Dense 비교 → 관점별 독립 Top-K → 선택 사례 기반 적용 전략 → 실행 순서·근거·한계의 흐름을 그림으로 설명합니다.

3개 가지는 이해를 돕는 예시이며 실제 관점 개수는 입력에 따라 달라집니다. 순위를 하나로 합치지 않는 점을 강조했습니다. 키 없는 데모, 선택적 QCI 비교, 교수님 제안의 전체 연구 목표는 펼침 설명에서 구분해 확인할 수 있습니다.

## 2. 현재 논문 상황 요약

- 연구 목적과 RQ1~4를 쉬운 말로 정리했습니다.
- v2.3 frozen 사례 84개, Dev 질문 10개·동적 관점 97개, AI-Silver 관점–사례 8,148쌍 구축 이력을 표시했습니다.
- 최신 동일 기준 Dev Recall@10 비교: Dense 47.64%, 256d QCI 27.73%, Dense+QCI 보정 45.33%. 사용자 만족도나 정확도로 표시하지 않았습니다.
- 기존 v1 100개 사례의 오프라인 Wald·근거 경로 Dev 실험과 v2.3의 미완료 통합 효과 검증을 구별했습니다.
- 사용자 검토·사람이 판정한 독립 정답·새 질문 Test·근거 결합 효과 검증을 다음 과제로 정리했습니다.
- 완성 원고의 집필·제출 여부는 저장소만으로 확인할 수 없어 논문 완료율을 만들지 않았습니다.
- 기준 커밋의 연구 문서 링크를 포함했습니다. 요약은 자동 갱신이 아닌 2026-10-25 확인 기준입니다.

## 사용과 보존

팝업은 ×, 맨 아래 닫기, Escape, 바깥 배경 클릭으로 닫습니다. 입력과 결과를 바꾸지 않으며 키·외부 통신·API 요금 없이 열립니다. 작은 화면에서는 관점 그림과 카드가 한 열로 배치되도록 구성했습니다.

기존 검색·추천·평가 저장 기능과 frozen 84개·연구 실험을 보존했습니다. Windows에서 이전 서버 여러 개가 같은 포트에 남는 문제도 포트 독점 바인딩으로 방지했습니다. 이 프로젝트 실행기에서 나온 중복 프로세스만 정리하고 최신 서버 하나로 다시 실행했습니다. 저장된 평가 DB는 변경하지 않았습니다.

## 검증 방법

```powershell
$env:PYTHONPATH = 'src;.'
./.venv/Scripts/python.exe -X utf8 -m pytest -q --junitxml=docs/prototype-validation/tests.xml
node --test tests/prototype_research_ui.test.cjs
```

팝업 대상·접근성 연결·ID 중복·그림의 독립 가지·연구 요약의 범위·정적 파일 허용 목록·열기/닫기/배경 클릭·서버 중복 바인딩을 자동 검증합니다. 브라우저에서 실제 두 팝업과 Escape 후 포커스 복귀, 그림·요약의 표시를 확인했습니다.

**검증 결과: Python 206개 + JavaScript 3개 통과.** 기존 Torch 경고 1건 외 실패가 없고, 최종 브라우저 오류 로그도 없습니다. 바탕화면 실행파일을 다시 실행해도 동일 서버를 재사용하는 것을 확인했습니다. [브라우저 확인 기록](prototype-validation/research-popup-verification.json) · [Python 테스트 원시 결과](prototype-validation/tests.xml).
