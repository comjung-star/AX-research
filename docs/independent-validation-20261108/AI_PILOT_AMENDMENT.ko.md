# 사람 검토가 없는 AI 예비 검증으로의 변경

사용자가 클로드 질문 생성과 사람 없는 진행을 명시적으로 요청해, 기존 사람 작성·검토 계획을 AI 예비 검증으로 변경했다. 사람용 빈 서식을 실제 제출이나 사람 Gold로 채우지 않는다. 유료 호출 금지의 기존 상태는 이번 사용자 승인 범위에서 제한적으로 변경했고 전체 파일럿 상한은2달러로 정했다. 기존 연구 배치나 이전 Test15는 재개하지 않았다.

질문 작성자는 Claude Sonnet5.5다. API 요청에는 일반적인10개 업무 분야와 질문 형식만 있으며 기존 사례·질문·점수·정답·연구 대화를 포함하지 않았다.40개 질문을 한 번 생성하고 원본을 보존했다. 모델 응답 ID, 사용량, 생성 요청 해시와비용을 남겼다. 기존38개 개발 질문과 정규화 정확 중복0개,10개 분야별4개를 확인했다. 문자 유사도는 보조 점검이며 현실성이나 의미적 독창성의 인간 인증이 아니다. 질문을 점수에 맞춰 삭제하거나 다시 생성하지 않았다.

평가자는 Claude Haiku5.5와 Gemini3.1Flash-Lite다. 각 질문의112사례 전부를 독립 API 요청으로 판정하며, 추천 방식·순위·이전 정답·작성자 정보를 숨겼다. 두 평가자는2개 제공사이며 작성자와 한 평가자는 Anthropic을 공유한다. 이것을 인간 Gold나 완전 독립적인 진실 판정이라고 표시하지 않는다.

첫 채점 실행에서는 Claude의기본thinking이4096출력 한도를 소모하고 Gemini가 일부 관련 사례만 반환하는 기술 문제가 있었다. 해당 실행을 중단하고 원본·실패·미확정 비용을 보존했다. 두 번째 실행은 같은0~3관련성 기준을 유지하면서 Claude의thinking을끄고 전체112위치의 구조화 응답을 요구했다. 입력 Task의짧은 발췌는 출처 연결용이며 모델이 직접 고른 증거 인용이라고 표시하지 않는다. 소규모 사전 점검에서 전체112위치 반환을 확인한 뒤 나머지를 실행했다. 정상 판정을 좋은 점수가 나올 때까지 재생성하지 않았다. Gemini HTTP429로 거절된7요청만 별도 사전 기록 후1회 복구했고, 원래 유효 응답이 있던 요청은 복구 대상에서 제외했다.

모형 비교는 기존 동결 원문 Dense/E/원문 토큰/관점 토큰4가지다. 관점 생성에는 기존 GPT-6 Luna와 core_preservation_prompts.py를 그대로 사용해X추출+E관점을40질문×3반복=120조합에서 생성했다. 새로운 모델이나 Claude 관점으로 바꾸어 기존 E인 것처럼 표시하지 않았다. 원래 BM25 토큰화와 고정 색인 통계의 조합을 재현하며, 소스 파일 자체를 덮어쓰지 않고 추론 프로세스에서만 역사적 토큰 함수를 사용한다.

추론은 네트워크를 차단한 로컬 실행이며 blind_review·labels·qrels·기존Test 경로 열기를 거부한다. 예측 파일을 먼저 봉인한 뒤 별도 실행에서 각 평가자 정답과 두 평가자의 이진 합의를 분석한다. 두 모델이 같은 관련/비관련 판단을 내린 쌍은 보수적으로 작은 등급을 사용하고, 이견·미판정은ABSTAIN으로 남긴다. 정상·보류·제외 질문 수를 함께 보고하며, 질문·사례 쌍4480개를4480개 독립 질문처럼 다루지 않는다.

합격 판단은 원래 계획의6대비·Bonferroni 보정 구간을 유지한다.40질문은 검정력이 보장된 최종 시험이 아니라 예비 검증이다. 이번 새 결과를 보고 후보10의 가중치나 규칙을 조정하면 이 자료는 이후 개발 자료로 분류한다. 사람 검증 부재를 해결한 것처럼 주장하지 않는다.
