# 관점 선택기 실행 예시

기능 검사용 합성 질문의 실제 출력이다. 실제 사용자 평가나 추천 정확도는 아니다. 사례 추천은 생성하지 않는다.

## extract_and_compare

> 청구서에서 금액을 뽑고, 계약 금액과 다른 항목을 찾아주세요.

**판정:** 일부만 지원

**선택:** P02 비정형 자료를 수기로 옮기고 업무 정보로 정리하는 부담, P03 업무 자료를 기준·다른 자료와 대조하는 검증 부담

- P02 원문 근거: 청구서에서 금액을 뽑고, 계약 금액과 다른 항목을 찾아주세요
- P03 원문 근거: 청구서에서 금액을 뽑고, 계약 금액과 다른 항목을 찾아주세요
- 보류 P01: 작업 표현은 있으나 이 관점에 맞는 대상의 근거가 부족합니다.

## search_please

> 출장 기준을 설명한 사내 규정을 찾아주세요.

**판정:** 선택 근거 확인

**선택:** P01 업무 지식이 길고 분산돼 필요한 근거를 찾는 데 시간이 걸림

- P01 원문 근거: 출장 기준을 설명한 사내 규정을 찾아주세요

## service_night

> 야간 문의가 누락됩니다. 고객 문의에 응대하고 싶습니다.

**판정:** 일부만 지원

**선택:** P04 문의량·접수 시간대가 응대 가능 용량을 넘어 대기·누락이 생김

- P04 원문 근거: 고객 문의에 응대하고 싶습니다 / 야간 문의가 누락됩니다
- 보류 P03: 작업 표현은 있으나 이 관점에 맞는 대상의 근거가 부족합니다.

## forecast_outside

> 다음 달 상품 수요를 예측해주세요.

**판정:** 네 시범 관점의 지원 범위 밖

**선택:** 없음

- 미지원 요구: 미래 예측은 아직 상세 검토한 네 관점의 지원 범위가 아닙니다.

## vague_document_work

> 문서 처리를 잘하고 싶습니다.

**판정:** 판단 보류

**선택:** 없음

- 보류 P01: 찾을 문서·지식과 검색 요구를 확인해야 합니다.
- 보류 P02: 문서를 찾는지, 요약하는지, 항목을 추출하는지 구분해야 합니다.
- 보류 P03: 무엇을 어떤 기준·다른 자료와 확인할지 근거가 필요합니다.

## missing_reference

> 청구서 내용이 맞는지 검증해주세요.

**판정:** 판단 보류

**선택:** 없음

- 보류 P03: 확인 대상은 있으나 대조 기준·다른 자료의 근거가 부족합니다.

## forbid_extract

> 청구서의 항목을 추출하지 마세요. 이미 있는 청구서 금액을 계약과 대조해주세요.

**판정:** 선택 근거 확인

**선택:** P03 업무 자료를 기준·다른 자료와 대조하는 검증 부담

- P03 원문 근거: 이미 있는 청구서 금액을 계약과 대조해주세요
- 보존한 제약: 청구서의 항목을 추출하지 마세요

## partial_write

> 청구서 금액을 계약과 대조하고 자동 수정해주세요.

**판정:** 일부만 지원

**선택:** P03 업무 자료를 기준·다른 자료와 대조하는 검증 부담

- P03 원문 근거: 청구서 금액을 계약과 대조하고 자동 수정해주세요
- 미지원 요구: 수정·거래·자동실행은 선택 관점과 별도의 기능·권한 검토가 필요합니다.

## historical_not_current

> 과거에는 문서를 검색했습니다. 지금은 다음 달 수요를 예측해주세요.

**판정:** 네 시범 관점의 지원 범위 밖

**선택:** 없음

- 미지원 요구: 미래 예측은 아직 상세 검토한 네 관점의 지원 범위가 아닙니다.

## same_industry_not_same_work

> 고객 문의가 많아 대기가 깁니다. 지금 필요한 것은 상담 대화록 요약입니다.

**판정:** 네 시범 관점의 지원 범위 밖

**선택:** 없음

- 미지원 요구: 요약은 검색·항목추출·대조검증·문의응대와 별도 작업입니다.

## human_approval_preserved

> 청구서 금액을 계약과 대조해주세요. 최종 수정은 담당자의 승인이 필요합니다.

**판정:** 선택 근거 확인

**선택:** P03 업무 자료를 기준·다른 자료와 대조하는 검증 부담

- P03 원문 근거: 청구서 금액을 계약과 대조해주세요
- 보존한 제약: 담당자의 승인
