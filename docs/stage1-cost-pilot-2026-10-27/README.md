전체프롬프트1요청당입력범위는GPT1341~2324, Gemini1453~2360, Claude1586~3588토큰이다. 모델마다토크나이저가달라같은문장의토큰수가다르다. 위전체입력수에는각요청의평가규칙·질문·참조문구·구조화텍스트가포함된다.

초기토큰집계사전점검6요청은별도로보존했다. OpenAIJSON모드는사용자입력에도JSON출력을명시해야집계요청이성공했으므로, **생성평가전에**모든모델의공통사용자입력끝에`Return JSON.`을추가하고프롬프트v2를고정했다. 최종678개집계와6개시험생성은모두v2다. 초기에는생성평가를하지않았고, 이전집계/실패기록은루트의`plan.json`, `counts/`, `count_failures/`에보존했다. 총집계API요청은초기6+최종678=684다.

집계는문자수/4의추정이아니다. OpenAI`/responses/input_tokens`, Claude`/messages/count_tokens`, Gemini`:countTokens`를사용했다. Claude는공식적으로집계치를추정값으로설명하며실사용과차이가생길수있다. 이번6개시험에서차이는0이었지만모든미래요청의청구가동일하다는보장은아니다. [OpenAI집계](https://developers.openai.com/api/docs/guides/token-counting), [Claude집계](https://platform.claude.com/docs/en/build-with-claude/token-counting), [Gemini집계](https://ai.google.dev/gemini-api/docs/tokens).

## 3. 실제 시험 비용과 전수 비용 예상

**수치의 의미:** 시험 비용은 실제 사용량에 표준 요율을 적용한 값이다. 전체 입력 비용은 모든 프롬프트의 토큰 집계에 근거한다. 전체 출력은 아직 생성하지 않았으므로, 미래 비용을 확정된 정확한 청구액으로 표현할 수 없다.

전수 예상 출력은 원질문과 참조관점의 시험 토큰/쌍을 각각 1120/3360쌍에 가중 적용했다. 두 범위가 같은 비중인 시험 40쌍의 단순 평균을 전체에 곱하지 않았다. 예측 출력은 GPT 110936, Gemini 108584, Claude 204680토큰이다. 이전의 '쌍당 입력1000/출력150' 가정을 실제 짧은 근거와 20쌍 묶음의 사용량으로 바꾼 결과다. 더 저렴한 모델로 몰래 교체한 결과가 아니다.

보수상한은각요청의입력을API집계×1.05+시험양의최대차이+32토큰으로늘리고, 출력은각요청최대1408토큰전부를쓴다고가정했다. 전체224요청의최대출력합은315392토큰/모델이다. 여기에상한비용의25%를재시도여유로추가했다. 할인가/Batch/무료tier/캐시혜택을미리당겨적용하지않았다.

공식요율: [GPT-6Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [Gemini](https://ai.google.dev/gemini-api/docs/pricing), [ClaudeHaiku4.5](https://platform.claude.com/docs/en/models/haiku-4-5/overview).

## 4. Claude $5 한도 계산과 차단

사용자가충전금$5를알렸으며현재계정잔액은독립적으로조회하지못했다. 이번계산은이연구작업의예산장부이며다른앱/키/조직사용자의계정전체소비를차단하는설정은아니다.

| 항목 | USD |
|---|---:|
| 전체4480쌍보수상한+25%재시도 | $2.67862375 |
| 이번40쌍시험 | $0.01554400 |
| 과거Claude연결시험사용량추정 | $0.00003200 |
| 사용하지않는추가안전여유 | $0.50000000 |
| 예산상필요액 | **$3.19419975** |
| $5대비남는여유 | **$1.80580025** |

따라서 현재 프롬프트·20쌍 묶음·최대출력1408·현 요율 조건에서는 **비용상 충분히 가능**하다. 시험40쌍을 전수에서 다시 평가하는 비용까지 보수적으로 중복 포함했다. 프롬프트 변경, 재채점, 추가 검증 또는 다른 계정 사용자의 소비를 무제한으로 허용하는 견적은 아니다.

시험 도구는 Claude 생성 예산을 $0.25로 제한했다. 요청 전에 입력집계×1.10+64의 입력 여유와 최대 출력 비용을 먼저 예약하고, 누적 예약이 한도를 넘으면 호출하지 않는다. 실패나 시간초과가 발생하면 사용량을 확인할 때까지 최대 예약을 유지하고 자동 재시도하지 않는다. 이번 생성6요청은 모두 사용량을 받아 불명 비용은 0이다. 지정한40쌍 밖의 배치는 거부하며, 명령행에 전수 생성 단계도 없다.

실제전수도구를추가할때는계정실제잔액확인후$0.50를분리보관하고, 누적지출+현재진행요청예약+다음요청상한이잔여허용액을넘기전에차단해야한다. 프롬프트・모델・출력상한이바뀌면토큰집계와승인을다시진행해야한다. 이번에계정의자동충전이나결제설정은바꾸지않았다.

## 5. 시험 판정 결과와 실행 판단

- 세모델모두40/40판정을반환했다. JSON구조・등급범위・항목번호・누락검사통과. 총120개AI판정이며인간검증정답이아니다.
- 세모델등급완전일치 **10/40=25%**, 양성/음성완전일치 **28/40=70%**, 관련성임계값을넘나든이견 **12/40=30%**다. 나머지18쌍은이진판정은같지만등급이다르다. 이는정확도나모델오답률이아니다.
- >=3양성은GPT1/40, Gemini7/40, Claude10/40이다. 모델별판정엄격도차이, reference해석・맥락일치기준・항목간혼동가능성을검토해야한다. 예: V21D001/reference고객문의병목/AXV2H_0003_01은1/0/3점이며, 직접문의처리관련성과일반문서검증의반복작업유사성을모델들이다르게설명했다. 어느점수를사람정답으로결정하지않았다.
- 영어근거12단어이내지시를초과한것은GPT6개, Gemini0개, Claude19개다. 실무validator는최대20단어를허용했고관측최대는각14/12/17단어였다. **JSON형식통과와모든지시준수는다르다**. 비용은잘라낸가짜출력이아닌실제전체usage로계산했다.
- reference는여전히draft이며의미중복・원문검증/불일치조정・사람승인도완료하지않았다. 전수실행전12개경계이견과근거를검토하고기준을명확히해야한다. 프롬프트를수정하면이전결과와분리하고다시실측해야한다.

**권고결론:예산은통과,전수생성은보류.** 다음단계는12쌍의이견근거를블라인드검토하고판정기준을점검하는것이다. 전체평가를자동으로진행하지않았다.

## 6. 재현・증거・보존
