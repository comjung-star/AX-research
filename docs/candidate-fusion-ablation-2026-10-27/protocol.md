이번에는 Stage1~3을 다시 실행하지 않는다. 모든 원문·점수·중앙값·108개 생성 관점·임베딩·216개 분기 순위와 유사도를 읽기 전용으로 재사용한다. 새 모델 호출, 키 읽기, 임베딩 추론, 정답 변경, 후보 수집, 파인튜닝, P/T/C 가중치 변경, Stage4 열람이 없다.

## 사전 고정한 세 조건

1. **Round-robin**: 기존 `branch_balanced_unique`와 기존 관점 순서 그대로다. 새 구현의 Top20이 과거 결과와 완전히 같은지 확인한다.112개까지 계속 선택한 순위는 순위 이동 진단용이며 첫20개를 바꾸지 않는다.
2. **Candidate Union + RRF**: 각 관점 전체112개를 모아 중복 없는112개 후보를 구성한다. 순위는1부터 시작한다. 각 사례의 점수는 `평균(1/(60+관점별 순위))`다. 관점 수가 늘어도 전체 경로 비중이 커지지 않게 평균한다. 상수60을 바꾸지 않는다.
3. **원질문 + 다중관점 RRF**: 원질문 경로는 `1/(60+원질문 순위)`, 다중관점 경로는 위 평균 점수다. `0.5×원질문 경로 + 0.5×다중관점 경로`로 합친다. 각 관점의 최종 비중은 `1/(2×관점 수)`이며 원질문 전체 비중은 항상1/2이다. 원래 코사인 유사도와 RRF 점수를 섞지 않는다.

점수는 정확한 분수로 계산해 관점 합산 순서나 부동소수점 오차가 동점을 바꾸지 않도록 한다. 동점은 사례ID 오름차순이다. 후보를 미리 Top10/20으로 자르지 않는다. 각 사례의 원질문 순위·관점별 순위·원래 유사도·RRF 항·정규화된 기여·합계·최종 순위를 보존한다.

두 Dense 구조 각각 세 조건을 비교한다. 기존 원질문 Single/3View는 한번만 보고한다. 동적 조건은 각 질문의3회 결과를 먼저 평균한 뒤 원질문 기준으로 평균한다. 평가K5/10/20, 관련기준3, Silver18양성쌍을 고정한다. Precision 평균은10질문, Recall/F1 평균은 양성 있는6질문이다. Q2/Q5/Q7/Q9의 Recall/F1은 미정이다.

## 원인 판별 범위

- 모든 분기가112개를 가진 상태에서 후보 합집합은 언제나112개다. 이 사실 자체를 좋은 검색 능력으로 해석하지 않는다.
- 과거 원질문 TopK 양성이 RR에서 누락됐으면 각 분기의 실제 순위와 RR 커서·중복 건너뛰기·선택 순서를 추적한다. 관점 내Top5/10/20 포함 비율은 추가 진단으로만 계산한다.
- 같은 분기 순위를 고정하고 RRF로 바꿨을 때 되찾는 사례는 이번 결합 방식 변화의 관찰된 효과다. 되찾지 못한 사례를 모두 RR 탓으로 돌리지 않는다. 원질문 경로를 추가하면 순위 정보 입력도 하나 추가되므로 ‘결합 규칙만 같은 입력으로 바꾼 효과’와 구분한다.
- V21D001의 도움말센터 답변 사례 `AXV2N_0121`, HR 질문응답 사례 `AXV2N_0124`를 모든 반복·두 구조에서 따로 추적한다. 회차1 Single의 과거 순위3→누락,25→13을 먼저 재현한다.
- 원문과 순위에서 직접 계산되는 사실, 이번 고정 조건의 반사실 비교, 관점 품질·의미 보존에 관한 추정은 별도 표시한다. 결과를 보고 상수·비중·관점 순서·정답을 바꾸지 않는다.

AGENTS.md의 RRF 금지는 제안 모델에 대한 원칙으로 유지한다. 이번에는 사용자가 명시적으로 요청한 결합 원인 분석 비교 조건이며, 교수님이 RRF60이나1:1을 승인했다고 표현하지 않는다. 학습형 Query–Case 정밀 재평가기까지 구현한 실험이 아니다. 개선되더라도 Dev AI-Silver 관찰이며 사람Gold·독립Test 일반화 주장이 아니다.
