## 2단계 — 직접 수행 업무와 전이 전략을 분리

서로 다른 두 정답 버전을 보존했다.

1. **직접/업무 기능 기준(이전 버전):** 관련 쌍 38/2,240. 평가 가능한 질문 9/20.
2. **전략 전이 가설 포함(이번 버전):** 조건부로 관련 후보 16쌍 추가 → 관련 쌍 54/2,240. 평가 가능한 질문 16/20.

추가 16쌍은 각기 근거로 삼은 **사례의 Task/구현 내용**, **전이 가능한 핵심 처리 방법**, **새 업무에 필요한 구체적인 수정**, **그대로 옮길 수 없는 한계**를 적었다. **모든 원래 판정은 유지**했으며 16개만 별도 overlay에서 관련으로 가정했다.

- 전이의 예: 공장 설비의 시계열 위험 예측 → 공급업체 납기 지연의 위험 점수 산출. 데이터와 정답 레이블을 새로 설계해야 하므로 성능 전이는 입증하지 않는다.
- 배제의 예: 버그 티켓 담당팀 라우팅 ≠ 방문지 순서를 바꾸는 배송 경로 최적화. 같은 '배정' 단어만으로 관련 판정 금지.
- 배제의 예: 생산 이미지 속 인물 익명화 ≠ 문서의 주민등록번호·연락처 문자열 검출. 보호 목적이 비슷해도 입력 모달리티와 핵심 탐지 방식이 다르다.

이번 평가는 **GPT-6 1개 평가자의 실험용 가설**이다. 앞선 149개 재검토도 GPT-6 판단이고, 그 밖의 2,091개도 동일 공급자 AI 3회 다수의견이다. 따라서 '독립 정답 검증 완료', '전문가 Gold', '3종 모델 합의'라고 표현하면 안 된다. 추천 순위를 이전 턴에서 일부 열람한 상태이므로 완전 블라인드 평가라고도 주장할 수 없다.

## 3단계 — 정확히 같은 Validation 20문항·112사례·저장된 순위 비교

검색/임베딩/모델을 수정하거나 다시 실행하지 않았다. 기존에 실제 생성된 A(원문 단일), C(다중관점), E(기존 핵심 보존) 순위를 사용하고 이전 실험의 I2(E 75%+C 25%)·I3(E 75%+A 25%) RRF 조합을 재계산했다. **I2/I3는 과거 진단용 결합 기준선이지 책임님의 제안 모델 자체가 아니다.** 동일 질문 20개, 동일 사례 112개, 동일 상위 5개 표시 예산, 반복 3회의 평균이다.

### 모든 20문항 공통 지표: Precision@5

| 방법 | 이전 직접 기준 | 전략 전이 가설 포함 |
|---|---:|---:|
| A 단일 | 14.00% | 18.00% |
| C 다중관점 | 13.33% | 18.00% |
| E 기존 | 13.67% | 17.67% |
| I2 결합 | 14.00% | **18.33%** |
| I3 결합 | 14.00% | 18.00% |

**주의:** 열 사이의 차이는 모델 개선이 아니라 정답 판정 기준 변경의 효과다. 모든 20문항에 상위 5개 추천을 내보내는 구조라 정답 후보 없는 질문의 Precision@5는 0으로 포함했다.

### 관련 사례가 1개 이상 있는 공통 16문항

| 방법 | F1@5 | nDCG@10 | Recall@5 |
|---|---:|---:|---:|
| A 단일 | 24.17% | **43.58%** | 34.94% |
| C 다중관점 | 24.56% | 43.42% | 38.69% |
| E 기존 | 23.95% | 41.17% | 37.37% |
| I2 결합 | **25.07%** | 41.89% | **39.11%** |
| I3 결합 | 24.47% | 41.92% | 38.07% |

F1@5와 nDCG@10은 정답이 없는 4개 질문에서 정의되지 않으므로 그 4개는 제외했다. 기존 9문항의 평균과 이번 16문항의 평균을 '모델 성능 증가'로 해석해서는 안 된다. 참고용으로만 0건 질문의 F1을 0으로 두는 별도 **20문항 전용 진단 지표**도 JSON에 기록했으며, 일반적인 F1과 혼동하지 않는다.

### 통계적 불확실성 및 남은 검색 실패

고정 20문항의 F1 진단값(E 대비, 없는 정답은 0으로 처리하는 명시적 규칙)으로 10,000회 질문 단위 재표본화한 95% 참고구간:

| 방법 | E 대비 F1 차이 | 95% 구간 |
|---|---:|---:|
| A | +0.18%p | −4.58~+4.46%p |
| C | +0.49%p | −2.04~+4.08%p |
| I2 | +0.89%p | 0.00~+2.26%p |
| I3 | +0.42%p | 0.00~+1.25%p |

모두 0을 포함한다. 따라서 어떤 방법이 우수하다는 **통계적 결론은 보류**한다. 또한 VQ004(보안 접근 이상), VQ006(납기 지연 예측), VQ019(문서 개인정보 탐지)의 새 전이 후보는 **어떤 방식으로도 Top-5에 등장하지 않았다**. VQ001의 새 영상 검사 전이 후보 2개도 Top-5에서 발견되지 않았다.

**연구적 해석:** '관련 사례 없음' 현상의 일부는 좁은 정답 기준에 의한 것이지만, 이후에도 **상위 추천에서 관련 사례를 놓치는 검색 실패**가 분명히 존재한다. 정답을 바꾸는 것만으로 추천기가 좋아진 게 아니다.
