## 2. 검증 A — 무엇을 검색하느냐가 중요했나?

**기존 TITLE+Round-robin 45.30% → 원문+관점+설명+Round-robin 54.01%**로 **+8.71%p** 상승.

다만 단순히 제목에 **설명만 붙이면 오히려 -2.35%p** 하락(42.95%). 따라서 관점에 '텍스트를 더 많이 넣으면 항상 좋다'는 주장은 반증된다.

10개 질문을 한 단위로 보았을 때 원문 추가가 **개선 5개·하락 3개·동률 2개**. 질문단위 10,000회 paired bootstrap 차이 95% 구간 **[-0.73%p, +20.23%p]**로 0을 포함한다. 개발용 탐색 결과이며 독립 Test 우수성의 근거로 해석하지 않는다.

**질문별 중요한 사례**
- `V21D005` 전사 데이터 분산·분석 기준 불일치: **16.67% → 66.67% (+50.00%p)**. 전체 개선폭에 큰 영향을 줌.
- `V21D002` 이메일 스레드·후속조치: **40.00% → 60.00% (+20.00%p)**.
- `V21D008` 수요·생산량 예측: **80.00% → 100% (+20.00%p)**.
- `V21D007` 구매·견적 자료 비교: **44.44% → 33.33% (-11.11%p)**로 악화.
- `V21D006` 상품 속성/검색: **58.33% → 50.00% (-8.33%p)**로 악화.

**해석:** 현재 구현의 **짧은 관점 제목만 임베딩**하는 방식이 원래 문제의 핵심 맥락을 잃을 가능성은 수치로 뒷받침된다. 그러나 다른 입력 조합 또는 정보량 변화의 영향도 있으므로 단일 원인이라고 확정하지 않는다.

## 3. 검증 B — 관점별 결과를 합치는 방식이 문제였나?

기존 입력 TITLE에 대해:
- Round-robin **45.30%**
- RRF(Reciprocal Rank Fusion, rank 상호 보강) **47.87%**
- 차이 **+2.57%p**, 질문별 개선 5·하락 4·동률 1; bootstrap 구간 **[-2.41%p, +7.78%p]**, 효과의 일관성 없음.

원문+관점+설명 입력에 대해:
- Round-robin **54.01%**
- RRF **53.33%**
- RRF가 **0.67%p 더 낮음**.

**해석:** 현재 데이터에서 결합 방법 교체만으로 문제를 해결한다는 근거는 부족하다. RRF는 진단 비교군이며 교수님이 요구한 관점별 Branch 보존 구조를 무조건 대체하는 최종안이 아니다.

## 4. 결정적인 추가 관찰 — 다중 관점 고유 효과인가?

최고 수치 54.01%는 기존 단일 Dense 53.32%보다 **0.69%p 높을 뿐**이다.

질문별로 두 모델을 비교하면:
- 다중 관점 우위 **1개**
- 단일 Dense 우위 **1개**
- Recall 동률 **8개**
- 상위 10개 실제 검색 사례도 질문×반복 전체에서 평균 **7.83개가 중복**.

**중요:** 원래 문제를 매 Branch에 넣으면 Branch들이 단일 Dense와 비슷한 결과를 낼 수 있다. **관점 분해를 통해 새롭고 관련성이 높은 사례를 추가로 회수했는지는 별도의 관점별 증분 분석이 필요**하다. 지금의 +0.69%p만으로 교수님 제안 다중관점 아키텍처의 이점을 입증했다고 해석하지 않는다.

## 5. 교수님 아키텍처와 연관된 판정

1. **검색 입력:** 긴 원문 맥락을 보존하는 것은 유효한 개선 후보. 제목과 설명만 쓰는 방식은 이번 실험에서 오히려 악화.
2. **결과 결합:** 현 단계에서 기존 Round-robin 방식 교체 근거 없음. RRF는 일부 조건에서 개선, 다른 조건에서 하락.
3. **Branch의 존재 의의:** 관점 구분을 유지하되, 각 관점이 **원문에 없는 새로운 상관 사례를 회수하는지**와 중복도·정답 손실을 동시에 확인할 필요.
4. **최종 실험 주장:** `RQ1`의 '다중 관점이 단일 Dense/GPT-only보다 일관되게 우수하다'는 가설은 **현재 개발 데이터 기준 여전히 미입증**. 데이터 라벨이나 평가 대상 사례를 임의 조정해 유리한 결과를 만들지 않는다.
5. **비교 공정성:** 코퍼스 및 BGE-M3 문서 임베딩을 동일하게 유지했으며, 97개 관점도 재생했다. 원래 Stage 1의 개별 branch 97개, 최종 30개 ranking 및 지표가 **정확히 재현됨**. 검색 조건 3×결합 조건 2의 6개 조합 모두 보고.
