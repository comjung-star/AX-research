# Dense 보존 방식 개발 결과 — 2026-11-08

## 결론

관점을 활용하면 기존 Dense가 놓친 정답 후보를 일부 추가로 찾았다. 그러나 그 후보를 최종 추천 5개에 올리는 방법은 아직 개선되지 않았다. 현재 결과는 **후보 검색 단계의 개선 가능성**이며, **최종 추천 성능 개선의 입증**은 아니다.

기존 개발 질문 20개와 사례 112개, 저장된 점수·토큰·관점만 사용했다. 신규 40개 AI 평가 자료와 Test15는 이번 개발에 사용하지 않았다. 유료 API 호출은 0회다. 운영 모델을 교체하지 않았다.

## 무엇을 바꾸고 확인했나

1. Dense 상위 3개를 보호하고 나머지 2자리를 원문 토큰 점수로 교체했다. 정답을 잃는 경우가 생겼으며, 정답표 세 버전에서 일관된 F1 개선이 없었다.
2. 추가 후보의 행동·대상 점수가 교체 대상보다 모두 높아야 한다는 조건을 넣었다. 그래도 F1이 떨어졌다. 이 점수들은 기존 임베딩의 유사도이며 사람이 확인한 의미 일치 정답이 아니다.
3. 최종 순위 변경을 멈추고 후보 검색 효과만 분리했다. Dense 상위 10개를 유지하고 후보 20개 중 하위 일부만 조건에 따라 교체했다. 각 관점에서 최대 20위까지만 탐색했다. 관점별 출처는 기록에 남겼다.

3단계는 최종 추천기를 대체하는 제안이 아니라 후보 보완 실험이다. 상위 10개가 Dense와 같으므로 F1@5와 nDCG@10도 정확히 같다. 이 동일성 자체를 성능 개선으로 주장하지 않는다.

## 후보 20개에서 정답을 찾은 비율 — Recall@20

|정답표 버전|양성 질문 수|Dense|원문 토큰 보완|원문 BM25 보완|관점 후보 보완|
|---|---:|---:|---:|---:|---:|
|working_transfer|16|65.02%|65.49%|65.02%|66.67%|
|original|17|60.89%|62.25%|62.46%|65.35%|
|scoped_consensus_464_only|18|61.87%|60.25%|61.87%|67.66%|

세 버전은 같은 질문에 대한 서로 다른 정답표다. 독립 실험 세 번이 아니다. 모두 AI 기반 Silver이며, scoped 버전도 전체 2,240쌍 중 464쌍만 별도 검토되었고 나머지는 기존 판정이다. 양성 사례가 없는 질문은 Recall/F1/nDCG 평균에서 제외했다. 반복 3회의 점수를 질문별로 평균해 집계했다.

관점 보완과 Dense의 Recall 차이(퍼센트포인트), 질문 단위 paired bootstrap 95% 구간:

- working: +1.65, 구간 −1.04~+5.12
- original: +4.46, 구간 +1.02~+8.40
- scoped: +5.79, 구간 −0.46~+14.81

원문 토큰/BM25 보완과의 비교 구간은 모든 버전에서 0을 포함했다. original의 Dense 비교만 0을 제외하지만, 개발 자료를 반복 확인했고 비교도 여러 번 했으므로 확정적 우위의 근거로 쓰지 않는다. 후보 수와 최종 출력 수는 같지만 관점 방식은 검색 경로가 더 많다. 계산량까지 같다는 뜻은 아니다.

working 정답표에서 Dense 대비 추가된 정답 질문–사례 쌍은 3개, 빠진 쌍은 2개였다. 반복을 중복 집계하지 않은 수다. 원문 토큰과 BM25 두 보완 방식 모두 놓친 정답 쌍은 2개였다:

- VQ006 — AXV2N_0119
- VQ014 — AXV24_36c7ef329920

이 두 쌍은 세 정답표 모두 2점(양성 기준 이상)이다. 세 표의 판정 일치는 확인했지만 독립된 사람의 검증을 뜻하지 않는다. Dense 상위 10개만 보호하므로 기존 후보 20개의 정답을 모두 보존한 것은 아니다.

## 다음 판단

현재 후보 보완 방식을 실험 기준점으로 보존한다. 다음 개선 대상은 **후보의 순서를 정하는 단계**다. 기존 단어 유사도만으로 새 후보를 상위에 올리는 규칙은 두 차례 실패했으므로 그대로 확대하지 않는다.

후속 작업에서는 원문 질문과 사례의 행동·대상·조건을 직접 비교하는 별도 채점기를 개발 자료 안에서 검증한다. 학습이 필요하면 질문 단위로 분리해 같은 질문의 사례가 학습과 검증에 동시에 들어가지 않게 한다. Dense 및 강한 단일질문 보완과 같은 후보/출력 예산으로 비교한다. 최종 F1/nDCG를 손상시키지 않으면서 후보 Recall 또는 최종 순위가 개선되는지 먼저 확인한다. 이번 단계에서는 새 채점기 학습이나 유료 평가를 시작하지 않았다.

기준을 통과한 한 방법만 고정한 뒤 별도 자료로 한 번 검증한다. 이미 결과를 본 신규 40개는 재사용 평가라는 사실을 밝히고, 최종 미열람 시험으로 부르지 않는다. 시험 결과를 보고 다시 조정하면 그 자료도 개발 자료로 취급한다. 시간 내 최종 순위 개선이 없으면 후보 Recall 결과와 최종 순위의 한계를 함께 보고한다.
