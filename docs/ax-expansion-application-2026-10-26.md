# AX 확장 자료 선별·연구 적용 결과

2026-10-26 · 적용 버전 `2.4.0-expansion.1`

## 실제 적용한 결과

기존 frozen 84개를 보존하면서 신규 24개 업무사례를 추가한 **108개 연구용 검색 코퍼스**를 만들고 프로토타입 기본 Dense 검색에 연결했다. 현재 로컬 서버의 `/api/bootstrap` 응답에서도 108개와 새 버전을 확인했고, HTTP 데모 요청의 각 관점이 108개 후보를 검색했다. 바탕화면 실행파일은 같은 소스를 사용하므로 다시 설치할 필요가 없다.

## 전체 판정과 남은 검토

| 단위 | 결과 |
|---|---|
| 1차 기준 적용 | 수집 기록 8,430개. 고유 사례 수가 아님 |
| AI 원문 접근·검토 | 출처 37개. 제목 수준의 본문만 확인돼 보류한 출처도 포함 |
| 신규 포함 | 출처 19개에서 업무 24개 |
| 연구 코퍼스 제외 | 출처 기록 6,143개 |
| 보류하여 검색에서 제외 | 출처 기록 2,268개 |

제외 6,143개는 기업 모집단 밖 6,106개, 중복 출처 기록 32개, 개별 사례가 아닌 페이지 3개, 개별 원문 검토 제외 2개다. 공공기관 목록을 제외한 것은 AI 활용 가치가 없어서가 아니라 현재 연구 모집단이 기업의 실제 운영 업무이기 때문이다.

보류 중 **1,558개는 개별 업무의 원문 상세 검토가 남아 있다.** 나머지는 접근 미해결 275개, 본문 부족 419개, 원문 검토 후 근거·단계·수치가 불명료한 16개다. 아직 확인하지 못한 자료를 부적격으로 확정하지 않았다. 전체 자료의 정밀 검토 완료가 아니며, 수집 원본도 삭제하지 않았다. 추가 발견 목록 중 본문 처리 전인 3,208개는 이번 판정 대상에 포함하지 않았다.

## 검색·연구 연결

- 기존 BGE-M3 1024d의 3-view 평균 Dense를 유지하고 신규 24개만 로컬 임베딩했다. 기존 84개 벡터는 변경하지 않았다.
- 관점별 독립 Top-K, 선택 사례 기반 전략·실행 순서·근거 표시, 사용자 평가 저장·내보내기를 유지했다. UI 수량과 평가 파일의 자료 버전은 실제 실행 버전을 따른다.
- QCI는 기존 84개 실험 재생으로만 동작한다. 108개 코퍼스에 새 QCI 성능이나 학습 결과가 있는 것처럼 표시하지 않는다.
- [연구용 실행 스크립트](../scripts/run_v24_retrieval.py)를 실행하여 기존 동적 관점 97개에 대해 84개/108개 각각 관점별 Top-10 **970행**을 저장했다. [실행 명세](../experiments/v24_expansion/run_manifest.json) · [108개 순위](../experiments/v24_expansion/active_dense_topk.csv) · [84개 비교 순위](../experiments/v24_expansion/frozen_dense_topk.csv).
- 기준 관점 관련도 3,240칸과 [동적 관점 관련도 10,476칸](../experiments/v24_expansion/runtime_relevance_annotation_sheet.csv)은 모두 미판정이다. 과거 AI-Silver나 인간 평가 점수를 복사하지 않았다. 따라서 Recall·전략 Coverage 향상을 주장하지 않는다.
- 신규 원인·전략 라벨은 동일 AI의 원문 검토 초안이다. 독립 Blind RCA·인간 정답·확인적 Wald 분석용 승인 라벨이 아니다. 신규 사례는 확인적 Wald 분석 자동 투입 대상에서 제외했다.

## 검증 결과

- Python 전체 **223개 통과**, 팝업 JavaScript **3개 통과**, 메인 JavaScript 문법 검사 통과.
- [전체 Python 검사 기록](prototype-validation/expansion-tests.xml).
- 저장된 예시 질문 10개를 확장 코퍼스로 실행하고 관점 유지·사례 기반 전략 생성 흐름을 확인했다.
- 자유 입력 6개에서 실제 로컬 BGE-M3 Dense를 실행했으며, 상위 결과에 서로 다른 신규 사례 9개가 등장했다. 번역 질문에 조선일보, 보험 서류에 Tricura·Amwins, 직원 설문에 Hershey, 설비 상태에 Acond·Aggreko 등이 검색됐다. [실제 실행 기록](prototype-validation/expansion-validation.json). 이는 알려진 영역의 동작 점검이며 독립 정확도 시험은 아니다.
- 기존 frozen JSON의 SHA-256 일치와 동결 manifest의 **11개 Git blob** 일치를 확인했다. 기존 추적 데이터·실험·설정·연구 소스의 Git 변경은 없다.
- 원래 `v23_validate_dataset.py`는 Windows 작업 사본의 CRLF 바이트로 Git blob을 직접 계산해 해시 단계에서 실패했다. 파일을 수정하지 않고 Git의 줄바꿈 필터를 적용하는 `git hash-object --path`로 manifest 11개를 대조해 일치를 확인했다. 새 검증 스크립트는 이 방식으로 검사한다.

유료 AI API 호출은 0회이며 실시간 API 경로를 재호출하는 검증은 수행하지 않았다. 키를 출력하거나 데이터셋에 넣지 않았고 GitHub 업로드·공개도 하지 않았다. 현재 적용은 검색에 사용할 수 있는 확장 버전을 제공한 상태이며, 미검토 자료의 추가 선별과 새 관련도 평가는 남아 있다.
