# 핵심 업무 보존형 3관점 개발 실험

2026-11-07

## 추출 기준

| 필드 | 근거 기준 |
|---|---|
| 목적 | 원문에 명시된 업무 목표 |
| 행동 | 실제로 요청한 구체 동작. 읽기·판단·쓰기·실행과 현재 감지·미래 예측을 구분 |
| 대상 | 그 행동이 적용되는 문서·기록·사물 등 |
| 입력 | 명시된 데이터·사용자 입력 |
| 결과 | 명시된 출력물·표시·변경 결과 |
| 운영 | 처리 순서·사람 인계·실행 조건 |
| 제약 | 제외·부정·권한·조건·우선순위의 원래 강도 |

각 필드는 text와 원문 evidence 배열로 반환한다. 미상 필드는 null과 빈 evidence다. E는 질문마다 각 회차에서 이 구조를 먼저 추출하고, 원문과 구조를 함께 보고 현업·운영·기술 3관점을 생성한다. 검색에는 관점 제목과 설명만 사용한다.

A는 새 질문 원문, B는 기존 동적 3관점, C는 기존 보완 고정 3관점, E는 새 보존형 고정 3관점이다. B와 C의 프롬프트 및 설정은 이전 버전에서 가져온다. 모두 새 개발 질문에서 실행한다. C1, BGE-M3, BM25, 후보 112개, 최고 관점 결합 및 기존 가중치는 동결한다.

프롬프트를 먼저 확정한 뒤 새 개발 질문 8개를 작성한다. 과거 Test 질문·정답·순위는 이번 질문 작성이나 실행 입력으로 열지 않는다. 질문 작성자는 기존 연구를 아는 동일 AI이므로 완전한 의미적 독립성을 주장할 수는 없다.

질문과 관련성 기준은 추천 실행 전에 고정한다. 전수 896쌍 관련성은 예측 봉인 뒤 모델명을 가린 별도 호출로 평가한다. 0~3점, 2점 이상 관련, 불확실하면 ABSTAIN을 사용한다. AI-Silver로 기록한다. 전수 판정 없는 질문의 Recall·F1·nDCG와 양성 0건의 Recall·F1은 미정의다.

각 조건 3회 생성한다. E의 3회에는 추출과 관점 생성의 전체 변동이 포함된다. E의 추가 호출·입력 비용도 별도로 보고한다. 자동 재생성·관점 선택·점수 보정은 수행하지 않는다. 형식 오류 또는 생성 품질 문제는 기록하고, 임의 응답 대체 없이 수행 범위를 보고한다.

보존 품질은 원문 근거 일치와 별도 의미 검토로 구분한다. 반복 평균과 표준편차, 질문을 단위로 한 paired bootstrap 95% 구간을 함께 보고한다. 신뢰구간은 이 작은 AI-Silver 개발 표본에 조건부인 수치다.
