## 8. 신뢰성과 한계

896개 판정 상태는 {'JUDGED': 867, 'UNJUDGED': 29}다. 질문·정답과 품질 평가는 같은 AI 계열에 의존하며 사람 Gold 검증은 수행하지 않았다. 질문은 코퍼스의 업무 목록을 참고해 작성한 개발 자료다. 실제 독립 업무 전체에 대한 일반화나 큰 표본의 유의성을 주장하기 어렵다.

세 회차 모두와 미판정 질문을 보존했다. 보류·무양성 처리 규칙은 인공 자료 검사로 확인했다. 지표 분모와 정의 불가 이유는 질문별 결과에 있다. 실제 업무 인계·권한·부정 표현의 오류 여부는 수치와 함께 원문을 다시 확인할 필요가 있다.
