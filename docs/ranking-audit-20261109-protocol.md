# 2026-11-09 최종 순위 개선 검증 규칙

사용자 승인 범위: 실패 분석 → 개선 → 기존 비교 → 질문 분리 검증 → 채택 결정. 새 유료 호출, 신규 40개 및 Test15 접근 없이 기존 개발20 ×112 자료만 사용한다. 이미 과거에 살펴본 개발 자료이므로 독립 시험이 아니다. 기존 모델은 변경하지 않는다.

진단 가설: 분야/단어 유사성과 작업 일치가 다르며, 단일 행동 점수도 오답을 높일 수 있다. 일부 정답은 업종 간 기능 전이 사례다. AI Silver 판정을 그대로 유지하며 실제 Gold로 승격하지 않는다. 조건 일치를 새로 이해했다는 주장을 하지 않는다.

방법: 원문 Dense, 토큰 MaxSim, 수정 BM25, 기존 행동/대상 임베딩, 두 점수의 최솟값/곱, 각 필드의 존재 여부, 기존 task cosine을 입력으로 하는 pairwise ridge 선형 채점기. 사례 ID/질문 ID는 입력 특성이 아니다. 각 연속 점수를 질문 내 전체112사례에서 min-max 변환한다. 누락 필드는 0으로 채우되 존재 여부를 별도로 제공한다. 행동/대상이 모두 있어야 최솟값/곱을 만든다. 정답은 working_transfer의 grade>=2 이진 기준만 학습에 사용한다. 질문별 모든 양성–음성 쌍의 차이를 만들며 각 질문의 총 가중치는 동일하다. 정규화된 점수 조합과 Dense의 혼합으로 최종 점수를 만든다. 조건/부정문 의미를 새로 계산하는 모델은 아니다.

분리: 정렬된20질문을 순번 mod5로 5개 외부 폴드(각4개)로 고정한다. 외부 평가4질문은 학습/설정선택에서 모두 제외한다. 나머지16질문 안에서 다른4폴드를 번갈아 내부 검증한다(학습12, 검증4). ridge λ={0.1,1,10}, Dense혼합에서 학습점수 비중={0,0.5,1}만 비교한다. 내부 Dense20의 질문 평균 F1@5 우선, nDCG@10 차선으로 선택하고 동점이면 학습 비중이 작고 정규화가 강한 설정을 선택한다. 무양성 질문의 F1/nDCG는 평균 제외하며 P@5에는 포함한다. 동일 질문/반복/사례쌍이 학습과 평가에 섞이지 않도록 확인한다. 사례 목록은 고정 검색 DB로 공유되며 미관측 사례 일반화 검증은 아니다.

외부16질문에서 학습한 같은 채점기로 ①Dense20 ②원문토큰 보완20 ③관점 보완20을 각각 정렬한다. 모든 후보는 기존 동결 파일의 후보20이고 출력5다. 후보 안에서만 순서를 바꾸며 밖은 기존 Dense순으로 붙인다. 설정 선택은 Dense20만 사용해 관점 후보의 효과와 채점기 효과를 분리한다. Dense 기본 점수만의 각 후보풀 순위도 함께 평가한다. 이전 E는 참고용이다.

순서: (1)원본/특성/분리 저장 (2)working 학습으로 외부예측 고정 (3)세 정답표에서 외부예측 평가. 다른 두 정답표는 학습/선택에 쓰지 않는다. 질문단위 paired bootstrap10,000회95% 구간은 개발 민감도 분석이며 외부 시험이나 선택 편향 보정으로 부르지 않는다.

유한 종료: 위 한 가족의 중첩 검증을 한 번 끝낸 뒤 결과를 보고 모델을 더 탐색하지 않는다. 채택 최소조건은 세 정답표 모두에서 Dense 대비 F1향상, nDCG 비감소, working F1 차이 구간 하한>0이다. 관점 고유 이득은 같은 채점기의 두 단일질문 후보조건과 별도 비교한다. 미충족이면 채택 보류/기각하고 원인과 잔여 여지를 보고한다. 충족해도 잠정 개발 채택이며 별도 최종평가 전 논문 확정 성능으로 부르지 않는다. 신규 외부시험 생성은 이번 범위에 없다.
