## 실제 결과

안전 입력창에서 사용자가 키를 입력했고 `OPENAI_API_KEY`, `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`가 Windows 사용자 환경변수에 설정된 것을 값 없이 확인했다. 기존 프로그램의 `.env`를 복사하거나 키를 Git 저장 파일에 작성하지 않았다.

| 서비스 | 요청 모델 | 생성 호출 | 결과 | 응답 토큰 사용량 | 공식 표준요율 기준 추정액 |
|---|---|---:|---|---|---:|
| OpenAI | gpt-6-luna | 1 | HTTP200, OK | 입력11 / 출력5 | $0.0000036 |
| Gemini | gemini-2.5-flash-lite | 1 | HTTP404 | 미확인 | 미확인 |

성공한 두 호출의 사용량 기반 합계는 **$0.0000356**다. 실제 청구서/세금/환율은 확인하지 않았으며 Gemini 실패 요청의 청구액은 임의로 0으로 확정하지 않았다. 결과는 `results.json`에 저장했다. 출력 내용은 OK 일치 여부만 기록하며 원시 응답·헤더·키·오류 본문을 저장하지 않는다.

Gemini는 실패 후 별도의 **읽기 전용 모델 목록 GET 1회**에서 HTTP200을 반환했고 요청 모델도 목록에 있었다. 따라서 키가 무효라거나 모델이 목록에서 삭제됐다고 단정하지 않는다. 생성 endpoint의 404 원인은 미확정이다. `gemini-model-metadata.json`에 모델 ID와 조회 상태만 기록했다. 추가 생성 호출·다른 모델 대체·자동 재시도는 하지 않았다. 총 외부 API 요청은 생성3회+메타데이터조회1회다.

Claude는 이 한 번의 요청을 처리할 수 있었지만 **정확한 잔액과 선불/후불/프로모션 크레딧 유형은 미확인**이다. 연결된 브라우저의 Billing 페이지는 로그인 화면이어서 계정 잔액을 읽지 못했다. 사용자 계정의 [Claude Billing](https://platform.claude.com/settings/billing)에서 Credit balance/Promotional credits, 만료일, Auto-reload, 조직 Spend limit를 확인해야 한다. 충전·자동충전·계정 연결은 변경하지 않았다. API 키를 발급받은 사실만으로 충전 잔액이 있다고 판단하지 않는다.

## 안전한 설정과 실행 방법

사용자 PowerShell에서 아래 파일을 실행하면 세 값을 **가려서 입력**받는다. 키를 이 명령 뒤에 붙이지 않는다. 빈 입력은 기존 설정을 유지한다.

```powershell
& 'C:\Users\iovek\OneDrive\문서\ChatGPT\AI공부\AX-stage123\scripts\set_stage1_api_keys.ps1'
```

설정은 Windows 사용자 환경변수에 보관되며 프로젝트 파일·명령행 인수·셸 명령 기록에 키를 쓰지 않는다. 사용자 환경변수는 암호화된 비밀 저장소가 아니며 같은 계정의 프로그램이 읽을 수 있다. 공용 PC나 공유 계정에는 이 방식을 쓰지 않는다. 변경/삭제는 Windows의 '사용자 환경 변수' 화면에서 해당 세 이름으로 관리한다. 채팅·스크린샷·로그에 값을 보내지 않는다.

새 프로세스는 환경변수를 상속한다. 현재 Codex 프로세스가 오래 실행 중이어도 테스트 도구는 명시된 세 이름의 사용자 환경변수를 직접 읽을 수 있다. process 값이 있으면 process 값을 우선한다. 환경변수 전체를 덤프하지 않는다.

키 파일은 만들지 않았다. 기존 `.local/` Git 제외 정책을 유지하고 `.env.*`/`.secrets/`를 추가로 제외했다. `.env.example`에는 예시 이름만 둘 수 있다. 키에 프로젝트별 최소 권한을 적용하고 사용하지 않는 키는 해당 공급자 콘솔에서 폐기한다. 플랫폼/API 로그 정책까지 로컬 도구가 변경하거나 보장하는 것은 아니다.

테스트 코드는 연구 데이터 파일을 읽지 않으며 고정 문장 `Reply with exactly OK.`만 전송한다. 키는 HTTPS 인증 헤더로만 전달하고 Gemini URL의 쿼리에 키를 넣지 않는다. HTTPS redirect도 차단한다. 응답 최대64토큰, timeout45초, 서비스별1회, 자동재시도0회다. OpenAI 저장 옵션은 false다. Gemini 무료 tier/서비스 정책에 따른 데이터 처리는 해당 계정 정책을 확인해야 한다.

실행 전 예상 토큰 비용이 $0.01보다 크면 차단한다. 이 값은 공급자 계정의 강제 청구 상한이 아니라 도구의 사전 추정 검사다. `.local/stage1-api-connection/ledger.json`에 실행 예약을 먼저 기록하므로 같은 도구를 다시 실행해도 추가 호출하지 않는다. 실패/타임아웃 이후에도 재시도하지 않는다. ledger를 삭제하거나 다른 경로로 우회해 재호출하지 않았다.

```powershell
$env:PYTHONPATH='src;.'
& ..\AX-prototype\.venv\Scripts\python.exe -m scripts.test_stage1_api_connections --execute
```

현재는 실행 기록이 이미 있으므로 이 명령으로 중복 호출되지 않는다. 추가 테스트가 필요하면 대상 모델과 추가 호출 횟수를 정한 후 별도 승인 범위로 진행한다. 연결 성공은 모델의 한국어 관련도 판정 품질 검증이나 전체 Stage1 실행 승인과 다르다.
