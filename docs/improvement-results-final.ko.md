# 로컬 성능 개선 반복 검증 결과와 완료 감사

2026-11-08. 요청한 네 우선순위의 분석과 무료 로컬 반복 검증을 수행했고, 고정된 개발 정답의 관측 평균에서 개선되는 후보10을 확보했다. 유료 API와 정답 변경 없이 실행 가능한 후보 모듈과 재현 증거를 남긴다. 이번 완료는 로컬 개선 탐색·비교·재현 작업의 완료다. 독립 Gold/새 Test 기반 논문 성능 우위가 확정됐다는 뜻은 아니다.

## 확보한 결과

원문 Dense 검색을 유지하면서 기존 BGE-M3의 단어별 의미 비교를 보탰다. 각 관점도 별도로 계산하고 원문과 의미가 가까운 관점에 더 큰 가중치를 주어 뒤에서 결합했다. 새 모델을 받거나 LLM을 다시 호출하지 않았다. 사전학습 ColBERT/교차 인코더가 아닌 원시 토큰 표현을 이용한 실험이다.

| 같은 고정 정답 기준 | E F1 / nDCG | Dense F1 / nDCG | 후보10 F1 / nDCG |
|---|---:|---:|---:|
| 신규20의 작업용 정답,16양성질문 |23.95 / 41.17|23.20 / 50.55|26.07 / 51.35|
| 신규20의 최초 정답,17양성질문 |23.72 / 42.39|25.81 / 46.94|27.36 / 49.36|
| 신규20의464쌍 합의 반영,18양성질문 |19.44 / 34.42|20.26 / 42.09|20.60 / 45.42|
| 기존 CPD의6완전판정 질문 |50.05 / 78.06|30.67 / 57.75|38.38 / 65.69|

숫자는%다. 다른 행의 절대 평균을 전후 개선률로 비교하지 않는다. CPD의2미완전 질문29판정은 임의로 채우지 않고 주 지표에서 제외했다. 표의 신규20은 모델 탐색에 반복 사용했고 CPD도 이전에 본 개발 질문이다. 어느 행도 새로운 독립 최종 Test가 아니다.

후보10은 신규20의 세 정답 버전 모두에서 E와 Dense보다 두 지표의 평균이 높다. 다른 기존 질문에서도 Dense보다 높았다. 그러나 CPD에서는 E가 더 좋았으므로 후보10으로 전부 교체하지 않는다. 신규20에서 Dense 대비 차이의95%구간은 모두0을 포함한다. 예를 들어 작업용 정답에서 F1 +2.86%p의 구간은[-2.52,+9.21]%p, nDCG +0.80%p는[-4.05,+5.73]%p다. 관측 개선을 확정적 일반화 우위로 표현하지 않는다.

## 우선순위별 수행 증거

| 요구한 작업 | 실제 수행과 근거 |
|---|---|
|1. 순위 계산에서 좋은 사례 손실 | cycle1의 요소 제거, cycle4/5의 학습·제한 결합, cycle6~9의 표본 편향·벡터 상호작용 비교. 기존 E의60개 질문·반복 순위를 먼저 재현했다. |
|2. 후보 수집 | cycle2에서 Dense20·교대20의 동일 후보 수로 E/원문규칙 순위를 비교했다. 후보 Recall과 최종 F1/nDCG를 구분했다. |
|3. 관점 의미 보존 | cycle2의 원문 기능 보존, cycle6의 원문/관점 cosine 가중, cycle10의 관점별 토큰/Dense 늦은 결합을 검증했다. |
|4. 언어 연결 | cycle3에서 기존 한영 기능·도메인 토큰을 비교했고, cycle10에서 동일 로컬 다국어 모델의 토큰 표현을 실제 계산했다. |
|고정 정답과 단순 Dense 비교 | 원래 정답 파일을 유지한 채 세 버전 모두에서 같은 후보 순위를 평가했다. 각 버전의 질문 분모를 별도 보고했다. |
|개발 개선과 독립 검증 구분 | 신규20·기존 CPD를 개발로 표시하고 Test15를 열지 않았다.464쌍 합의도 전체 독립 Gold로 표시하지 않았다. |
|무료 로컬 반복 실행 | 모든 새 실험의 paid_calls=0, test_access=false. 기존 모델 해시와 입력 해시를 확인했다. |
|재현 가능한 개선 구현 | src/ax_research/token_interaction.py의 TokenInteractionRanker를 별도 추가하고 신규20의60개와 CPD8의24개 순위를 모두 정확히 재현했다. 정답을 입력받는 인터페이스가 없다. |

후보는 별도 모듈로 남겼으며 기존 E/앱에 자동 적용하지 않았다. GitHub 커밋·push도 하지 않았다. 기존 추적 파일 변경은 토큰 캐시를 제외하는 .gitignore 한 줄뿐이고, 연구 코드·결과·검사는 새 파일로 남겼다. 기존 코어·모델·정답은 변경하지 않았다.

## 마지막 선택기 실험도 숨기지 않는다

cycle12에서 정답을 보지 않고 얻는 질문·순위 특성12개로 E/후보10 선택기를 만들고5분할 질문 제외 검증을 했다. 자료 묶음 이름이나 질문ID를 입력 특성으로 쓰지 않았다. 신규 작업용 정답에서 F1은26.07%였지만 nDCG49.06%로 후보10의51.35%, Dense50.55%보다 낮았다. CPD F1은E와 같은50.05%를 유지했지만 nDCG는76.64%로E78.06%보다 낮았다. 한 자료 묶음을 통째로 제외하는 스트레스 검증도 충분하지 않았다. 따라서 선택기는 채택하지 않았고 같은 자료에서 다른 선택기 설정을 계속 고르지 않았다.

## 재현 확인

- 후보10의240개 후보 순위와3정답 버전의 질문별/전체 지표를 토큰 캐시에서 다시 계산해 일치했다: improvement-cycle10-20261108-verification.json.
- CPD의80경로 토큰 점수,48개 후보 순위와전체 지표를 재계산해 일치했다: improvement-cycle11-20261108-verification.json.
- 재사용 모듈이 두 자료의84개 질문·반복 순위를 모두 재현했다: reusable-token-ranker-verification.json.
- 실패한 실제 벡터 신경망의 저장 모델10개를 재로드해40개 질문·모형 출력을 재현했다: improvement-cycle9-20261108-verification.json.
- 선택기56개 결정과168개 순위,4평가 조건 지표를 재현했다: improvement-cycle12-20261108-verification.json.
- 새 검사12개와 기존6개, 총18개 통과. 평가 질문의 정답을 바꿔도 선택기의 학습·결정이 바뀌지 않는 검사, 등록 사례 누락/비정상 벡터 거부, 동일 관점 추가 시 점수 보존, 반복의 독립표본 오인 방지 등을 포함했다. 이 검사는 정답 의미의 정확성이나 논문 통계적 우위의 증명이 아니다.

## 논문에 남은 조건

현재 주장할 수 있는 것은 기존 자료에서 관측된 개선, 토큰 비교의 보완 효과, 실패한 학습/선택 방법과 재현성이다. 사람 검증 Gold, 독립 새 질문에서의 우위, 다중관점 자체의 보편적 기여, Factor/Wald/전략 추천 전체의 개선은 이번 작업으로 입증하지 않았다. 최초 정답에서는 원문 토큰 Hybrid의 F1이 관점 포함보다 높았으므로 다중관점 효과를 분리해서 검증해야 한다.

다음 연구 단계는 후보10의 공식·모델·입력 정책을 고정하고 기존 결과를 보지 않은 작성자의 새 질문과 원문 근거 기반 정답으로 원문 Dense/E/원문 토큰/관점 토큰을 한 번 비교하는 것이다. 비용이나 새 API 호출을 승인받았다는 뜻이 아니며 이번 실행에 포함하지 않았다. 기존 Test15는 과거 노출 이력이 있으므로 새로운 미사용 최종 Test로 다시 이름 붙이지 않는다.
