# AX v2.3 Dev Ground Truth 구축 결과 보고 — AI Silver 평가정답 동결

작성일 2026-10-23 · 연구용 코퍼스 `release/ax-v2.3-frozen-20261023` (84개 사례) · 개발 질문 10개

## 연구 성과물의 정확한 이름
**완성된 산출물:** `AX_v2.3_DEV_AI_SILVER_2520` — 연구용 개발 평가 기준 *후보* (0~4점 전체 커버리지).
**아직 완료되지 않은 산출물:** 연구자/인간이 직접 판정·승인한 최종 *Gold Ground Truth*.

사용자가 별도 입력하지 않아도 가능한 모든 **AI 독립 채점·반복검증·관점별 관련도·전략 후보·재검토 목록·릴리스 고정** 작업을 완료했다. **AI 작업을 인간 평가로 허위 표시하지 않는다.**

## 2. 방법
- 동결된 84개 사례의 `problem`, `task`, `context`와 열 개 사용자 업무문제·참조 관점의 제목만 사용.
- `strategy`, `factor`, `implementation`, `outcome`, 검색 순위, 과거 AI 점수, 이전 사람 점수는 LLM 채점에 주입하지 않았다.
- 채점 기준: 4=문제와 업무/환경 직접 일치, 3=핵심 문제·업무 강하게 일치, 2=일부 교집합, 1=주변 유사, 0=무관. 양성 임계값 3.
- 분리된 독립 API 응답(모델 `gpt-6-luna`) 3회 결과를 모두 보존하고 중앙값을 AI-Silver 점수로 저장. 원문 입력, 판단 이유, API 응답 ID, 모델명, 프롬프트 SHA를 원본 작업 폴더에 보존.
- 교차 채점에서 관련/비관련이 뒤집히는 90개를 표시. 점수 차가 2점 이상인 사례까지 포함해 119개 블라인드 검토목록 생성.
- [검증 워크플로](https://github.com/comjung-star/AX-research/actions/runs/39928151451)는 점수 범위·중앙값·관점쌍·사례 ID·모델 응답 기록·전략 후보·과거 50개 파일럿 분리를 검증하여 **성공**.

## 3. 기존 연구자 직접평가 50개 재활용 정책
v2.2에서 실제 연구자가 직접 평가한 **50개**의 기록을 삭제하지 않았다.
- 최종 v2.3에 남은 동일 사례: **45개** 평가쌍.
- 이 중 사례 입력 텍스트가 바뀐 평가쌍: **4개**.
- 같은 45개를 대상으로 연구자 과거 점수와 신규 AI-Silver 중앙값이 관련/비관련 기준으로 다름: **19개**.
- 비교 표본 자체가 예전 AI 이견을 의도적으로 많이 뽑은 편향 표본이다. 19/45를 새로운 AI 일반 오답률, 연구자 실수 비율이라고 주장할 수 없다.
- 예전 50개 점수를 v2.3 Gold 파일로 **자동 이식하지 않았다**. 인간 검증을 했다고 꾸미지 않는다.

- `v23-gt-V21D001..010-p1..3/ratings.csv` 및 `raw_batches/`: 세 번 독립 평가의 원자료와 응답 감사기록.

## 5. 연구 적용 시 필수 주의
1. 이번 2520개의 정답은 **AI-Silver 평가 기준**이다. 논문에 사람이 확인한 최종 Ground Truth라고 쓰면 안 된다.
2. 3회 완전 일치 69.3%라는 수치는 동일 모델 반복평정 일치이지 외부 정확도 69.3%라는 뜻이 아니다.
3. 90개 경계의견 변동 및 연구자 50개와의 이견이 있으므로, 본 Silver 기반 Recall@K 등은 **탐색적 Dev 결과**로만 보고한다.
4. 테스트와 무관한 30개 참조 관점은 평가 기준으로만 사용하고, 검색모델이나 실시간 LLM 관점 생성에 제공하지 않는다.
5. 사용했던 10개 질의는 Dev이고, v2.3 신규 사례 중 일부는 예전 Dev coverage를 보고 선정됐다. **독립 Held-out Test Ground Truth가 없는 현재 최종 성능을 주장할 수 없다.**
6. Gold 필요시 연구자가 현재 v2.3의 독립 관련도 판단을 승인해야 하나, **제3자 평가자나 장문 이유 작성은 필수가 아니며**, 이전 작업을 재제출하도록 요구하지 않는다. 인간 승인 절차가 생략되었다고 사실을 조작하지 않는다.

## 결론
v2.3을 기준으로 **2,520개 개발용 AI-Silver 평가정답 후보 + 완전한 감사 증거 + 검증 자동화**를 구축·보존했다. 사람이 평가하여 확정한 Gold와 새로운 Test Gold는 **아직 아니다**. 연구자/지도교수에게 이 상태를 명시하면 재현 가능한 Dev 실험 준비자료로 사용할 수 있다.
