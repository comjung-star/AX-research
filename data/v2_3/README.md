# AX 데이터셋 v2.3.0 — 원인·전략 연결 정제 결과
**기준일 2026-10-23 · 상태: 연구자 최종 동결 승인 전 · 개발용 Ground Truth 미완성.**

## 적용한 승인 원칙
1. 기업의 실제 업무·고객 서비스 운영 단위가 아닌 사례는 제외한다.
2. 원인 또는 전략을 기존 분류체계에 표현할 수 없으면 근거에 따라 분류체계의 범위·유형을 보완한다.
3. 그래도 업무별 원인 또는 실제 전략을 명확히 분류할 증거가 없으면 제외한다.
4. 하나의 업무에 둘 이상의 원인·전략이 직접 나타나면 복수 라벨을 허용한다. 추론만으로 부여하지 않는다.
5. v1/v2.1/v2.2 원본은 변경하지 않고, v2.3 별도 버전으로 관리한다.

## 근거 구분
- Root Cause는 사례의 **Problem / Task / Context**로만 판단한다. Solution의 효과를 보고 문제의 원인을 거꾸로 만들어내지 않는다.
- Strategy는 실제 **Implementation / 배포기능**에서 확인한다.
- AI 추론/해석을 출처에서 '직접 발언'한 것처럼 표시하지 않으며, 불확실한 KPI나 출처 공급사 주장에 독립감사 여부를 표시한다.
- 복수 Factor와 복수 Strategy를 기록해도 모든 가능한 쌍의 인과관계가 증명된 것은 아니다.

## 데이터셋과 정답표를 혼동하지 않는다
- v2.3 **86개 업무 사례 정제 초안**은 구축되었다. 하지만 **논문의 새로운 검색 Ground Truth는 아직 확정하지 않았다.**
- v2.3에는 기존 Dev 질문 10개와 기준관점 30개를 연동한 **2580개 빈 UNJUDGED** 평가표를 생성했다.
- v2.2의 AI 3회 평가점수와 연구자 50개 파일럿은 **자동으로 v2.3 정답표에 복사하지 않는다.** 별도 연구 방법과 승인 후 사용 여부를 정한다.
- 원래 v2.2의 2개 사례(Wayfair/제주은행)는 Dev의 빈 관점을 본 후 추가됐으므로 **개발 데이터 선정 편향**을 논문에 공개한다. 독립적인 최종 Test 질문/정답표로 결론을 검증해야 한다.
- **제3자 검토는 의무사항이 아니며**, 연구자 단독 평가를 사용할 수 있다. 다만 '제3자 불필요'와 '기존 AI 점수=검증된 인간 정답'은 다르다.
