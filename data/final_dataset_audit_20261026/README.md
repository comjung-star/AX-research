# 최종 실험 데이터셋 감사 · 2026-10-26

**요청한 최종 완료 상태는 아직 달성하지 못했다. 현재 최종 실험 승인 사례는 0건이다.**

원문 문서 근거가 있는 후보는 **117건**이다. 이 숫자를 완성된 최종 실험 데이터셋 수로 보고하면 안 된다. 이전 112건도 최종 실험 승인본이 아니었다. 이 감사본은 부족한 검증을 파일과 승인 조건으로 드러내고, 미완료가 완료로 잘못 집계되는 것을 방지한다.

## 이번에 실제 수행한 작업

- 원본 등록 11,766건·검색 후보 9,416건과 모든 v2.3/v2.4/v2.5·과거 실험을 보존했다. 이 감사본은 별도 파생본이다.
- 11,766건의 기존 판정·근거·검토 방법을 다시 연결했다. 기존 자동 접근/스키마 점검을 개별 사실검증으로 바꾸지 않았다.
- 24개 확장 업무의 로컬 원문 문단들이 기존 근거 해시와 일치함을 확인했다. 이것은 보관 원문의 무결성 점검이며 문장 내용의 독립 사실 검증과 다르다.
- 보류했던 Wayfair/제주은행의 공식 원문을 개별 대조했다. 기존 v2.3 레코드는 변경하지 않았다. 원천이 보고한 운영과 성과이며 독립 실측으로 승격하지 않았다.
- 과거 업무 범위 때문에 제외했던 Duolingo Role Play, Explain my Answer, Be My AI 3개 기능을 공식 원문과 대조해 새 후보본에 복원했다. 원인 라벨의 과거 ABSTAIN도 그대로 보존했다.
- 위 5건의 새 문서 검토는 `individual_source_reviews.json`에 기록했다. 신규 사례 수집, 유료 API 호출, 독립적인 기관 간 성과 교차검증은 0이다.
- 후보 117건을 87개 기관/출처/기존 표본 연결 그룹으로 묶었다. 기존 112건의 3-view 임베딩에서 평균 cosine >=0.90인 중복 의심 쌍은 0이었다. 이 임계값 점검은 의미 중복이 없다는 보증이 아니다. 새 5건도 별도 검토 대상이다.
- 신규 117건 × 기존 Dev 10질문 × 3개 평가 reference = **3,510쌍**의 독립 관련성 검토 입력을 만들었다. 구현·성과·원인·전략·모델 순위를 숨긴다. 원인은 Problem만, 전략은 구현/성과만 별도 입력으로 만든다.

후보 117의 구성은 기존 112 + 보류 원문 재확인 2 + 범위 제외 복원 3이다. 기존 112에는 과거 검토 업무 106 + 미국 기관 원천 행 검토 6이 들어 있다. 후보 중 기업 106, 공공 6, 교육 2, 개인 1, 복합 2라는 업무 구분은 분류 컬럼이지 제외 기준이 아니다.

| 의미 중복 최종 조정 | 유사도 자동 점검만 있음. 최종 의미 검토 승인 없음 |
| 최종 모델·프롬프트·평가 규칙 동결 | 전체 최종 실험을 위한 동결 기록 없음 |

| 최종 확인적 평가에 대한 연구자 승인 | 없음 |

기존 frozen 84건에는 AI가 3회 판정한 Dev Silver 2,520쌍이 있다. 새 후보본과 사례 ID가 겹치는 것은 84건이지만, 이 과거 자료는 인간 Gold가 아니며 새로운 최종 Test의 정답표가 아니다. 미승인 상태를 없애려고 이름을 Gold/Test로 바꾸거나 신규 후보의 미판정을 0점으로 채우지 않았다.

모델·프롬프트를 고정한 후에 Test를 구성하라는 `AGENTS.md` 규칙도 유지한다. 아직 전체 FAME-AX의 최종 모델이 확정되었다는 근거가 없으므로 데이터 작업만으로 그 동결을 만들어 완료라고 선언하지 않는다.

## 저장 파일

- `readiness.json`: 단일 판정 결과. `final_experiment_eligible_cases=0`, `completion_claim=false`.
- `source_supported_candidates.json`: 117개 후보. 모든 `final_experiment_approved=false`.
- `case_evidence_matrix.csv`: 문서 근거와 검토 방법, 기존 라벨 검토 기록 유무, 새 승인 상태.
- `registry_review_status.csv`: 원본 11,766개와 기존 근거 연결. 모든 기록의 사실검증을 새로 수행했다는 의미가 아니다.
- `candidate_groups.csv`, `known_group_links.csv`, `semantic_duplicate_review_queue.csv`: 누수/중복 점검과 한계.
- `blind_relevance_input.json`, `relevance_annotation_template.csv`: 해결 정보와 검색 순위를 숨긴 독립 판단 입력과 미판정 양식.
- `factor_blind_input.csv`, `strategy_blind_input.csv`: 독립된 입력 View.
- `manifest.json`: 파일 해시, 시작 SHA, 생성기 해시, 입력 fingerprint. 완료 승인으로 사용하지 않는다.

## 독립 검토 이후의 검증

독립 판단 결과는 `relevance_pass_1.csv`와 `relevance_pass_2.csv`로 저장하고, 각각 서로 다른 검토자 ID·정확한 입력 해시·0–4 점수·근거 이유가 필요하다. 누락·중복·빈 점수·이전 입력의 판정은 거부한다. 동일 검토자의 반복을 독립 검토자 2명으로 간주하지 않는다.

필요한 후속 승인 자료는 감사기에 명시되어 있다. 승인 자료를 자동으로 만들어 통과시키지 않는다. 원인/전략·중복·불일치·연구자 승인은 해당 후보/판단 입력 fingerprint와 실제 검토자·이유에 연결해야 한다. Test는 동결 시각 이후에 만들어야 하고, frozen artifact와 정답표의 해시를 확인해야 한다.

현재 도구의 명시적 허용 규칙 때문에 별도 독립 AI 검토자 2개 사용 여부를 질문했고 아직 답을 받지 않았다. 허용 없이 별도 검토자를 실행하거나 이 채팅의 반복 판단을 독립 2회로 꾸미지 않는다. 연구자 승인 및 최종 모델 동결은 그와 별개의 조건이다.

```powershell
$env:PYTHONPATH='src;.'
.\.venv\Scripts\python.exe -m scripts.audit_final_dataset
.\.venv\Scripts\python.exe -m pytest -q tests/test_final_dataset_audit.py
```

위 명령의 성공은 **감사 절차가 정상 실행되었음**을 의미한다. `readiness.json`의 조건이 실패한 상태에서 테스트가 통과했다는 이유로 최종 데이터셋이 완성됐다고 보고하면 안 된다.
