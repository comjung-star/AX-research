# AX v2.2 — 점수만 입력하는 사람 평가 규칙 (2026-10-23)

**연구자 요청:** 사람의 개별 점수(0–4)만 입력하고, 자유서술식 `판단 이유`는 작성하지 않아도 된다. 이미 제출한 연구자 1차 50건도 모두 유효한 **1차 평가 자료**이며 재작성할 필요가 없다.

## 1. 1차 점수 입력 (필수)
- 질문 및 평가용 관점과 실제 사례의 **Problem / Task / Context**만 보고 0/1/2/3/4 중 한 점수를 선택한다.
- 필수 기록: 고유 평가항목 ID, query ID, reference perspective ID, case ID, 점수, 평가자 식별자, 평가 버전/일자, 1차 평가 상태.
- 자유서술 이유/판단 근거 텍스트: **선택 입력(빈칸 허용)**. 1차 점수의 유효성 검사에서 이유가 없다고 탈락시키지 않는다.
- AI의 3회 점수, 기존 인적 점수, 유사도 순위, 솔루션/전략/성과 정보는 평가 전에는 보여주지 않는다.

## 2. 독립 검토 (최종 GT와 별도)
- 동일한 사례·동일한 질문·관점·문구/원문을 두 번째 사람에게 별도로 점수만 매기도록 한다. 이름/ID는 첫 평가자와 달라야 한다.
- 두 점수가 다르면 **제3의 블라인드 수치 평정** 또는 별도 조정자가 확인하여 **선택한 최종 점수와 조정자 ID, 이전 두 점수**를 함께 기록한다. 사유 문장은 필수로 요구하지 않는다. 관점별 '관련 있음' 기준은 3점 이상이다.
- 숫자만으로 자동 다수결/중앙값/AI 점수 복사로 정답 승격하지 않는다. 누가 어떻게 최종 판정했는지 감사 가능하도록 두 최초 평점과 조정 이력을 보존한다.
- 외부 논문 심사·지도교수 요구로 추가 질적 근거가 필요해지면, **그때 합의한 불일치 사례만** 제한적으로 근거를 보강한다. 당장 50개를 다시 평가하거나 이유를 일일이 쓰지 않는다.

## 3. 연구 결과로 주장할 수 있는 범위
- 이번 50건은 **파일럿**이다. 독립 제2인 평가가 없고 전체 2,790 항목의 인간 정답표가 아니므로 `NOT_GOLD` 상태를 유지한다.
- 최초 50건은 연구자에게 **한국어 요약/의역**으로 표시되었고 원래 JSON/CSV는 일부 영문 원문이다. 제2평가·정답 확정 시 **두 사람이 같은 입력을 보았는지** 확인해야 한다. 그렇지 않으면 문구 차이로 인한 평가 불일치를 별도로 기록하거나 같은 입력으로 재시험해야 한다.
- 26건의 불일치는 **사람 vs AI 예비 점수의 차이**이며, 어느 쪽이 틀렸다는 판정이 아니다. 추가 검토는 **점수만 재평가하는 방식**을 허용한다.
- 50개는 점수가 흔들리는 항목을 집중적으로 뽑았으므로 전체 2,790개 판단의 오류율 또는 모델 성능으로 일반화하지 않는다.
- `data/v2_1/ground_truth_protocol_v2_1.md`의 기존 91건 검수 규칙과 `scripts/v21_evaluate.py`의 엄격한 최종 GT 차단장치는 **변경하지 않는다**. 이 문서는 별도 v2.2 점수 전용 파일럿 프로토콜이다.
- 향후 v2.2 전체를 정식 GT로 승격하려면, 이 규칙에 맞춘 **별도의 명시적인 v2.2 평가기/정답 동결 절차**와 독립 평정 범위·합의 기준이 충족되어야 한다. 이 50건 제출만으로 자동 승인하지 않는다.

**결론:** 손으로 적어야 하는 이유 0개. 점수 50개는 이미 정상 접수·보존, 최종 GT 0개는 별도의 독립 검토/전수 범위 때문에 유지.
